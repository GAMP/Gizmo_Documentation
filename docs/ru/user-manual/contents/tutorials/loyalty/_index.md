Для привлечения и удержания клиентов в Gizmo доступен обширный набор инструментов. Логически данный набор инструментов можно разбить на две категории:

- Групповые инструменты лояльности
- Персонализированные инструменты лояльности

## Групповые инструменты лояльности

К групповым инструментам лояльности относятся все инструменты, связанные с группой пользователей, а именно:

- Персонализированные приложения для группы пользователей. Инструмент позволяет давать определённой группе пользователей уникальный контент в виде эксклюзивных игр и приложений.
- Персонализированный профиль безопасности. Инструмент позволяет дать вашим привилегированным пользователям больше свободы действий за игровым пк.
- Личное хранилище. Позволяет настроить привилегированным пользователям их личное хранилище для сейвов и других пользовательских данных.
- Скидки. Количество скидок не ограничено. Скидки доступны в разных сценариях использования, которые можно комбинировать. Использование скидок может быть ограничено датами, днями недели и временем. Как настроить скидки -- в инструкции [«Скидки и акции»](./discounts-and-promotions.md). Возможные реализации:
  - Кешбэк бонусами за определённый или за любой заказ
  - Фиксированное бонусное вознаграждение за определённый или за любой заказ
  - Скидка на определённую позицию в заказе или на весь заказ
  - Скидка или вознаграждение за определённый метод оплаты заказа
  - и др.
- Кредитная линия. Инструмент позволяет открыть вашим привилегированным пользователям кредитную линию -- см. инструкцию [«Как включить постоплату»](./../staff/postpay.md).
- Система бонусов. Инструмент, призывающий пользователей копить бонусы и тратить их на определённые товары. Получать бонусы можно за покупку определённых товаров и услуг, за общее количество потраченных средств или за общее количество потраченного времени -- см. инструкцию [«Бонусные баллы для клиентов»](./loyalty-program.md).
- Ограничение на использование определённых групп устройств. С данным инструментом вы можете создать в своём заведении зону устройств, которая будет доступна только привилегированным пользователям.
- Уровни привилегий. Инструмент позволяет задавать правила перехода пользователей из одной группы в другую (через систему достижений), тем самым автоматизируя процесс получения всех вышеперечисленных групповых привилегий -- см. инструкцию [«Как настроить уровни привилегий»](./ladder.md).

## Персонализированные инструменты лояльности

К персонализированным инструментам лояльности относятся следующие инструменты:

- Акции. Инструмент, который позволяет создавать акционные кампании с промокодами. Промокод единоразово активирует для пользователя скидку или скидочную группу -- см. инструкцию [«Промокоды»](./promo-codes.md).
- Достижения. Инструмент, позволяющий отмечать прогресс пользователя в заведении. Прогресс достижений может быть учтён в Уровнях привилегий и в Испытаниях. В системе имеется готовый набор достижений (Потраченные деньги, время, накопленные бонусы, срок регистрации и др.), однако имеется возможность создания своих кастомных достижений, например, достижение за подписку на группу в социальной сети -- см. инструкцию [«Как настроить достижения»](./achievements.md).
- Испытания. Инструмент позволяет мотивировать пользователей совершать достижения. Испытания могут иметь временные рамки и количественные рамки выполнения. За испытания пользователю может быть назначен приз в виде товара, услуги или бесплатного времени. Приз может быть выдан автоматически или вручную оператором -- см. инструкцию [«Как настроить испытания»](./challenges.md).

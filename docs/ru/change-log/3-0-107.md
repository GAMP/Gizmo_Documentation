## Client Shell

### Исправленные баги

- Все DLL-файлы теперь подписаны для безопасного обновления.
- Исправлены уведомления об оставшемся времени пользователя.
- Исправлена ошибка при покупке пакетов времени в Gizmo Client, когда не задана касса по умолчанию.
- Gizmo Client показывал новости всех филиалов, даже если в текущем филиале новости отключены. Исправлено.

## Общее

### **Исправленные ошибки**

- Заказы с нулевой суммой оплаты теперь получают статусы «Оплачен» и «Завершён» (если доставка не требуется).
- Баллы за товар не начисляются, если его стоимость в заказе равна 0. Исправлено.
- Исправлена ошибка с правами доступа в API.
- В некоторых случаях не начислялся процентный бонус при применении скидки. Исправлено.
- Сервер мог аварийно завершить работу во время резервного копирования и при изменении связанных с ним настроек. Исправлено.
- Файл PowerOff.bat не выполнялся при команде перезагрузки. Исправлено.

## Companion

### **Исправленные ошибки**

- Дублирование позиций бандла в фискальном чеке. Исправлено.

## Web Manager

### **Исправленные ошибки**

- Исправлена ошибка автоматического закрытия балансов пользователей.
- Удалённые филиалы отображались в списке на страницах карточки склада и карточки кассы. Исправлено.
- Видимость меню «Действия» на странице пользователя зависила от права «Редактирование» пользователя.
- Право «Изменение группы пользователя» не применялось при создании пользователя. Исправлено.

### **Косметические изменения**

- Из фильтра дат в календаре бронирований убрано время.
- Вкладка «Плагин» переименована в «Плагины и интеграции».

### **Исключения**

- Нельзя удалить кассу, если она последняя в филиале и есть активные операторы, которым требуется смена.
- Новое исключение: оператор не может продать клиенту пакет времени, если клиент вошёл на хост из группы хостов, для которой продажа этого пакета запрещена.

### **Новые функции**

- Добавлена функция дублирования товара.
- Добавлена функция дублирования пакетов времени (Time offer).
- Добавлена функция дублирования тарифа.
- Новые отдельные права операторов: «Вход пользователей (для хостов)» и «Вход пользователей (для конечных точек)».
- В окне «Закрытие баланса» теперь отображается баланс пользователя.

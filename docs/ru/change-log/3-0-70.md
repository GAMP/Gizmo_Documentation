## Новые функции

1. Linux-версия Gizmo

2. Docker-версия Gizmo

3. Поддержка базы данных Postgres

4. Web-версия Gizmo Manager (v3)

5. Обновленное API (v3)

6. Web имплементация удаленного доступа на клиентские пк (RemoteControl)

7. Web имплементация удаленного просмотра на клиентские пк (RemoteView)

8. Возможность использования нескольких клубов на одном сервере (Branch). Общая база пользователей.

9. Расширенный список политики безопасности

10. Обновленная система фискализации оплат (аванс, посоплата, предоплата)

11. Возможность добавления в единую корзину товаров/услуг/депозитов для одного или нескольких пользователей (в том числе и при комбинированных системах налогооблажения)

12. Возрастные ограничения (продажа товаров/услуг, авторизация, запуск приложений)

13. X-отчет по эквайринговому терминалу

14. Добавление отчетов в избранное с настроенными пользовательскими фильтрами

15. Создание дополнительных полей в профиле пользователя

16. Оплата Online-методами прямо из менеджера c возможностью отправки платежной ссылки пользователю

17. Складской учет (возможность создания складов, передвижение товаров между складами, пополнение и списание товаров (инвентаризация)

18. Функционал пересчета товара на складе с возможностью полной оплаты/оплаты по себестоимости/списания недостающих позиций

19. Гибкая скидочная система: создание скидок на поминутный тариф, способ оплаты, продукты и группы продуктов, пакеты времени с возможностью комбинирования условий предоставления. Опционально скидка может быть предоставлена в виде бонусов

20. Создание скидочных групп

21. Привязка скидочных групп к группам пользователей

22. Функционал создания промокодов с привязкой к скидочной группе

23. Платное бронирование

24. Частичная оплата бронирования

25. Обновленная логика бронирования (учет активных сессии)

26. Расширение статусов бронирования

27. Бронирование нескольких устройств одновременно

28. Расширенные настройки бронирования (ограничения посадки до/после сессии, период ожидания старта резервации, разрешения на продажу пакетов времени/поминутного тарифа, минимальное и максимальное время бронирования, дефицит фактор, включение в оплату бронирования сервисного сбора, минимальный первоначальный платеж, время ожидания первого платежа, установка льготного периода отмены бронирования и суммы возврата, использование скидок и промокодов при бронировании)

29. Лог бронирования

30. Очередь ожидания для клиентов

31. Перенос настроек Gizmo Companion в Gizmo Manager

32. Обновленный дизайн Gizmo Companion

33. Обновленная логика формирования заказов

35. Перенос настроек для скинов в Gizmo Manager

36. Роли внутренних пользователей (Кассир, Собственник, Маркетолог, Администратор, Менеджер)

38. Расширенные настройки прав доступа внутренних пользователей

39. Возможность кастомизации заставки главного экрана

40. Автоматизированный возврат платежей через карту

41. Прочие визуальные улучшения и оптимизации

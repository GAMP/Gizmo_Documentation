## Client Shell

### Исправленные баги

- Пользовательские CSS-стили не загружались на экране входа.
- Пустой серый экран при запуске Client.
- Окно онлайн-пополнения депозита в некоторых случаях было недоступно.
- Возможность оплаты с депозита на стороне Client теперь не зависит от возможности оплаты с депозита на стороне Manager.
- Загруженные иконки таблицы Уровней могли ломать вёрстку.
- Пароль меню менеджера в Client не работал после обновления на v3.

### Новые функции

- Новый скин -- Grafit.

### Проблемы удобства использования

- Номер телефона клиента стирался из поля после ввода неверного пароля.

## Общее

### Новые функции

- Новые возможности программы лояльности  -- Достижения, Уровни, Челленджи.
- Серверные скрипты событий (UserLogin, UserLogout, PowerOn, PowerOff в папке `batch`) теперь работают на установках под Linux и Docker. Для Linux и Docker используются файлы `.sh` вместо Windows-файлов `.bat`.
- Добавлена возможность настраивать пробрасываемые порты в self-hosted Docker. Порты и имя хоста теперь используются как подсказки для генерации целевого URL сервера.

## Companion

### Исправленные ошибки

- Проблема фискализации с принтерами ШТРИХ: чек не печатался, так как номер телефона пользователя не сопоставлялся корректно.
- Не было возможности отключить интеграцию с фискальным провайдером в Companion.

##  Web Manager

### Исправленные ошибки

- Маркированный товар можно было создать без штрихкода.
- Код телефона KZ не устанавливался на странице профиля пользователя (окно контактной информации).
- Способ оплаты «Депозит» в некоторых случаях был доступен для заказа с маркированными и немаркированными товарами одновременно.
- Исправлена работа горячих клавиш (Ctrl+S, Ctrl+O, Ctrl+L).
- Некоторые действия из подменю хоста на странице управления не вызывались.
- Сумма скидки в некоторых случаях не передавалась в  чек.
- Оператор мог продать маркированный товар нефискальным способом даже при включённой фискализации.
- Исправлены ошибки UI/UX при настройке временных диапазонов для пакетов времени и обычных товаров.
- В некоторых случаях не работало автоосвобождение гостей. Исправлено.
- Не работал автологин гостя.
- Смену нельзя было открыть, если фискальные настройки ранее менялись.
- Исправлена проблема с часовыми поясами в отчётах.
- Медленная загрузка списка товаров на странице POS -- Продажи.
- Оператор мог выбрать удалённые товары в качестве призов (карточка челленджа).
- Исправлены наиболее частые проблемы с Ctrl+A (Выделить всё).
- В некоторых случаях нельзя было создать способы оплаты из-за некорректной проверки значений.
- Покупка пакетов времени не учитывалась в статистике достижений.

- Вкладка «Склад» на странице «Магазин» перенесена в конец списка вкладок.
- Изменён порядок полей «Мобильный телефон» и «Дополнительный телефон» в карточке создания пользователя.
- Исправлен UI области пользователей на странице POS -- Продажи.
- Символ «∞» не отображался на карте, если у пользователя скидка 100 %.
- Логин пользователя не отображался на странице лицензии.
- Некоторые подписи в меню настроек не показывали полный текст при наведении.
- Добавлены переводы для некоторых полей.
- Изменён перевод кнопки «Принять» в диалоге возврата платежа.
- Обязательные поля не выделялись при создании элемента челленджа.
- Все группы политик в карточке профиля безопасности были развёрнуты по умолчанию.
- Логотип достижения не заполнял круг в карточке достижения.

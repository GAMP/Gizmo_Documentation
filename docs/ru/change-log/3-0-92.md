## Общее

### Новые функции

- Linux-версия Gizmo.
- Docker-версия Gizmo.
- Поддержка базы данных PostgreSQL.
- Web-версия Gizmo Manager (v3).
- Обновлённое API (v3).
- Web-реализация удалённого доступа к клиентским пк (RemoteControl).
- Web-реализация удалённого просмотра клиентских пк (RemoteView).
- Возможность использовать несколько клубов на одном сервере (филиалы) с общей базой пользователей.
- Расширенный список политик безопасности.
- Новая система фискализации оплат (аванс, постоплата, предоплата).
- Добавление в единую корзину товаров, услуг и депозитов для одного или нескольких пользователей, в том числе при комбинированных системах налогообложения.
- Возрастные ограничения: продажа товаров и услуг, авторизация, запуск приложений.
- X-отчёт по эквайринговому терминалу.
- Добавление отчётов в избранное с настроенными пользовательскими фильтрами.
- Создание дополнительных полей в профиле пользователя.
- Оплата онлайн-методами прямо из Manager с возможностью отправить пользователю платёжную ссылку.
- Складской учёт: создание складов, перемещение товаров между складами, пополнение и списание товаров (инвентаризация).
- Пересчёт товара на складе с возможностью полной оплаты, оплаты по себестоимости или списания недостающих позиций.
- Гибкая скидочная система: скидки на поминутный тариф, способ оплаты, товары и группы товаров, пакеты времени с возможностью комбинировать условия предоставления. Скидку можно предоставить в виде бонусов.
- Создание скидочных групп.
- Привязка скидочных групп к группам пользователей.
- Создание промокодов с привязкой к скидочной группе.
- Платное бронирование.
- Частичная оплата бронирования.
- Обновлённая логика бронирования с учётом активных сеансов.
- Расширенный список статусов бронирования.
- Бронирование нескольких устройств одновременно.
- Расширенные настройки бронирования: ограничения посадки до и после сеанса, период ожидания начала брони, разрешение продажи пакетов времени и поминутного тарифа, минимальное и максимальное время бронирования, дефицит-фактор, сервисный сбор в оплате брони, минимальный первоначальный платёж, время ожидания первого платежа, льготный период отмены и сумма возврата, скидки и промокоды при бронировании.
- Журнал бронирований.
- Очередь ожидания для гостей.
- Настройки Gizmo Companion перенесены в Gizmo Manager.
- Обновлённый дизайн Gizmo Companion.
- Обновлённая логика формирования заказов.
- Поддержка продажи маркированных товаров из Gizmo Client.
- Настройки скинов перенесены в Gizmo Manager.
- Роли операторов: кассир, собственник, маркетолог, администратор, менеджер.
- Создание собственных ролей операторов.
- Расширенные настройки прав доступа операторов.
- Передача параметров пользователя и компьютера в iframe (Gizmo Client).
- Настройка заставки главного экрана.
- Автоматический возврат платежей на карту.
- Обновлённый модуль подтверждения телефона и email пользователя через сторонние сервисы. Список сервисов расширяется с помощью плагинов.
- Прочие визуальные улучшения и оптимизации.

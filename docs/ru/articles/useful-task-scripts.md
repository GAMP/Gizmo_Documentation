**Задачи** -- действия, которые Gizmo выполняет на клиентском пк автоматически: при входе или выходе гостя, при включении пк, на разных этапах запуска игры. В статье -- готовые скрипты для частых случаев.

## Как добавить скрипт

1. Откройте **Станции -> Задачи** и создайте задачу типа **Скрипт**.
2. Выберите **Тип сценария**: **Пакетный (Batch)** -- для команд из этой статьи, **Скрипт реестра** -- для `.reg`-скриптов.
3. Вставьте скрипт и включите **Скрытое выполнение задачи**.
4. Назначьте задачу:
   - на событие игрового места (**Вход пользователя**, **Выход пользователя**, **Включение компьютера**) -- на вкладке [«Активации задач»](./../usage/gizmo-manager/stations/task-activations.md);
   - на этап запуска игры (**Задачи до развертывания**, **Задачи до запуска исполняемого файла** и др.) -- на вкладке **Задачи** исполняемого файла, см. [«Карточка редактирования исполняемого файла»](./../usage/gizmo-manager/stations/prilozheniya/kartochka-redaktirovaniya-ispolnyaemogo-fayla/_index.md).

Все поля задач -- в статье [«Задачи»](./../usage/gizmo-manager/stations/zadachi.md).

> [!WARNING]
>
> Скрипты удаляют файлы и меняют настройки Windows. Проверьте пути под свои пк и сначала запустите задачу на одном пк.

## Удалить папку

```
rd /s /q "C:\Путь\к\папке"
```

Например, перед запуском игры можно удалить папку с её временными файлами.

## Удалить файл

```
del /q /f "D:\Games\Steam\steamapps\appmanifest_550.acf"
```

## Закрыть программу

```
taskkill /im "programname.exe" /f
```

Вместо `programname.exe` укажите имя процесса -- его видно в диспетчере задач на вкладке **Подробности**.

## Заблокировать сайт

Скрипт перенаправляет адреса сайтов на сам пк через файл `hosts`, и браузер не может их открыть. Назначьте задачу на событие **Вход пользователя** или **Включение компьютера**.

```
set "HOSTS=%windir%\System32\drivers\etc\hosts"
findstr /x /c:"127.0.0.1 www.example.com" "%HOSTS%" >nul || echo 127.0.0.1 www.example.com>>"%HOSTS%"
findstr /x /c:"127.0.0.1 example.com" "%HOSTS%" >nul || echo 127.0.0.1 example.com>>"%HOSTS%"
```

Замените `example.com` на нужные сайты -- по строке на каждый адрес. Проверка `findstr` не даёт добавлять одну и ту же строку при каждом запуске. Если последняя строка файла `hosts` не заканчивается переводом строки, первая запись склеится с ней -- откройте `hosts` в Блокноте и проверьте один раз.

## Скрыть панель задач

В профиле безопасности панель задач можно заблокировать от изменений, но не скрыть полностью -- см. вопрос о меню «Пуск» в [FAQ](./../faq.md). Скрыть её можно бесплатной утилитой NirCmd:

1. Скачайте [NirCmd](https://www.nirsoft.net/utils/nircmd-x64.zip) (64-бит) и на каждом клиентском пк запустите `nircmd.exe` -> **Copy To Windows Directory** -- утилита скопируется в папку Windows.
2. Создайте задачу со скриптом и назначьте её на событие **Вход пользователя**:

```
timeout 3
nircmd.exe win hide class Shell_TrayWnd
nircmd.exe win normal title gizmo
nircmd.exe win max title gizmo
```

Первая команда скрывает панель задач, две последние разворачивают окно оболочки на весь экран.

## Отключить проводник Windows

Самый жёсткий вариант: без проводника у гостя нет ни рабочего стола, ни панели задач.

1. В профиле безопасности добавьте ограничение **Имя файла** -- `explorer.exe`. Подробнее -- в инструкции [«Профили безопасности»](./../tutorials/client-shell/security-profiles.md).
2. Создайте задачу со скриптом и назначьте её на событие **Вход пользователя**:

```
taskkill /im "explorer.exe" /f
```

> [!CAUTION]
>
> Без проводника режим обслуживания работает некорректно: рабочего стола Windows не будет. Кроме того, задачи и профили, которые отключают проводник, -- частая причина чёрного экрана при запуске оболочки, см. [«Чёрный экран или долгий запуск Gizmo Client»](./../tutorials/client-shell/client-startup-troubleshooting.md).

## Отключить контроль учётных записей (UAC)

Контроль учётных записей Windows (UAC) ограничивает права программ, пока администратор их не подтвердит. Gizmo Server, работающему как служба, и Gizmo Client для части функций нужны права администратора, поэтому UAC рекомендуется отключить на всех пк с Gizmo -- и на сервере, и на клиентских пк.

Скрипт реестра (тип сценария **Скрипт реестра**):

```
Windows Registry Editor Version 5.00

[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System]
"EnableLUA"=dword:00000000
```

Вручную: нажмите **Win + R**, введите `regedit`, сделайте резервную копию реестра (**Файл -> Экспорт**), откройте раздел `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System` и задайте параметру **EnableLUA** значение `0`.

После изменения перезагрузите пк. Чтобы снова включить UAC, задайте **EnableLUA** значение `1`.

## Изменить длительность всплывающих уведомлений

Сколько секунд Windows показывает уведомления (в том числе уведомление Gizmo об окончании времени):

```
REG add "HKCU\Control Panel\Accessibility" /v "MessageDuration" /t REG_DWORD /d "10" /f
```

Вместо `10` укажите нужное число секунд.

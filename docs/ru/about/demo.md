## Gizmo manager

Чтобы познакомиться с Gizmo до установки, можно подключиться к общему демо-стенду -- серверу Gizmo, который уже развёрнут и настроен. Ставить базу данных и сервер не нужно.

Адрес демо-стенда `cloud3.gizmopowered.tech`. Данные для входа можно получить в [поддержке](./support.md).

> [!WARNING]
>
> - Демо-стенд общий: им одновременно пользуются другие клубы. Не вводите на нём реальные данные -- аккаунты лаунчеров, данные гостей, пароли.
> - Часть функций на демо-стенде может не работать, например удалённое управление пк.
> - На демо-стенд нельзя подключать игровые пк.

Когда будете готовы установить Gizmo у себя -- см. инструкцию [«Быстрый старт»](./../instalation/quick-install.md).

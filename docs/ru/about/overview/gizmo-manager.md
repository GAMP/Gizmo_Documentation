**Gizmo Manager** -- приложение, в котором выполняется большинство работ с системой Gizmo, и главное рабочее место оператора клуба.



## <icon code="info" /> Кратко

| | |
|---|---|
| **Где работает** | В браузере на любом устройстве: открывается по адресу сервера |
| **Кто использует** | Операторы и администраторы клуба |
| **Что нужно для работы** | Установленный [Gizmo Server](./gizmo-server.md) и учётная запись оператора |

> [!NOTE]
>
> Полноценного десктопного приложения для Gizmo V3 нет -- используется веб-архитектура, которая позволяет управлять клубом с любого устройства, где есть браузер. Страницу Gizmo Manager можно установить из браузера как приложение -- подробнее в инструкции [«Gizmo Manager как приложение»](./../../tutorials/gizmomanager-as-an-app.md).

## <icon code="list-checks" /> Что можно делать

-  **Обслуживать зал** -- сажать гостей, следить за занятостью мест и временем на карте, ставить в очередь, бронировать места.

-  **Продавать товары и услуги** -- пробивать время и товары на кассе, принимать оплату, вести депозиты.

-  **Настраивать клуб** -- компьютеры и терминалы, ассортимент магазина, акции и скидки.

-  **Работать с отчётностью** -- анализировать данные в отчётах, фиксировать ошибки в журнале, вести учёт товаров на складе.

**Gizmo Companion** - вспомогательная программа для **Gizmo Server**.

## Назначение

Gizmo Companion необходим для:

-  Исполнения широковещательных команд внутри локальной сети (таких как WoL).

-  Обеспечения связи с локально подключенным POS оборудованием (кассы, эквайринговые терминалы, QR-дисплеи, сканеры штрих-кодов и QR-кодов, денежных ящиков).

-  Обеспечения связи с принтерами.

-  Обеспечения связи с RFID-считывателями.

-  Обеспечения функции передачи файлов.

## Принцип работы

Gizmo Companion по своей сути является программой посредником между Gizmo Manager и локально установленным оборудованием.

Рекомендуется установка как минимум одного Gizmo Companion внутри локальной сети управляемых устройств.

В большинстве случаев Gizmo Companion устанавливается на компьютер оператора.

## Минимальные системные требования

Для установки Gizmo Companion необходима ОС Windows 10/11 или Windows server 2019 и выше.

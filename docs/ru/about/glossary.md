Короткие определения терминов, которые встречаются в базе знаний Gizmo. Подробности -- по ссылкам.

## Программы

| Термин | Что это |
|---|---|
| **Gizmo Server** | Главный компонент: ведёт учёт времени и денег, следит за игровыми местами и гостями, хранит настройки. Должен работать постоянно -- как служба Windows или консольное приложение. См. [«Gizmo Server»](./overview/gizmo-server.md) |
| **Gizmo Manager** | Рабочее место оператора и администратора: зал, продажи, настройки, отчёты. Открывается в браузере, можно работать с нескольких устройств одновременно. См. [«Gizmo Manager»](./overview/gizmo-manager.md) |
| **Gizmo Client** | Оболочка на игровых пк: заменяет рабочий стол Windows и даёт гостю доступ к играм, магазину и своему счёту. См. [«Gizmo Client»](./overview/gizmo-client.md) |
| **Gizmo Companion** | Связывает сервер с кассовым оборудованием точки продаж и др. См. [«Gizmo Companion»](./overview/gizmo-companion/_index.md) |
| **База данных** | Хранит все данные клуба: гостей, балансы, цены, историю продаж. Gizmo работает с Microsoft SQL Server или PostgreSQL. См. [«Базы данных»](./../instalation/gizmo/self-hosted/databases/_index.md) |

## Люди и места

| Термин | Что это |
|---|---|
| **Пользователь** | Постоянный гость с учётной записью. Хранит купленные пакеты, депозит, бонусные баллы, личные файлы. См. [«Аккаунты клиентов»](./../tutorials/staff/user-accounts-guide.md) |
| **Гость (гостевая учётная запись)** | Разовый гость без регистрации. Учётная запись создаётся автоматически и попадает в гостевую группу по умолчанию группы станций. Неиспользованные пакеты и депозит гостевой записи пропадают при закрытии баланса |
| **Оператор** | Сотрудник клуба с учётной записью для работы в Gizmo Manager. Учётная запись оператора не может использоваться как учётная запись гостя. См. [«Карточка оператора»](./../configure/operators-and-permissions/operators/operators-card.md) |
| **Станция (хост)** | Игровое место, за которым сидит гость: компьютер с Gizmo Client или терминал |
| **Терминал** | Игровое место без Gizmo Client -- консоль, бильярдный стол и т. п. Создаётся вручную. См. [«Как добавить консоль или другое игровое место»](./../tutorials/hosts-operations/add-terminal.md) |
| **Филиал** | Отдельный клуб в сети, которая работает на одном сервере. См. [«Несколько клубов на одном сервере»](./../tutorials/operations/multiple-clubs-setup.md) |
| **Касса** | Точка продаж, к которой привязан Companion и кассовое оборудование. См. [«Как подключить Companion и настроить кассу»](./../tutorials/sales/register/companion-and-register.md) |

## Группы и профили

| Термин | Что это |
|---|---|
| **Группа пользователей** | Набор правил для гостей: чем платить за время, к каким станциям есть доступ, кредит, скидки, бонусные баллы. Гость состоит только в одной группе. См. [«Группы пользователей»](./../tutorials/staff/user-groups.md) |
| **Группа станций** | Объединяет игровые места одной зоны: задаёт для них группу приложений, профиль безопасности, тему оформления. Станция состоит только в одной группе и обязательно должна в неё входить: без группы Gizmo Client не подключится к серверу |
| **Группа приложений** | Набор приложений, доступных гостю. Назначается группе станций или группе пользователей |
| **Слой карты** | Схема расположения мест на **Карте**, например этаж или зона. Место может быть на нескольких слоях. См. [«Как работать с картой клуба»](./../tutorials/operations/reading-the-map.md) |
| **Тариф** | Правила оплаты времени: почасовая ставка, стартовый и минимальный взносы, шаги и расписания на разные часы недели. См. [«Тарификация»](./../tutorials/sales/pricing/tariffs-guide.md) |
| **Профиль безопасности** | Набор ограничений Windows для гостя: скрытые диски, запрещённые программы, политики. См. [«Профили безопасности»](./../tutorials/client-shell/security-profiles.md) |

## Сеансы

| Термин | Что это |
|---|---|
| **Сеанс пользователя** | Время от входа гостя в систему до выхода. Пересадка на другое место сеанс не прерывает. У гостя одновременно может быть только один сеанс |
| **Приостановленный сеанс** | Сеанс, для которого команда входа уже отправлена на станцию, а станция ещё не подключилась к серверу: выключена или загружается. Такой сеанс отмечается восклицательным знаком |
| **Ожидающий сеанс** | Сеанс на станции, которая аварийно потеряла связь с сервером. Если связь вернулась, сеанс продолжается; иначе он закрывается по истечении времени ожидания -- см. [«Оболочка»](./../configure/client/shell.md) |
| **Расчётный период** | Период начисления за время: начинается со входа гостя и заканчивается, когда выставлен счёт за время -- автоматически или через **Закрыть баланс**. Если гость снова войдёт до этого, например после перезагрузки пк, период продолжится и стартовый взнос не возьмётся повторно. См. [«Счета»](./../configure/finance/invoices.md) |

## Деньги

| Термин | Что это |
|---|---|
| **Счёт** | Список купленных позиций. Бывает неоплаченным, частично или полностью оплаченным. Товары и пакеты попадают в счёт в момент продажи, а поминутное время -- при закрытии баланса |
| **Товар** | Позиция магазина. Цена -- в деньгах, баллах или в том и другом |
| **Пакет времени** | Товар, который содержит игровые минуты. Может иметь срок действия и ограничения по группам станций и времени. См. [«Пакеты времени»](./../tutorials/sales/pricing/time-packages-guide.md) |
| **Набор** | Несколько товаров и (или) пакетов, которые продаются как одна позиция, обычно дешевле, чем по отдельности |
| **Депозит** | Деньги, которые гость внёс на свой счёт. Ими можно оплачивать покупки и время по тарифу |
| **Баланс** | Состояние расчётов с гостем: депозиты минус неоплаченные счета и время. Отрицательный баланс -- долг. См. [«Время, депозит и баланс»](./../articles/billing-faq.md) |
| **Бонусные баллы** | Внутренняя валюта клуба: начисляются за покупки и время, тратятся на товары и пакеты. См. [«Бонусные баллы для клиентов»](./../tutorials/loyalty/loyalty-program.md) |
| **Способ оплаты** | Чем оплачивается покупка: наличные, карта, депозит, баллы, онлайн-оплата. См. [«Как настроить способы оплаты»](./../tutorials/sales/register/payment-methods.md) |
| **Кредит** | Разрешение группе пользователей покупать или играть в долг. См. [«Как включить постоплату»](./../tutorials/staff/postpay.md) |
| **Закрыть баланс** | Расчёт с гостем: выставляется счёт за время, гость оплачивает все неоплаченные счета любыми способами, его сеанс закрывается |
| **Аннулирование счёта** | Отмена продажи. Аннулируется только весь счёт целиком; при этом оплату можно вернуть |
| **Смена** | Рабочий период оператора на кассе. Все операции на кассе после открытия смены относятся к ней. См. [«Как управлять сменами в менеджере»](./../tutorials/operations/shifts.md) |
| **Фискальный чек** | Чек, который печатает касса и передаёт в налоговую. См. [«Фискализация чеков в РФ»](./../articles/fiscalization.md) |

## Приложения

| Термин | Что это |
|---|---|
| **Исполняемый файл** | Ярлык запуска приложения в оболочке: путь, аргументы, развёртывания, ЛФП, лицензии, задачи. См. [«Что происходит при запуске приложения»](./../articles/app-launch-sequence.md) |
| **Личные файлы пользователя (ЛФП)** | Папки с пк гостя (например, сохранения игр), которые Gizmo хранит на сервере и возвращает гостю на любом пк. См. [«Как сохранять прогресс игр гостей между сеансами»](./../tutorials/client-shell/personal-files.md) |
| **Личное хранилище** | Виртуальный диск гостя, файлы которого лежат на сервере |
| **Развёртывание** | Копирование файлов игры с сервера на клиентский пк перед запуском. См. [«Развёртывание -- как работает и частые вопросы»](./../articles/deployment-faq.md) |
| **Профиль лицензий** | Набор клубных аккаунтов лаунчера, которые Gizmo выдаёт гостям. См. [«Как настроить клубные аккаунты в лаунчерах»](./../tutorials/client-shell/club-licenses.md) |
| **Задача** | Действие, которое Gizmo выполняет автоматически по событию: скрипт, запуск программы, перенаправление папки, уведомление. См. [«Полезные скрипты для задач»](./../articles/useful-task-scripts.md) |
| **Переменная** | Псевдоним пути или значения в формате `%имя%`. См. [«Переменные»](./../configure/server/variables/_index.md) |

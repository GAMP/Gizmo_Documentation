Позволяет искать по Gizmo Manager. Доступны для поиска:

-  Клиенты

-  Игровые места

-  Товары

-  Пакеты времени

Доступные кнопки:

-  Для игровых мест:

   -  **Вход в систему** -- позволяет войти в выбранный аккаунт пользователя на этом устройстве.

   -  **Включить режим администратора** -- включает режим администратора (полный доступ) на этом устройстве.

-  Для пользователей:

   -  **Вход в систему** -- позволяет войти в выбранный аккаунт пользователя на выбранном устройстве.

   -  **Закрыть баланс** -- деавторизует клиента с игрового места и закрывает все его счета для оплаты.

   -  **Депозит** -- пополнить депозит выбранного клиента.

   -  **Продажи** -- открыть раздел продаж с выбранным пользователем.

-  Для товаров -- нажатие по товару открывает карточку его настроек.

-  Для пакетов времени -- нажатие по пакету открывает карточку его настроек.

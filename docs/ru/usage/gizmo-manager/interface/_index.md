Раздел описывает постоянные элементы Gizmo Manager -- те, что видны на любой странице приложения, в каком бы разделе оператор ни находился.

Интерфейс разделён на три части. Слева, во всю высоту, -- панель навигации по разделам. Сверху -- узкая строка с полем поиска по центру, значком уведомлений и меню оператора справа. Всё остальное пространство страницы занимает содержимое выбранного раздела.

Статические элементы интерфейса позволяют совершать следующие действия:

-  переключаться между разделами при помощи панели навигации;

-  быстро находить гостя, станцию или товар в строке поиска, не заходя в соответствующий раздел;

-  видеть запросы помощи от гостей и новые заказы в момент их появления в уведомлениях;

-  управлять собственной учётной записью оператора -- сменить пароль, изменить тему или выйти из системы.

## Из чего состоит

-  [Панель навигации](./navigation-panel.md) -- вертикальная полоса вдоль левого края. Содержит четырнадцать разделов приложения, от «Карты» до «Заказов». Текущий раздел подсвечен.

-  [Поиск](./search.md) -- поле в верхней части экрана по центру. Ищет по четырём типам записей сразу: клиенты, игровые места, товары и пакеты времени. Из результатов поиска можно сразу выполнить действие -- например, посадить гостя за машину или пополнить его депозит.

-  [Уведомления](./notifications.md) -- значок колокольчика в правом верхнем углу, слева от имени оператора. Открывает окно с двумя разделами: события системы и запросы помощи от гостей. Рядом с названием каждого показано количество.

-  [Меню оператора](./operator-menu.md) -- имя учётной записи в правом верхнем углу. Открывает список действий: смена пароля, переключение светлой и тёмной темы, выход из системы.

-  [Виджет поддержки](./support-widget.md) -- средство связи с технической поддержкой Gizmo.

Gizmo Manager --  приложение, в котором выполняется большинство работ с системой Gizmo, и главное рабочее место оператора клуба.

Приложение открывается в браузере по адресу сервера. Интерфейс устроен одинаково на всех страницах: слева панель навигации по разделам, сверху строка с поиском, уведомлениями и меню оператора, в центре -- содержимое выбранного раздела.

> [!IMPORTANT]
> 
> Настройки подключения Gizmo Manager можно узнать в разделе -- [настройки сети](./../../configure/server/network.md).

## Что можно делать в приложении

Работа оператора в Manager сводится к нескольким постоянным задачам:

-  **Обслуживать зал** -- сажать гостей, следить за занятостью мест и временем на [Карте](./map/_index.md), ставить в [Очередь](./ochered.md), когда мест не осталось, [Бронировать](./../../configure/policies/reservations.md) места для клиентов.

-  **Производить** **продажу товаров и услуг** -- пробивать время и товары на [Кассе](./tochka-prodazh/_index.md), принимать оплату, вести депозиты.

-  **Настраивать клуб** -- конфигурировать компьютеры и терминалы в [Станциях](./stations/_index.md), вести ассортимент в [Магазине](./magazin/_index.md), запускать акции и скидки в [Маркетинге](./marketing.md).

-  **Формировать** **и собирать отчётность** -- анализировать данные в [Отчётах](./otchety/_index.md), фиксировать ошибки в [Журнале](./monitoring.md), ввести учёт товаров на [Складе](./magazin/warehouses.md).

## Из чего состоит приложение

Все страницы Manager устроены по одной схеме, поэтому общие элементы описаны отдельно -- в разделе [Интерфейс](./interface/_index.md):

-  [Панель навигации](./interface/navigation-panel.md) -- слева, является основным навигатором между разделами приложения.

-  [Поиск](./interface/search.md) -- вверху по центру. Позволяет найти необходимую информацию: посмотреть клиентов, станции, товары и пакеты времени.

-  [Уведомления](./interface/notifications.md) -- вверху справа, сообщают о заказах, запросах помощи и событиях.

-  [Меню оператора](./interface/operator-menu.md) -- в правом верхнем углу, смена пароля, темы и выход.

> [!NOTE]
> 
> Вход в приложение Gizmo Manager и авторизация оператора описаны на странице [Экран входа в систему](./login-screen.md).

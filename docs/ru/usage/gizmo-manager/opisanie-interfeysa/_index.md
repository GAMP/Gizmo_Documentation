Интерфейс Gizmo Manager состоит из трёх основных элементов: верхней панели, боковой навигации и рабочей области.

## Верхняя панель

В верхней части интерфейса расположены:

-  **Поиск** - строка поиска для быстрого нахождения нужного раздела или элемента.

-  **Уведомления** - иконка колокольчика. При нажатии открывается панель уведомлений с двумя вкладками:

   -  **Уведомлений** - системные уведомления.

   -  **Запросы** - входящие запросы на помощь от пользователей.

-  **Меню оператора** - имя текущего оператора. При нажатии открывается меню с действиями: закрыть смену, изменить пароль, переключить тему, выйти.

## Навигационное меню

В левой части интерфейса расположено вертикальное меню для перехода между разделами Gizmo Manager:

-  **Карта** - визуальная карта расположения хостов.

-  **Станции** - управление хостами.

-  **Касса** - точка продаж.

-  **Пользователи** - управление пользователями.

-  **Бронирования** - управление бронированиями.

-  **Мониторинг** - мониторинг состояния хостов.

-  **Журналы** - журналы событий.

-  **Отчёты** - финансовые и статистические отчёты.

-  **Очередь** - очередь ожидания хостов.

-  **Маркетинг** - маркетинговые инструменты.

-  **Магазин** - управление товарами и продажами.

-  **Управление** - управление хостами и задачами.

-  **Настройки** - настройки системы.

-  **Заказы** - управление заказами.

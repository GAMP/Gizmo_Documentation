Раздел «Маркетинг» собирает всё, чем клуб удерживает гостей: новости на экранах, скидки, соревновательные механики и акции. Настройки отсюда попадают в Gizmo Client, то есть гость видит их прямо на игровой машине.

Раздел открывается кнопкой <cmd text="Маркетинг"/> в левом меню и разделён на вкладки.

## Что где настраивается

-  **Новости** -- объявления, которые гость видит в клиенте. У каждой новости есть название, признак публикации, даты начала и окончания показа и ссылка, по которой можно перейти за подробностями. Создаются кнопкой <cmd text="Создать новость"/>.

-  **Каналы** -- источники, по которым новости раскладываются: например, отдельно общеклубные объявления и отдельно сообщения для конкретного зала.

-  **Достижения** -- награды, которые гость получает за игровые события.

-  **Лестница** -- рейтинговая таблица гостей.

-  **Испытания** -- задания, за выполнение которых полагается награда.

-  **Скидки** -- правила снижения цены.

-  **Скидочные группы** -- объединения скидок, которые назначаются группам гостей целиком, а не по одной.

-  **Акции** -- временные предложения, ограниченные сроком.

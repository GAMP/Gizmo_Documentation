order: 1
title: Компьютеры
---

Раздел позволяет управлять подключаемыми клиентскими пк. Устройства появляются здесь автоматически при первом подключении к серверу, либо могут быть добавлены вручную.

-  Редактировать -- открывает карточку редактирования выбранного устройства.

-  Удалить -- удаляет выбранные устройства.

-  Создать компьютер -- создает карточку клиентского пк.

![](./kartochka-reda.png){width=1919px height=1079px}

Данная карточка открывается при ручном создании нового или редактировании существующего терминала.

-  Имя -- название терминала в Gizmo.

-  Номер -- номер терминала в Gizmo.

-  Слоты -- доступное количество клиентов, которые могут быть авторизованы на этом терминале.

-  Филиал -- филиал, к которому привязан терминал.

-  Группа станций -- группа, в которую входит терминал. От этого зависит стоимость почасовой оплаты, разрешения для пакетов времени (если настроено) и другие.

-  Слои карты -- слои, на которых будет доступен этот терминал.

-  Контроллер -- контроллер, привязанный к этому терминалу.

order: 7

Раздел отвечает за настройку приложений, которые пользователи видят в оболочке. Приложение состоит из карточки приложения и одного или нескольких исполняемых файлов -- разных вариантов его запуска.

-  **Редактировать** -- открывает [карточку редактирования](./kartochka-redaktirovaniya-prilozheniya.md) выбранного приложения.

-  **Удалить** -- удаляет выбранные приложения.

-  **Создать категорию приложений** -- создаёт категорию. Категория визуально разделяет приложения по подразделам в оболочке -- например, «Игры» и «Лаунчеры» -- и указывается в карточке приложения.

-  **Создать приложение** -- создаёт приложение и открывает карточку его редактирования.

Карточка открывается при создании нового профиля лицензий или редактировании существующего. Позволяет указать и использовать клубные лицензии для исполняемых файлов. Тип лицензии зависит от лаунчера -- поддерживаются не все лаунчеры.

> [!WARNING]
>
> Карточка не откроется, если на сервере не включён плагин лицензий. Откройте <cmd text="Настройки"/> -> <cmd text="Сервер"/> -> <cmd text="Плагины"/> и убедитесь, что включён плагин **BaseLmPlugin**. Если он отключён -- включите его и обязательно перезапустите сервер и Gizmo Manager.

При создании карточки нужно выбрать лаунчер, для которого будет создана лицензия. Сменить лаунчер после создания профиля нельзя -- потребуется создать новый профиль.

-  **Battle.NET** -- игровой лаунчер Battle.NET.

-  **Command Line** -- лицензионный ключ передаётся исполняемому файлу приложения как параметр командной строки.

-  **EA Desktop** -- игровой лаунчер Electronic Arts (бывший Origin). Перед добавлением каждый аккаунт нужно один раз подготовить -- см. инструкцию [«Как настроить клубные аккаунты в лаунчерах»](./../../../../../tutorials/client-shell/club-licenses.md).

-  **Epic** -- игровой лаунчер Epic Games.

-  **Instance** -- ограничивает число одновременных пользователей: каждый запущенный экземпляр приложения на клиентском пк занимает одну лицензию.

-  **Process** -- ключ устанавливается с помощью сторонней утилиты, например программы командной строки.

-  **Registry** -- ключ хранится в одном параметре реестра Windows.

-  **Registry Import** -- ключ задаётся содержимым `.reg`-файла: вставьте текст файла целиком.

-  **Riot** -- игровой лаунчер Riot Games.

-  **Steam** -- игровой лаунчер Valve.

-  **UBI Uplay** -- игровой лаунчер Ubisoft.

Выбирайте тип по тому, как приложение хранит ключ или данные лицензии.

Поля профиля лицензий отличаются в зависимости от лаунчера. Рассмотрим их на примере Steam.

-  **Название** -- наименование профиля лицензий.

-  **End session when process tree exits** -- если включено и в поле **Ignored processes in tree** указан процесс (например, `cs2.exe`), при завершении этого процесса лаунчер автоматически закроется, а лицензия освободится.

-  **Ignored processes in tree** -- процессы, при завершении которых лаунчер закрывается, а лицензия освобождается. Указывайте точное название процесса, которое можно проверить в диспетчере задач Windows. Несколько процессов перечисляются через `;`.

-  **Grace period after tree exit** -- сколько секунд Gizmo ждёт после выхода из игры, прежде чем закрыть лаунчер и освободить лицензию.

-  **Лицензионные ключи** -- аккаунты для лицензии, добавляются кнопкой <cmd text="+ Добавить ключ лицензии"/>:

   -  **Username** -- логин учётной записи.

   -  **Password** -- пароль учётной записи.

   -  **Account ID** -- идентификатор учётной записи Steam. Больше не используется, поле можно оставить пустым.

-  После добавления ключа появляется строка с ним:

   -  **Хост** -- ПК, к которому можно привязать эту лицензию; в этом случае она будет открываться только на нём. Если ПК не выбран, лицензия динамически распределяется между клиентскими ПК.

   -  **Включить** -- доступен ли лицензионный ключ для использования.

## Обновление плагина лицензий

Лаунчеры регулярно меняют экраны входа, поэтому плагин лицензий **BaseLmPlugin** периодически обновляется. Обычно он обновляется вместе с Gizmo Server -- см. инструкцию [«Как обновить Gizmo»](./../../../../../tutorials/operations/update-gizmo.md).

Если поддержка Gizmo пришлёт исправленную версию плагина отдельно, замените его вручную:

1. Сохраните резервную копию текущего файла `C:\Program Files\NETProjects\Gizmo Server\plugins\BaseLmPlugin.dll`.
2. Остановите Gizmo Server -- см. [«Как перезапустить сервер Gizmo»](./../../../../../tutorials/operations/server-restart.md).
3. Замените `BaseLmPlugin.dll` новым файлом. Не оставляйте старый файл в папке `plugins` -- даже под другим именем.
4. Откройте **Свойства** нового файла и, если внизу есть отметка о блокировке файла, снимите её.
5. Запустите Gizmo Server, перезапустите Gizmo Manager и Gizmo Client на клиентских пк.

> [!WARNING]
>
> Заменяйте плагин вручную только по указанию поддержки Gizmo.

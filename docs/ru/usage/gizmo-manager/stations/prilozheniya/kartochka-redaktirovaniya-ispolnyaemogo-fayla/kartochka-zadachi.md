title: Карточка задачи
---

Карточка открывается при создании новой задачи или редактировании существующей. Задачи -- это скрипты, уведомления или другие действия, которые Gizmo выполнит при наступлении указанного события.

При создании карточки нужно выбрать тип задачи:

-  **Процесс** -- запуск определённого процесса на клиентском ПК.

-  **Перенаправление папки** -- создание символической ссылки (Junction) на клиентском ПК.

-  **Скрипт** -- выполнение скрипта на выбранном языке.

-  **Уведомление** -- показ уведомления клиенту на экране.

От выбранного типа зависит набор полей.

## Процесс

-  **Имя** -- название задачи.

-  **Имя файла** -- путь к процессу или его название в системе, по которому он будет запущен.

-  **Аргументы** -- ключи запуска процесса, если они есть.

-  **Рабочий каталог** -- рабочая папка процесса.

-  **Дождаться завершения задачи** -- пока процесс не завершится, другие задачи и события не будут выполняться.

-  **Скрытое выполнение задачи** -- задача выполняется в фоне, невидимо для клиента. Если процесс открывает свои окна или приложения, они всё равно будут видны. Рекомендуем включать.

## Перенаправление папки

-  **Имя** -- название задачи.

-  **Путь до перенаправляемой папки** -- путь, на месте которого будет создано Junction-соединение.

-  **Путь до папки назначения** -- папка, где реально хранятся файлы; на неё указывает симлинк, созданный по пути из поля **Путь до перенаправляемой папки**.

-  **Удалить перенаправляемую папку** -- удалить ли папку с тем же названием, что уже существует по пути из поля **Путь до перенаправляемой папки**.

## Скрипт

-  **Имя** -- название задачи.

-  **Тип сценария** -- язык и способ запуска скрипта:

   -  **Пакетный (Batch)** -- синтаксис, используемый в .bat файлах.

   -  **VB скрипт** -- язык Visual Basic.

   -  **Auto it скрипт** -- язык AutoIt.

   -  **Скрипт реестра** -- синтаксис скриптов реестра, позволяет изменять ключи реестра.

-  **Скрипт** -- код самого скрипта.

-  **Дождаться завершения задачи** -- пока скрипт не завершится, другие задачи и события не будут выполняться.

-  **Скрытое выполнение задачи** -- задача выполняется в фоне, невидимо для клиента. Рекомендуем включать.

## Уведомление

-  **Имя** -- название задачи.

-  **Заголовок** -- заголовок уведомления у клиента.

-  **Сообщение** -- текст самого уведомления у клиента.

-  **Ожидать подтверждения** -- уведомление не исчезнет с экрана, пока клиент его не закроет.

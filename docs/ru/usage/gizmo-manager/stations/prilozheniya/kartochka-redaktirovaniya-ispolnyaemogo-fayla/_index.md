title: Карточка редактирования исполняемого файла
---

Карточка открывается при создании нового исполняемого файла в приложении или редактировании существующего. Состоит из нескольких вкладок.

## Главная

-  **Доступность** -- филиалы, в которых будет доступно приложение.

-  **Визуальные опции** -- оформление исполняемого файла:

   -  **Подпись** -- название ярлыка в оболочке при наведении на карточку приложения.

   -  **Описание** -- описание ярлыка при открытии деталей приложения.

   -  **Изображение** -- иконка исполняемого файла при наведении на карточку приложения. Соотношение 1:1, рекомендуется 256×256 px.

-  **Параметры исполняемого файла** -- сами параметры ярлыка:

   -  **Путь к исполняемому файлу** -- путь к .exe или другому исполняемому файлу на клиентском ПК.

   -  **Аргументы** -- ключи запуска, если исполняемый файл их поддерживает.

   -  **Рабочий каталог** -- рабочая папка исполняемого файла. Обычно совпадает с папкой, в которой он находится.

-  **Организация параметров запуска** -- дополнительные параметры запуска:

   -  **Auto Launch** -- запускает исполняемый файл сразу после завершения предварительных действий (профили развёртывания, задачи и т. д.). Если выключено, клиенту нужно нажать дважды: первый раз -- чтобы выполнить предварительные действия, второй -- чтобы подтвердить запуск.

   -  **Monitor Children** -- собирает данные об использовании приложения для отображения в отчётах.

   -  **Terminate Children** -- завершает любой процесс, запущенный исполняемым файлом, как только сам исполняемый файл завершает работу.

   -  **Multirun** -- позволяет запускать несколько экземпляров одного и того же исполняемого файла повторным нажатием.

   -  **Quick Launch** -- добавляет исполняемый файл в панель быстрого доступа на главном экране клиента.

   -  **Ignore Execution Limit** -- разрешает запуск этого приложения, даже если уже работает другое. Игнорирует ограничение на одновременный запуск нескольких приложений из <cmd text="Настройки"/>.

   -  **Shell Execute** -- позволяет системе самой выбрать режим выполнения приложения при запуске.

   -  **Исполняемые режимы** -- метки исполняемого файла, удобные для настройки ограничений и сбора данных.

## Личные файлы

Вкладка позволяет прикрепить к исполняемому файлу личные файлы пользователей (ЛФП) -- функцию, которая сохраняет указанные папки с клиентского ПК на сервере и восстанавливает их при запуске приложения или входе в систему на любом ПК клуба. Полезно для хранения игровых сохранений и их синхронизации между игровыми местами и филиалами.

-  **Выберите личный файл** -- прикрепляет уже существующий ЛФП, если такие созданы.

-  <cmd text="+ Создать новый личный файл"/> -- создаёт новый ЛФП и открывает [карточку его редактирования](./lichnye-fayly-polzovateley.md).

## Развёртывания

Вкладка позволяет прикрепить к исполняемому файлу профили развёртывания -- функцию, которая обновляет папку на клиентском ПК файлами из исходной папки (обычно расположенной на сервере). Развёртывание сравнивает папку-источник и папку-назначение и копирует только отличающиеся файлы, а при необходимости удаляет на клиенте те файлы, которых больше нет в источнике. Подходит для обновления игр на клиентских ПК и развёртывания любых файлов и папок.

-  **Выберите развёртывание** -- прикрепляет уже существующий профиль развёртывания, если такие созданы.

-  <cmd text="+ Создать новую установку"/> -- создаёт новый профиль развёртывания и открывает [карточку его редактирования](./razvertyvaniya.md).

## Лицензии

Вкладка позволяет привязать к исполняемому файлу клубные лицензии. Их тип зависит от лаунчера -- поддерживаются не все лаунчеры.

-  **Стратегия резервирования лицензий** -- как лицензии распределяются между клиентами при запуске:

   -  **Первая доступная** (по умолчанию) -- резервируется первый свободный ключ, начиная с самого верхнего набора лицензий. Если ни в одном из указанных наборов нет свободной лицензии, резервирование не удастся.

   -  **По одному из каждого** -- резервируется по одной свободной лицензии из каждого набора. Если хотя бы в одном из указанных наборов нет свободной лицензии, резервирование не удастся.

-  **Набор лицензий**:

   -  **Выберите лицензию** -- прикрепляет уже существующий профиль лицензий, если такие созданы.

   -  <cmd text="+ Создать новую лицензию"/> -- создаёт новый профиль лицензий и открывает [карточку его редактирования](./kartochka-licenziy.md). Карточка не откроется, если на сервере не включён плагин лицензий -- подробнее в предупреждении в статье о карточке лицензии.

## Задачи

Вкладка позволяет выбрать, создать и назначить на события задачи -- скрипты, уведомления или другие действия, которые Gizmo выполнит при наступлении указанного условия.

-  **Выберите задачу** -- прикрепляет уже созданную задачу к выбранному событию.

-  <cmd text="+ Создать новую задачу"/> -- создаёт новую задачу и открывает [карточку её редактирования](./kartochka-zadachi.md).

-  Доступные события:

   -  **Задачи до развёртывания** -- выполняются до начала развёртывания файлов приложения.

   -  **Задачи до выдачи лицензий** -- выполняются до назначения клиентскому ПК лицензии.

   -  **Задачи до запуска исполняемого файла** -- выполняются перед стартом исполняемого файла, к которому привязаны.

   -  **После завершения работы исполняемого файла** -- выполняются после завершения процесса, запущенного исполняемым файлом.

После создания задачи выберите её в поле **Выберите задачу** для нужного события.

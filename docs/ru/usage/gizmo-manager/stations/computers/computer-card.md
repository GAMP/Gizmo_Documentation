title: Карточка редактирования компьютера
---

![](./computer-card.png){width=1919px height=1079px}

Карточка открывается при ручном создании нового пк или редактировании существующего.

-  **Название** -- имя пк, отображается в списке станций, на карте клуба и в результатах поиска.

-  **Номер** -- порядковый номер пк в Gizmo.

-  **Имя хоста** -- имя пк в системе Windows. Если в <cmd text="Настройки"/> -> <cmd text="Сеть"/> включена функция **Восстанавливать имена хостов**, Gizmo назначает это имя для пк в Windows при каждом подключении.

-  **MAC адрес** -- физический адрес сетевой карты пк. Используется, чтобы опознавать устройство при смене IP и для отправки Wake On LAN.

-  **IP адрес** -- текущий адрес пк в локальной сети. Отображается только если пк включён и подключён к серверу.

-  **Версия** -- версия Gizmo Client на этом пк. Отображается только при активном подключении.

-  **Филиал** -- филиал, в котором отображается этот пк.

-  **Группа станций** -- группа, к которой привязан этот пк. Определяет стоимость почасовой оплаты, доступные пакеты времени и применяемый профиль безопасности.

-  **Слои карты** -- слои, на которых пк отображается в разделе <cmd text="Карта"/>.

-  **Контроллер** -- контроллер, привязанный к пк. Требуется для удалённого включения и выключения HDMI-сигнала на этом месте.

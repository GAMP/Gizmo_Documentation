Раздел предназначен для привязки задач к событиям на игровом месте. Экран разделён на четыре блока -- по одному на каждое событие; в скобках указано количество назначенных задач.

## События

-  **Включение компьютера** -- ПК запустился и подключился к серверу.

-  **Вход пользователя** -- пользователь авторизовался на игровом месте.

-  **Выход пользователя** -- пользовательский сеанс завершён.

-  **Выключение компьютера** -- ПК уходит в отключение.

## Назначение задачи

В каждом блоке доступны:

-  **Выберите задачу** -- назначает событию одну из созданных [задач](./zadachi.md).

-  **Создать новую задачу** -- открывает создание задачи; после сохранения она становится доступна для назначения.

Одному событию можно назначить несколько задач.

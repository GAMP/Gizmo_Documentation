Вкладка содержит список всех учётных записей клуба и открывается первой при переходе в раздел. По каждой записи видно, кто это, в какой группе состоит, сколько у него денег, времени и баллов и находится ли он сейчас за станцией.

Вкладка предназначена для повседневной работы с гостями: найти нужного, посадить за станцию и снять с неё, пополнить депозит, оформить продажу, выдать и снять бан, удалить и восстановить запись. Отсюда же запускаются два служебных инструмента -- поиск дубликатов и массовая загрузка клиентов из файла.

## Кнопки создания

Расположены в правом верхнем углу.

-  <cmd text="Создать пользователя"/> -- открывает пустую [карточку пользователя](./user-card.md).

-  <cmd text="Аудит пользователей"/> -- открывает окно поиска дубликатов, описано ниже.

-  <cmd text="Импорт пользователей"/> -- открывает окно загрузки списка из файла, описано ниже.

## Действия над выбранными записями

Строка над списком. Слева -- счётчик отмеченных записей, справа от него -- значки действий. Пока галочками не отмечена ни одна запись, действия недоступны.

-  **Вход в систему** -- сажает выбранного пользователя за станцию. Сочетание клавиш `CTRL+L`.

-  **Выход из системы** -- завершает сеанс пользователя на станции. Сочетание клавиш `CTRL+ALT+L`.

-  **Забанить** -- закрывает пользователю доступ к станциям.

-  **Удалить** -- убирает учётную запись из списка.

Значок <cmd text="..."/> открывает полный перечень действий, включая те, которых нет среди значков.

-  **Вход в систему**, **Выход из системы** -- то же, что и значки.

-  **Продажи** -- переводит на оформление продажи выбранному пользователю. Сочетание клавиш `CTRL+S`.

-  **Депозит** -- пополнение денежного депозита. Сочетание клавиш `CTRL+D`.

-  **Другие действия** -- **Забанить**, **Разбанить**, **Удалить**, **Жесткое удаление**, **Восстановить**.

-  **Оборудование** -- оборудование, выданное пользователю.

## Счётчики

Стоят в правой части строки действий и показывают состояние базы целиком, независимо от выбранного фильтра.

-  **Депозиты** -- сумма денег на депозитах всех пользователей.

-  **Пользователи** -- общее количество учётных записей.

-  **Забаненые** -- количество записей с активным баном.

-  **Удалённый** -- количество удалённых записей.

## Фильтры состояния

Кнопки над таблицей. Выбранная кнопка подсвечена, одновременно действует только одна.

-  **Все** -- показывает все записи.

-  **Активные** -- только пользователи, находящиеся в сеансе.

-  **Гости** -- записи гостевых групп.

-  **Забаненые** -- записи с активным баном.

-  **Удалённые** -- удалённые записи.

## Поиск и фильтры

Два значка справа над таблицей открывают дополнительную строку поиска и фильтров.

-  **Поиск** -- поле поиска по списку.

-  **Быстрый фильтр** -- то же состояние записи, что и кнопки над таблицей. Текущее значение показано рядом с названием фильтра.

-  **Группа пользователей** -- оставляет записи выбранной группы.

Заданные условия снимаются ссылкой <cmd text="Очистить все"/>, строка закрывается кнопкой <cmd text="Отмена"/> справа.

## Список пользователей

Каждая строка -- одна учётная запись. Двойное нажатие на строку открывает [карточку пользователя](./user-card.md).

-  **Имя пользователя** -- логин, под которым гость входит в клиентскую оболочку.

-  **Имя**, **Фамилия** -- личные данные из карточки.

-  **Группа пользователей** -- [группа](./../user-groups/_index.md), к которой отнесена запись.

-  **Сеанс** -- текущий сеанс пользователя.

-  **Хост** -- станция, за которой пользователь находится сейчас.

-  **Слот** -- слот станции, занятый пользователем.

-  **Баланс** -- денежный баланс счёта. Отрицательное значение означает задолженность.

-  **Время** -- остаток оплаченного времени.

-  **Депозиты** -- сумма на депозите.

-  **Баллы** -- накопленные баллы лояльности.

-  **Применяется** -- что списывается при работе за станцией.

-  **Возраст** -- возраст пользователя.

-  **Создано** -- дата и время создания записи.

-  **Состояние** -- состояние учётной записи.

Записи разбиты на страницы, переход между ними -- стрелками в правом нижнем углу.

## Окно «Аудит пользователей»

Открывается кнопкой <cmd text="Аудит пользователей"/>. Ищет учётные записи, заведённые на одного и того же человека дважды: сравнивает записи по контактам и, если сказано, объединяет найденные пары.

В окне три блока.

-  **Проверять дубликаты по** -- признаки сравнения: **Номер телефона** и **Электронная почта**. Оба включены по умолчанию, можно оставить один.

-  **Код страны телефона** -- обязательное поле. Пока оно не заполнено, окно сообщает «Поле обязательно для заполнения!», а запуск недоступен. Код нужен, чтобы привести номера к единому виду перед сравнением.

-  **Действие** -- **Найти дубликаты**: только обнаружить и сообщить, данные не меняются; **Объединить дубликаты**: обнаружить и объединить автоматически.

Внизу окна две кнопки: <cmd text="Отмена"/> закрывает окно без изменений, <cmd text="Запустить аудит"/> начинает проверку.

## Окно «Импорт пользователей»

Открывается кнопкой <cmd text="Импорт пользователей"/>. Загружает сразу много учётных записей из таблицы Excel.

-  **Код страны телефона** -- обязательное поле, как и в аудите. Используется для приведения номеров к единому виду при проверке и импорте.

-  **Область загрузки** -- перетащите в неё файл или выберите его ссылкой **обзор**. Поддерживаются форматы `.xls`, `.xlsx`, `.xlsm`, `.xlsb`, `.xlt`, `.xltx`, `.xltm`, размер файла -- до 50 МБ.

Под областью загрузки стоит напоминание, что обязательные поля пользователей проверяются перед началом импорта.

Внизу окна две кнопки: <cmd text="Отмена"/> закрывает окно, <cmd text="Продолжить"/> переходит к загрузке выбранного файла.

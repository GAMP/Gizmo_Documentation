Карточка содержит все правила одной группы пользователей: что её участникам разрешено, чем они могут платить за время, к каким станциям допущены и какая скидка к ним применяется.

Карточка открывается двойным нажатием на строку в [списке групп](./../user-groups/_index.md), кнопка <cmd text="Создать группу"/> открывает её пустую форму. Экран разделён на две колонки.

## Имя

Первый блок левой колонки. Содержит единственное поле **Имя** -- название группы, под которым она видна в списках и в карточках пользователей.

## Переопределения

Три отдельных флажка левой колонки. Каждый из них позволяет группе перебить настройку, заданную на уровне станции.

-  **Переопределение группы приложений** -- участникам группы назначается своя [группа приложений](./../../stations/gruppy-prilozheniy/_index.md), а не та, что задана группе станций.

-  **Переопределение профиля безопасности** -- к участникам применяется свой [профиль безопасности](./../../stations/profili-bezopasnosti/_index.md).

-  **Переопределение возрастного рейтинга** -- к участникам применяется своё возрастное ограничение.

## Необходимая информация о пользователе

Блок левой колонки. Задаёт, какие данные обязательно заполнить в карточке участника группы. Значок карандаша открывает окно **Управление необходимой информацией о пользователях**.

В окне перечислены десять полей карточки, каждое со своим флажком: **Имя**, **Фамилия**, **Дата рождения**, **Электронная почта**, **Адрес**, **Телефон**, **Мобильный**, **Почтовый индекс**, **Страна**, **Пол**. Отмеченные становятся обязательными для участников группы.

Ссылка **Выбрать все** отмечает сразу все поля, справа от неё стоит счётчик вида «выбрано 0 из 10». Внизу окна кнопки <cmd text="Отмена"/> и <cmd text="Сохранить"/>.

## Настройки

Нижний блок левой колонки. Таблица из двух колонок: **Функция** и **Включить**, каждая строка -- отдельный переключатель.

-  **Личное хранилище** -- участникам группы выделяется личная папка на станции, файлы в которой сохраняются между сеансами.

-  **Вход из менеджера** -- оператор может посадить участника за станцию из Gizmo Manager.

-  **Вход с хоста** -- участник может войти сам, с клиентской машины.

-  **Кнопка выхода пользователя из системы** -- в клиентской оболочке участнику показывается кнопка выхода.

## Категория пользователей

Первый блок правой колонки. Поле **Используется для** задаёт, кому группа предназначена, и принимает одно из трёх значений:

-  **Только для зарегистрированных** -- в группу попадают клиенты с учётной записью;

-  **Зарегистрированные и гости** -- и те, и другие;

-  **Только для гостей** -- клиенты без собственной учётной записи.

## Группа скидок

Второй блок правой колонки. Поле **Назначение скидки** привязывает к группе скидочную группу из раздела [Маркетинг](./../../marketing.md). Значок креста рядом с полем снимает привязку.

## Выставление счетов

Третий блок правой колонки. Таблица **Разрешенные источники времени** с колонкой **Включить** задаёт, чем участники группы могут оплачивать время за станцией.

-  **Пакет времени** -- разрешено списывать время с купленных пакетов.

-  **Депозиты** -- разрешено списывать деньги с депозита.

Если выключены оба переключателя, участникам группы платить за время нечем.

## Кредит

Четвёртый блок правой колонки. Показывает текущее правило кредита; при отсутствии кредита стоит надпись «Нет кредита». Значок карандаша открывает окно **Кредит**.

В окне два независимых переключателя, у каждого одни и те же три значения.

-  **Разрешить кредит на продажу** -- можно ли продавать участнику группы в долг.

-  **Разрешить использовать кредит** -- можно ли участнику расходовать выданный кредит.

Значения: **Нет кредита** -- в долг нельзя; **Неограниченно** -- предела нет; **Ограниченный** -- в долг можно до заданной суммы.

Внизу окна кнопки <cmd text="Отмена"/> и <cmd text="Сохранить"/>.

## Лояльность

Пятый блок правой колонки. Показывает привязанную программу лояльности; при её отсутствии стоит надпись «Без программы лояльности». Значок карандаша открывает окно **Лояльность** с выбором из трёх вариантов:

-  **Без программы лояльности** -- баллы участникам группы не начисляются;

-  **Деньги** -- баллы начисляются за потраченные деньги;

-  **Время** -- баллы начисляются за проведённое за станцией время.

Внизу окна кнопки <cmd text="Отмена"/> и <cmd text="Сохранить"/>.

## Доступ

Нижний блок правой колонки. Таблица **Группа хостов** с колонкой **Включить**: перечислены все [группы станций](./../../stations/station-groups/_index.md) клуба, переключатель напротив каждой открывает или закрывает участникам группы доступ к её станциям.

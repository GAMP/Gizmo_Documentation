Вкладка содержит перечень групп, по которым распределены учётные записи клуба. Группа -- это набор общих правил: какие источники времени разрешены её участникам, к каким станциям они допущены, какая скидка им положена и что им доступно в клиентской оболочке.

Вкладка предназначена для того, чтобы задавать правила не каждому гостю отдельно, а сразу целой категории: постоянным клиентам, гостям без учётной записи, участникам акции. Отсюда группы заводятся, правятся и удаляются.

Новая группа создаётся кнопкой <cmd text="Создать группу"/> в правом верхнем углу. Двойное нажатие на строку открывает [карточку группы](./user-group-card.md).

## Список групп

-  **Имя** -- название группы.

-  **Пользователи** -- сколько учётных записей входит в группу.

-  **Личное хранилище** -- выделено ли участникам группы личное хранилище файлов на станции.

-  **Гость** -- отмечает гостевую группу, в которую попадают клиенты без собственной учётной записи.

-  **Группа по умолчанию** -- отмечает группу, в которую попадают вновь созданные записи.

-  **Группа скидок** -- скидочная группа, привязанная к этой группе пользователей. Скидочные группы заводятся в разделе [Маркетинг](./../../marketing.md).

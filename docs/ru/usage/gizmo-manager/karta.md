Карта — визуальное отображение всех хостов в виде схемы расположения. Позволяет быстро отслеживать состояние хостов и выполнять действия над ними.

## Интерфейс карты

В верхней части страницы отображается название текущей схемы расположения (layout). Переключаться между схемами можно с помощью вкладок.

Панель инструментов содержит счётчик выбранных хостов (**Выбрано**) и кнопки быстрых действий над выбранными хостами.

В правой части панели инструментов отображается сводная статистика:

-  **Всего** - общее количество хостов.

-  **Доступно** - количество свободных хостов.

-  **Занято** - количество хостов с активными сессиями.

-  **Скоро освободится** - количество хостов, сессия на которых скоро завершится.

Также доступно переключение между режимом сетки и списком.

## Контекстное меню

При нажатии на хост или на кнопку **«...»** открывается контекстное меню с действиями, сгруппированными по категориям.

### Пользователи

-  **Вход в систему** (`CTRL+L`) - открывает диалог **«Расширенный вход»** для входа пользователя на хост. В диалоге отображается информация о хосте, доступны фильтры по типу (все, пользователи, гости) и поле поиска пользователя или гостя.

-  **Выход из системы** (`CTRL+ALT+L`) - выход пользователя с хоста.

-  **Переместить пользователя** - перемещение пользователя на другой хост.

### Касса

-  **Продажи** (`CTRL+S`) - открытие окна продаж для выбранного хоста.

-  **Депозит** (`CTRL+D`) - пополнение депозита пользователя.

-  **Другие действия** - дополнительные кассовые операции:
   -  **Закрыть баланс** (`CTRL+B`) - закрытие баланса пользователя.
   -  **Возврат депозита** (`CTRL+ALT+D`) - возврат средств на депозит.
   -  **Варианты выставления счетов** - дополнительные варианты выставления счёта.

### Хосты

-  **Выключить** (`CTRL+ALT+T`) - выключение хоста.

-  **Включить** (`CTRL+T`) - включение хоста.

-  **Перезагрузить** (`CTRL+R`) - перезагрузка хоста.

-  **Оболочка** - управление оболочкой Gizmo Client:
   -  **Включить режим администратора** - переключение оболочки в режим администратора.
   -  **Выключить режим администратора** - выключение режима администратора.

-  **Перезапустить оболочку** - перезапуск Gizmo Client на хосте.

-  **Система** - системные действия над хостом:
   -  **Заблокировать** - блокировка ввода на хосте.
   -  **Разблокировать** - снятие блокировки ввода.
   -  **В рабочем состоянии** - отметка хоста как рабочего.
   -  **Не в рабочем состоянии** - перевод хоста в режим обслуживания.
   -  **Вкл. безопасность** - включение профиля безопасности.
   -  **Откл. безопасность** - отключение профиля безопасности.

-  **Удаленный доступ** - подключение к хосту через удалённое управление.

-  **Просмотр** - просмотр экрана хоста без управления.

### Оборудование

-  **Оборудование** - управление оборудованием хоста:
   -  **Получить** - получение оборудования пользователем.
   -  **Выдать** - выдача оборудования пользователю.

-  **Карточка пользователя** - просмотр карточки текущего пользователя на хосте.

## Статусы хостов

Цвет рамки карточки хоста отображает его сетевой статус:

-  **Не в сети** - хост недоступен (серая рамка).

-  **В сети** - хост доступен (зелёная рамка).

-  **Занят** - на хосте активна сессия (красная рамка).

-  **Режим администратора** - на хосте включён режим администратора (синяя рамка).

Дополнительные статусы отображаются в виде иконок на карточке хоста:

-  🔴 **Забронирован** - хост забронирован.

-  🟡 **Осталось 5 минут** - сессия на хосте скоро завершится.

-  **Гость зарезервировал** - хост зарезервирован гостевым пользователем.

-  **Защита отключена** - профиль безопасности отключён на хосте.

-  **Не в рабочем состоянии** - хост переведён в режим обслуживания.

-  **Заблокирован** - ввод на хосте заблокирован.

-  **Выдано оборудование** - пользователю выдано оборудование.

Для просмотра легенды статусов нажмите иконку **«i»** в правой части панели инструментов.

## Режимы отображения

Карта поддерживает два режима отображения хостов, переключаемых кнопками в правой части панели инструментов:

-  **Сетка** - отображение хостов в виде карточек на схеме расположения. В данном режиме можно перемещать хосты по карте. Кнопка **«Сбросить»** возвращает расположение хостов к исходному виду.

-  **Список** - отображение хостов в виде таблицы со следующими столбцами: **Номер**, **Имя**, **Группа**, **Пользователь**, **Сеанс**, **Осталось времени**, **Баланс**, **Применяется**, **Следующее бронирование**, **Статусы**.

Вкладка содержит перечень позиций, доступных к продаже. Заведённый здесь товар отображается на экране [продаж](./../../tochka-prodazh/prodazhi.md), а при соответствующей настройке -- и в клиентской оболочке.

## Список товаров

-  **Имя** -- наименование позиции.

-  **Штрихкод** -- код для сканера.

-  **Статус** -- доступность позиции к продаже.

-  **Награда** -- баллы, начисляемые пользователю за покупку.

-  **Стоимость** -- закупочная стоимость позиции.

-  **Цена** -- цена продажи.

-  **Тип** -- товар или услуга.

-  **Группа** -- товарная группа, определяющая размещение позиции на экране кассира.

## Действия

-  **Создать товар** -- открывает пустую [карточку товара](./kartochka-produkta.md).

-  **Удалить** -- удаляет выбранные позиции.

Двойное нажатие на строку открывает карточку существующего товара.

## Связанные разделы

Остатки по позициям ведутся на складе -- см. вкладки «Остатки товаров» и «Движение товаров» раздела [«Магазин»](./../_index.md). Группы, по которым товары распределяются на экране кассира, задаются на вкладке «Группы товаров».

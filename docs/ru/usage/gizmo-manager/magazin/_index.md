Раздел предназначен для ведения ассортимента и складского учёта: здесь заводятся товары и их группы, ведутся остатки и оформляются складские операции. Раздел разделён на восемь вкладок, первой открывается «Склады».

Раздел открывается кнопкой <cmd text="Магазин"/> в левом меню.

## Вкладки

Ассортимент:

-  [**Склады**](./warehouses.md) -- места хранения товара. По каждому складу выводятся имя, тип, филиал и статус. Создаются кнопкой <cmd text="Создать склад"/>.

-  **Товары** -- перечень позиций, доступных к продаже. По каждой выводятся имя, штрихкод, статус, награда, стоимость, цена, тип и группа.

-  **Наборы** -- позиции, объединяющие несколько товаров и продаваемые как одна.

-  **Группы товаров** -- разделы, по которым товары распределяются на экране кассира.

Складской учёт:

-  **Движение товаров** -- история операций с остатками: дата, наименование позиции, тип транзакции, начальное и конечное количество, склад и оператор.

-  **Пересчет склада** -- инвентаризации. По каждой выводятся дата, склад, филиал, оператор, тип, количество записей, недостача и излишек.

-  **Складские операции** -- операции с остатками: дата, филиал, склад, тип, оператор, статус и количество.

-  **Остатки товаров** -- текущее количество по каждой позиции с указанием группы, типа, штрихкода, филиала и склада.

## Как это связано между собой

Товар заводится на вкладке **Товары** и относится к одной из **групп товаров**; группа определяет, в какой вкладке позиция окажется на экране [продаж](./../tochka-prodazh/prodazhi.md). Количество товара учитывается на **складе**: продажа списывает позицию, приход пополняет остаток, **пересчёт склада** приводит учётные данные в соответствие с фактическими.

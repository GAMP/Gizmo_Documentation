На карточке достижения присутствуют следующие поля для заполнения:

## Общие параметры

- **Включено** - статус активности достижения. Если неактивно - достижение не учитывается
- **Скрыть от клиентов** - если включено, то данное достижение не отображается в интерфейсе Gizmo Client. Пользователи могут получить данное достижение, но они не будут видеть его в интерфейсе Gizmo Client
- Название - название достижения, отображается как в интерфейсе Gizmo Client, так и в интерфейсе Gizmo Manager. Является обязательным полем для заполнения. Максимальная длина символов - 45.
- Описание - описание достижения. В данное поле необходимо вводить подробную информацию о достижении, так как данное поле также отображается в Gizmo Client.
- Медиа - в данное поле закружается бейдж достижения. Поддерживаемые форматы: JPEG, PNG, SVG. Настоятельно рекомендуется использовать формат SVG, так как это векторный формат и он будет одинаково хорошо отображаться во всех интерфейсах системы.

## Параметры достижения

- Сигнал - главные параметр на который реагирует достижение. Сигнал - триггерный параметр, по которому система ведет расчет достижения. Доступны следующие параметры достижений:
  - Внесенные депозиты - сумма, внесенных депозитов пользователем
  - Время в приложениях - суммарное время запуска того или иного приложения пользователем
  - Время в играх - суммарное время запуска той или иной игры пользователем
  - Входы в систему - суммарное количество логирований пользователя в Gizmo Client
  - Дней с момента регистрации - количество дней с момента регистрации пользователя
  - Заработанные баллы - сумма заработанных пользователем баллов
  - Посещения - суммарное количество посещений пользователя
  - Потраченные баллы - суммарное количество потраченных баллов пользователем
  - Потраченные деньги - суммарное количество потраченных денег пользователем (в том числе и внесенных депозитов)

  > [!TIP]
  >
  > Вы можете создать собственные сигналы через систему плагинов, например, сигнал «Подписка на канал в социальной сети»
- Период - период расчета достижений. Данный параметр отвечает за период рассчета сигналов достижения.  Доступны следующие периоды:
  - День
  - Неделя (календарный)
  - Месяц (календарный)
- Целевое значение  - значение сигнала. Для каждого сигнала используется свой показатель (Например, для сигнала «Заработанные баллы» в целевом значении указывается минимальное количество заработанных пользователем для получения данного достижения)
- Макс. выполнений за период - максимально возможное количество достижений, которые пользователь может получить за указанный период.



  > [!IMPORTANT]
  >
  > **Пример**
  >
  > Создано достижение со следующими параметрами:
  >
  > **Параметры джостижения**\
  > Название: «Ежедневное пополнение депозита»\
  > Сигнал: «Внесенные депозиты»\
  > Период: «День»\
  > Целевое значение: 1000 у.е.\
  > Макс. выполнений за период: 1\
  > \
  > **Результат**\
  > Если клиент за день пополнит депозит на сумму, превышающую 1000 у.е., то он получит данное достижение. Если сумма пополнений за день будет 2000 у.е., то у клиента все равно будет только одно достижение, так как это ограничено параметром «Макс. выполнений за период».

## Рассписание выполнения

Вы можете ограничить период, в котором будут учитываться достижения пользователей.

Если расписание не заполнено - учитываются все дни.

Для некоторых сигналов, например, для сигнала «Дней с момента регистрации», выбор рассписания недоступен.

Для добавления рассписания нажмите на кнопку «Добавить день» и выберите день недели для добавления.

По умолчанию добавляется весь указанный день. Чтобы ограничить времянные рамки выполнения сниимите галочку «Весь день» и укажите «Время начала» и «Время окончания».

Для удаления дня недели нажмите на иконку с корзиной в строке дня недели.

> [!IMPORTANT]
>
> **Пример**
>
> Вы настраиваете достижение «Ранняя пташка» с сигналом «Время игры»  и вам необходимо, чтобы данное достижение учитывалось только в будние дни и только в утренние часы. В таком случае вам нужно добавить все будние дни и на каждый день установить времянное ограничение. В таком сценарии достижение будет зачитываться пользователю только в том случае, если оно будет выполняться в утренние часы по будним дням.

## Фильтры

Помимо рассписания выполнения достижений вы можете также добавить дополнительную фильтрацию условий выполнения.

Для добавление фильтра нажмите кнопку «Добавить фильтр»

Для редактирования фильтра нажмите иконку «карандаш» в строке фильтра

Для удаления фильтра нажмите иконку «корзина» в строке фильтра

Для каждого сигнала набор возможных фильтров отличается

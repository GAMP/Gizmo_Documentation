Карточка содержит все параметры одного достижения: общие сведения, условие получения, расписание и фильтры.

Карточка открывается кнопкой <cmd text="Добавить достижение"/> на вкладке **Достижения**, а для существующего достижения -- двойным нажатием на его бейдж или кнопкой <cmd text="Редактировать"/> в превью.

## Общие параметры

-  **Включено** -- статус активности достижения. Неактивное достижение не учитывается.

-  **Скрыть от клиентов** -- если включено, достижение не отображается в интерфейсе Gizmo Client. Пользователи могут получить это достижение, но не будут видеть его в интерфейсе Gizmo Client.

-  **Название** -- название достижения, отображается в интерфейсах Gizmo Client и Gizmo Manager. Обязательное поле. Максимальная длина -- 45 символов.

-  **Описание** -- описание достижения. Вводите сюда подробную информацию о достижении: это поле также отображается в Gizmo Client.

-  **Медиа** -- бейдж достижения. Поддерживаемые форматы: JPEG, PNG, SVG. Настоятельно рекомендуется использовать SVG: это векторный формат, и он одинаково хорошо отображается во всех интерфейсах системы.

## Параметры достижения

-  **Сигнал** -- главный параметр, на который реагирует достижение. Сигнал -- триггерный параметр, по которому система ведёт расчёт достижения. Доступные сигналы:

   -  **Внесенные депозиты** -- сумма депозитов, внесённых пользователем.

   -  **Время в приложениях** -- суммарное время запуска того или иного приложения пользователем.

   -  **Время в играх** -- суммарное время запуска той или иной игры пользователем.

   -  **Входы в систему** -- суммарное количество входов пользователя в Gizmo Client.

   -  **Дней с момента регистрации** -- количество дней с момента регистрации пользователя.

   -  **Заработанные баллы** -- сумма заработанных пользователем баллов.

   -  **Посещения** -- суммарное количество посещений пользователя.

   -  **Потраченные баллы** -- суммарное количество баллов, потраченных пользователем.

   -  **Потраченные деньги** -- общая сумма денег, потраченных пользователем (в том числе внесённых депозитов).

   > [!TIP]
   >
   > Вы можете создать собственные сигналы через систему плагинов, например сигнал «Подписка на канал в социальной сети».

-  **Период** -- период расчёта сигналов достижения. Доступные периоды:

   -  **День**.

   -  **Неделя** (календарная).

   -  **Месяц** (календарный).

-  **Целевое значение** -- значение сигнала. Для каждого сигнала используется свой показатель: например, для сигнала **Заработанные баллы** в целевом значении указывается минимальное количество баллов, которое пользователь должен заработать для получения этого достижения.

-  **Макс. выполнений за период** -- максимальное количество достижений, которые пользователь может получить за указанный период.

   > [!IMPORTANT]
   >
   > **Пример**
   >
   > Создано достижение со следующими параметрами:
   >
   > **Параметры достижения**\
   > Название: «Ежедневное пополнение депозита»\
   > Сигнал: **Внесенные депозиты**\
   > Период: **День**\
   > Целевое значение: 1000 у.е.\
   > Макс. выполнений за период: 1\
   > \
   > **Результат**\
   > Если клиент за день пополнит депозит на сумму, превышающую 1000 у.е., он получит это достижение. Если сумма пополнений за день составит 2000 у.е., у клиента всё равно будет только одно достижение -- это ограничено параметром **Макс. выполнений за период**.

## Расписание выполнения

Расписание ограничивает период, в котором учитываются достижения пользователей.

Если расписание не заполнено, учитываются все дни.

Для некоторых сигналов, например **Дней с момента регистрации**, выбор расписания недоступен.

Чтобы добавить расписание, нажмите <cmd text="Добавить день"/> и выберите день недели.

По умолчанию добавляется весь указанный день. Чтобы ограничить временные рамки выполнения, снимите флажок **Весь день** и укажите **Время начала** и **Время окончания**.

Чтобы удалить день недели, нажмите значок корзины в строке этого дня.

> [!IMPORTANT]
>
> **Пример**
>
> Вы настраиваете достижение «Ранняя пташка» с сигналом **Время в играх** и хотите, чтобы оно учитывалось только в будние дни и только в утренние часы. Для этого добавьте все будние дни и на каждый день установите временное ограничение. Тогда достижение будет засчитываться пользователю, только если оно выполняется в утренние часы по будним дням.

## Фильтры

Помимо расписания выполнения можно добавить дополнительную фильтрацию условий выполнения.

Чтобы добавить фильтр, нажмите <cmd text="Добавить фильтр"/>.

Чтобы отредактировать фильтр, нажмите значок карандаша в его строке.

Чтобы удалить фильтр, нажмите значок корзины в его строке.

Набор доступных фильтров зависит от сигнала.

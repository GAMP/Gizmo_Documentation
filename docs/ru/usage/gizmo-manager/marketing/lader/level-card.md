---
title: Карточка уровня
order: 2.5
---

При создании уровня доступны следующии параметры:

- Значек уровня. Отображается в Gizmo Client.
- Название уровня
- Целевая Группа пользователей. Пользователи, достигшие этого уровня, автоматически переводятся в эту группу.
- Описание уровня. Описание уровня доступно пользователям в Gizmo Client.



В зависимости от выбранного режима подсчета,  в каждом уровне дополнительно настраиваются следующие параметры:

#### Режим посчета - по заработанным очкам за достижения

- Порог очков. Значение очков, необходимое пользователю для получения данного уровня привелегий.

#### Режим посчета - по заработанным достижениям

- Требования. Список достижений, необходимых пользователю для получения данного уровня привелегий.

  > [!NOTE]
  >
  > Для начального уровня в режиме посчета по заработанным достижениям список достижений не указывается.

title: Карточка уровня
order: 2
---

Карточка содержит параметры одного уровня привилегий. Карточка открывается при создании уровня кнопкой <cmd text="Добавить уровень"/> или при редактировании существующего уровня.

-  **Значок уровня** -- отображается в Gizmo Client.

-  **Название уровня**.

-  **Целевая группа пользователей** -- пользователи, достигшие этого уровня, автоматически переводятся в эту группу.

-  **Описание уровня** -- доступно пользователям в Gizmo Client.

Набор дополнительных параметров уровня зависит от выбранного режима подсчёта.

## Режим подсчёта -- по заработанным очкам за достижения

-  **Порог очков** -- количество очков, необходимое пользователю для получения этого уровня привилегий.

## Режим подсчёта -- по заработанным достижениям

-  **Требования** -- список достижений, необходимых пользователю для получения этого уровня привилегий.

   > [!NOTE]
   >
   > Для начального уровня в режиме подсчёта по заработанным достижениям список достижений не указывается.

Уровни привилегий -- механизм Gizmo для привлечения и удержания пользователей.

Вкладка предназначена для настройки уровней привилегий.

## Общие положения

В Gizmo большое значение отводится [группам пользователей](./../../users/user-groups/_index.md). В частности, группа пользователей может иметь привилегии доступа к определённым группам хостов, ей может быть назначена группа скидок, ей могут быть доступны определённые игры и приложения.

Уровни привилегий позволяют настроить механику и правила, по которым пользователи перемещаются из одной группы пользователей в другую.

## Режимы подсчёта уровня привилегий

Уровень привилегий рассчитывается в одном из двух режимов: по заработанным очкам за достижения или по заработанным достижениям.

### По заработанным очкам за достижения

В этом режиме каждому [достижению](./../achievements/_index.md) присваиваются очки.

Если пользователь получил достижение, в награду ему начисляется заданное количество очков.

Для каждого уровня привилегий можно настроить количество очков, которое должно быть у пользователя, чтобы он получил этот уровень привилегий.

### По заработанным достижениям

В этом режиме для каждого уровня привилегий указывается перечень достижений, которые должны быть у пользователя, чтобы он получил этот уровень привилегий.

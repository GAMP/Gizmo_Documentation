Уровни привелегий - функционал Gizmo, позволяющий привлекать и удерживать пользователей.

На данной вкладке производится настройка Уровней привелегий.

## Общие положения

В Gizmo большое значение отводится[ группам пользователей](./../../users/user-groups/_index.md). В частности, Группа пользователей может иметь привелегии доступа к определенным группам хостов, Группе пользователей может быть назначена Группа скидок, Группе пользователей могут быть доступны определенные игры и приложения.

Уровни привелегий позволяют настроить механику и правила, при которых будут происходить перемещения пользователей из одной группы пользователей в другую.

## Режимы подсчета уровня привелегий

Расчет уровня привелегий производится в одном из двух доступных режимов:

- по заработанным очкам за достижения
- по заработанным достижениям

Разберем данные режимы подробнее.

### По заработанным очкам за достижения

В данном режиме, каждому [достижению](./../achievements/_index.md) присваиваются очки.

Таким образом, в случае, если пользователь получил достижение, в награду ему присвается выбранное количество очков.

Оператор имеет возможность настроить для каждого уровня привелений необходимое значение очков, которое необходимо иметь пользователю чтобы он получил выбранный уровень привелегий.

### По заработанным достижениям

В данном режиме, для каждого уровня привелегий указывается перечень достижений, которые необходимо иметь пользователю, чтобы он получил выбранный уровень привелегий.

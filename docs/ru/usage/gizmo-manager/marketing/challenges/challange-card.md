> [!WARNING]
>
> Испытание - это контракт (оферта), предлагаемая пользователю. Если испытание уже создано, то некоторые его параметры нельзя изменить. Поэтому, опции, доступные при создании и при редактировании испытания отличаются.

В карточке испытания доступны следующие параметры для заполнения:

- **Включено**. Статус испытания (включено/выключено)
- **Название**.
- **Скрыть от клиентов**. Статус видимости для клиентов
- **Тип окна**. Времяной диапозон в который будет действовать испытание.
  - Бессрочный.
  - С окном.
    - Начало. Дата начала действия испытания
    - Окончание. Дата окончания действия испытания
- **Требования**. Список достижений и их количество, необходимое для выполнения испытания. Для добавления требуемых достижений выберите доступные [достижения](./../achievements/_index.md) из списка, укажите их количество и нажмите кнопку «Добавить». Для удаления ранее добавленных достижений нажмите кнопку «Х» на бейдже ранее добавленного достижения.
- **Выполнения и лимиты.** В данном блоке задаются следующие ограничения:
  - **Макс. выполнений на клиента.** Параметр регулирует Максимальное количество раз, которое каждый клиент может выполнить это испытание.
  - **Максимум выполнений всего.** Максимальное количество раз, которое это испытание может быть выполнено всеми клиентами. Оставьте пустым для неограниченного количества.
- **Награды.** В данном блоке указываются награды, которые клиент получает за выполнение данного испытания. Награды могут выдаваться автоматически или по обращению на стойке оператора. Допускается добавление нескольких типов наград одновременно. Допускается добавление любого количества наград.\
  Для добавления награды укажите ее тип, дополнительные параметры и нажмите на кнопку «Добавить».\
  Для удаления награды нажмите на кнопку «Х» в бейдже с названием добавленной награды.
  - Тип награды. Тип получаемой награды, доступны следующие значения:
    - Баллы. Пользователь получает баллы за выполнение данного испытания. Количество получаемых баллов указывается оператором. Дополнительно оператор может отметить,
    - Товар.

> [!WARNING]
>
> Испытание -- это контракт (оферта), предлагаемый пользователю. Если пользователь выполнил испытание до начала его редактирования, то и после редактирования оно будет числиться у пользователя как выполненное вне зависимости от новых условий.

Карточка открывается на вкладке **Испытания**: дважды нажмите на строку с испытанием или в меню **«…»** в строке испытания выберите <cmd text="Редактировать"/>.

-  **Включено** -- статус испытания (включено/выключено).

-  **Название**.

-  **Скрыть от клиентов** -- статус видимости для клиентов.

-  **Тип окна** -- временной диапазон, в течение которого действует испытание:

   -  **Бессрочный**.

   -  **С окном** -- задаются поля:

      -  **Начало** -- дата начала действия испытания.

      -  **Окончание** -- дата окончания действия испытания.

-  **Требования** -- список достижений и их количество, необходимое для выполнения испытания. Чтобы добавить требуемые достижения, выберите доступные [достижения](./../achievements/_index.md) из списка, укажите их количество и нажмите <cmd text="Добавить"/>. Чтобы удалить добавленное достижение, нажмите значок креста на его бейдже.

-  **Выполнения и лимиты** -- блок ограничений:

   -  **Макс. выполнений на клиента** -- максимальное количество раз, которое каждый клиент может выполнить это испытание.

   -  **Максимум выполнений всего** -- максимальное количество раз, которое это испытание может быть выполнено всеми клиентами. Оставьте пустым для неограниченного количества.

-  **Награды** -- награды, которые клиент получает за выполнение испытания. Награды могут выдаваться автоматически или по обращению на стойке оператора. Можно добавить несколько типов наград одновременно и любое количество наград.

   Чтобы добавить награду, укажите её тип, дополнительные параметры и нажмите <cmd text="Добавить"/>.

   Чтобы удалить награду, нажмите значок креста на бейдже с названием добавленной награды.

   -  **Тип награды** -- тип получаемой награды. Доступные значения:

      -  **Баллы** -- пользователь получает баллы за выполнение испытания. Количество баллов указывает оператор. Дополнительно можно отметить, что баллы выдаются вручную оператором.

      -  **Товар** -- пользователь получает выбранный товар за выполнение испытания. Количество товаров указывает оператор. Дополнительно можно отметить, что товары выдаются вручную оператором.

      -  **Время** -- пользователь получает время за выполнение испытания. Количество времени указывает оператор. Дополнительно можно отметить, что время выдаётся вручную оператором.

-  **Медиа** -- изображение для испытания. Отображается в Gizmo Client.

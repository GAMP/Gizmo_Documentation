На данной вкладке оператору доступна таблица с ранее созданными испытаниями. Также на данной вкладке опреатор может создавать, удалять и редактировать испытания.

Испытания - это набор достижений, заработав которые, пользователю полагается награда.

В таблице отображается следующий набор параметров испытаний:

- Название испытания
- Статус (активный/неактивный, скрытое от клиента)
- Дата начала испытания
- Дата окончания испытания
- Доступность испытания по филиалам

На странице  также реализована возможность массового удаления испытаний, возможность поиска и фильтрации по следующим по статусу.

## Создание испытания

Для создания испытания необходимо нажать кнопку «Создать испытание» в верхнем правом углу экрана. По результату нажатия на кнопку испытани откроетка карточка испытания.

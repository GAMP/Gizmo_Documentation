---
title: Каналы
order: 0.5
---

**Каналы** -- RSS-ленты, записи из которых показываются гостям на главной странице Gizmo Client вместе с новостями клуба. Например, можно подключить ленту игровых новостей или новостей киберспорта.

Для канала указываются:

-  **Название** -- заголовок ленты, который видит гость;

-  **URL** -- адрес RSS-ленты;

-  **Максимум записей** -- сколько последних записей из ленты показывать.

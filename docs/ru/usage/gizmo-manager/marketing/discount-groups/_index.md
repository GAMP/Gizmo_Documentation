Вкладка содержит таблицу созданных групп скидок.

> [!NOTE]
>
> Группа скидок -- логическая сущность для объединения скидок. Одна скидка может быть связана с разными группами скидок.

Таблица групп скидок состоит из колонок:

-  **Имя** -- название группы скидок.

-  **Количество скидок** -- количество скидок в группе.

-  **Количество групп пользователей** -- количество групп пользователей, с которыми связана эта группа скидок.

## Поиск

На вкладке доступен поиск.

## Создание группы скидок

Чтобы создать группу скидок, нажмите <cmd text="Создать группу скидок"/> в правом верхнем углу экрана. Откроется [карточка группы скидок](./discount-group-card.md).

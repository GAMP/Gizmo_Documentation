На данной вкладке Оператору доступна таблица с ранее созданными группами скидок.

> [!NOTE]
>
> Группа скидок - логическая сущность для объединения скидок. Важно отметить, что одна скидка может быть связана с разными группами скидок.

Таблица групп скидок состоит из следующих колонок:

- **Имя**. Название группы скидок
- **Количество скидок.** Количество скидок в группе
- **Количество групп пользователей.** Количество групп пользователей с которыми связана данная группа скидок.

## Поиск

На данной вкладке доступен поиск.

## Создание группы скидок

Для создания группы скидок необходимо нажать кнопку «Создать группу скидок» в правом правом углу экрана. По результату нажатия на кнопку откроется [карточка группы скидок.](./../discounts/discount-card.md)

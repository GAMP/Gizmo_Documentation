В карточке скидки доступны следующие блоки и поля для заполнения.

## Общий блок

- **Включить скидку.** Параметр отвечающий за активизацию скидки в системе. Использовать можно только включенные скидки.
- **Имя**. Название скидки, обязательно для заполнения.
- **Описание**. Описание скидки.

## Доступность

В данном блоке настраивается доступность скидки по филиалам, а также по дате и времени.

### По филиалу

В блоке указаны названия ваших филиалов и статус доступности. По умолчанию доступность на всех филиалах отключена.

### Пользовательские диапазоны

По умолчанию, скидка доступна в любой период времени, однако в данном блоке Оператор имеет возможность включить «Диапазон дат» и указать «Дату начала» и «Дату конца» действия скидки в соответствующих полях. При заданных значениях диапазона дат скидка будет учитывать указанный период и будет доступна для применения только в указанный период дат.

Дополнительно, имеется возможность задать интервалы времени доступности скидки.

Для этого, оператору необходимо включить флаг «Диапазон времени» и добавить при помощи UI элемента «+» добавить и настроить диапазон времени.

Диапазон времени настраивается с учетом дней недели.

Для удаления диапазона времени необходимо нажать на иконку корзины напротив созданного диапазона.

## Целевые группы

Целевые группы -- это группы, на которые распространяется скидка.

Доступны следующие типы целевых групп:

- Товары
- Пакеты
- Товарные группы
- Способы оплаты
- Тарифы

Оператор может добавить несколько целевых групп одновременно, однако в таком случае необходимо обязательно указать параметр «Активация группы». Данный параметр может принимать только одно из двух значений:

- Все. Обозначает, что для применения скидки в заказе пользователя должны присутствовать все добавленные целевые группы.
- Любой. Обозначает, что для применения скидки в заказе пользователя должна быть хотя бы одна добавленная целевая группа.

Для добавления целевой группы нажмите на кнопку «Создать группу назначения» и выберите тип создаваемой целевой группы

Добавив целевую группу вы можете уточнить на что именно распространяется данная скидка при помощи UI элемента «+», либо проставив флаг «Включить все» (в таком случае, скидка будет действовать на все объекты в данной целевой группе, например, на все товары, если у вас выбрана целевая группа «Товары»).

Если вы ошиблись с добавленным объектом в целевую группу вы всегда можете удалить его через иконку корзины, расположенной напротив добавленного объекта.

Если вы ошиблись с добавлением целевой группы вы всегда можете удалить её через кнопку «Удалить группу», расположенной напротив добавленной группы.

Внутри добавленной целевой группы вы также можете заметить условия активации для объектов группы.

Условия активации для объектов группы отличаются от условий активации групп. Возможны следующие варианты:

- Все. Означает, что для активации данной Целевой группы в заказе пользователя должны присутствовать все объекты данной целевой группы.
- Любой. Означает, что для активации данной Целевой группы в заказе пользователя должен присутствовать хотя бы один объект из данной целевой группы.
- Количество. При выборе данного варианта появляется параметр «Минимальное количество». Означает, что для активации данной Целевой группы в заказе пользователя должно присутствовать «Минимальное количество» объектов из данной целевой группы.
- Сумма. При выборе данного варианта появляется параметр «Минимальная сумма». Означает, что для активации данной Целевой группы в заказе пользователя должен присутствовать объекты из данной целевой группы на сумму равную или выше заданной.

## Вознаграждение

Вознаграждение -- то, что получает пользователь, в случае выполнения условий скидки.

Тип награды:

- Бонус. Пользователь получит Бонусы за заказ. По сути, вариант кэшбэка бонусами.
- Скидка. Пользователь получит скидку

Вознаграждение может быть применено к:

- Строке заказа. В таком случае, пользователь получит скидку только на объекты, указанные в целевых группах
- Всему заказу. В таком случае пользователь получит скидку на весь заказ (не только на объекты указанные в целевых группах).

Тип расчета вознаграждения:

- Процент. Процент скидки применяемый в строке заказа/ко всему заказу.
- Фиксированный. Фиксированная сумма вознаграждения за заказ (сумма скидки или сумма начисленного бонуса).

В карточке скидки доступны следующие блоки и поля для заполнения.

## Общий блок

- **Включить скидку.** Параметр отвечающий за активизацию скидки в системе. Использовать можно только включенные скидки.
- **Имя**. Название скидки, обязательно для заполнения.
- **Описание**. Описание скидки.

## Доступность

В данном блоке настраивается доступность скидки по филиалам, а также по дате и времени.

### По филиалу

В блоке указаны названия ваших филиалов и статус доступности. По умолчанию доступность на всех филиалах отключена.

### Пользовательские диапозоны

По умолчанию, скидка доступна в любой период времени, однако в данном блокее Оператор имеет возможноть включить «Диапозон дат» и указать «Дату начала» и «Дату конца» действия скидки в соответствующих полях. При заданных значениях диапозона дат скидка будет учитывать указанный период и будет доступна для применения только в указанный период дат.

Дополнительно, имеется возможность задать интервалы времени доступности скидки.

Для этого, оператору необходимо включить флаг «Диапозон времени» и добавить при помощи UI элемента «+» добавить и настроить диапозон времени.

Диапозон времени настраивается с учетом дней недели.

Для удаления диапозона времени необходимо нажать на иконку корзины напротив созданного диапозона.

## Целевые группы

Целевые группы - это группы, на которые распространяется скидка.

Доступны следующие типы целевых групп:

- Товары
- Пакеты
- Товарные группы
- Способы оплаты
- Тарифы

Оператор может добавить несколько целевых групп одновременно, однако в таком случае необходимо обязательно указать параметр «Активация группы». Данный параметр может принимать только одно из двух значаний:

- Все. Обозначает, что для применения скидки в заказе пользователя должны присутствовать все добавленные целевые группы.
- Любой. Обозначает, что для применения скидки в заказе пользователя должна быть хотябы одна добавленная целевая группа.

Для добавления целевой группы нажмите на кнопку «Создать группу назначения» и выберите тип создаваемой целевой группы

Добавив целевую группу вы можете уточнить на что именно распространяется данная скидка при помощи UI элемента «+», либо проставив флаг «Включить все» (в таком случае, скидка будет действовать на все объекты в данной целевой группе, например, на все товары, если у вас выбрана целевая группа «Товары»).

Если вы ошиблись с добавленным объектом в целевую группу вы всегда можете удалить его через иконку корзины, расположенной напротив добавленного объекта.

Если вы ошиблись с добавлением целевой группы вы  всегда можете удалить ее через кнопку «Удалить группу», расположенной напротив добавленной группы.

Внутри добавленной целевой группы вы также можете заметить условия активации для объектов группы.

Условия активации для объектов грнуппы отличаются от условий активации групп. Возможны следующие варианты:

- Все. Означает, что для активации данной Целевой группы в заказе пользователя должны присутствовать все объекты данной целевой группы.
- Любой.  Означает, что для активации данной Целевой группы в заказе пользователя должен присутствовать хотябы один объект из данной целевой группы.
- Количество. При выборе данного варианта появляется параметр «Минимальное количество». Означает, что для активации данной Целевой группы в заказе пользователя должено присутствовать «Минимальное количество» объектов из данной целевой группы.
- Сумма. При выборе данного варианта появляется параметр «Минимальная сумма». Означает, что для активации данной Целевой группы в заказе пользователя должен присутствовать объектоы из данной целевой группы на сумму вравную или выше заданной.

## Вознаграждение

Вознаграждение - то, что получает пользователь, в случае выполнения условий скидки.

Тип награды:

- Бонус. Пользователь получит Бонусы за заказ. По сути, вариант кэшбэка бонусами.
- Скидка. Пользователь получит скидку

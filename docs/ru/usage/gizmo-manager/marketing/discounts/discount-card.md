title: Карточка скидки

Карточка содержит все условия одной скидки: где и когда она доступна, на что распространяется и что получает пользователь. Карточка открывается кнопкой <cmd text="Создать скидку"/> на вкладке **Скидки**.

## Общий блок

-  **Включить скидку** -- активирует скидку в системе. Использовать можно только включённые скидки.

-  **Имя** -- название скидки, обязательно для заполнения.

-  **Описание** -- описание скидки.

## Доступность

Блок задаёт доступность скидки по филиалам, а также по дате и времени.

### По филиалу

В блоке указаны названия ваших филиалов и статус доступности. По умолчанию доступность во всех филиалах отключена.

### Пользовательские диапазоны

По умолчанию скидка доступна в любой период времени. Чтобы ограничить срок действия, включите **Диапазон дат** и заполните поля **Дата начала** и **Дата конца**. При заданном диапазоне дат скидка доступна для применения только в указанный период.

Дополнительно можно задать интервалы времени доступности скидки.

Для этого включите **Диапазон времени**, добавьте диапазон времени кнопкой <cmd text="+"/> и настройте его.

Диапазон времени настраивается с учётом дней недели.

Чтобы удалить диапазон времени, нажмите значок корзины напротив созданного диапазона.

## Целевые группы

Целевые группы -- это группы, на которые распространяется скидка.

Доступны следующие типы целевых групп:

-  **Товары**.

-  **Пакеты**.

-  **Товарные группы**.

-  **Способы оплаты**.

-  **Тарифы**.

Можно добавить несколько целевых групп одновременно, но в этом случае обязательно укажите параметр **Активация группы**. Он принимает только одно из двух значений:

-  **Все** -- для применения скидки в заказе пользователя должны присутствовать все добавленные целевые группы.

-  **Любой** -- для применения скидки в заказе пользователя должна быть хотя бы одна добавленная целевая группа.

Чтобы добавить целевую группу, нажмите <cmd text="Создать группу назначения"/> и выберите тип создаваемой целевой группы.

В добавленной целевой группе можно уточнить, на что именно распространяется скидка: добавить объекты кнопкой <cmd text="+"/> или отметить **Включить все**. Во втором случае скидка действует на все объекты целевой группы -- например, на все товары, если выбрана целевая группа **Товары**.

Если объект добавлен в целевую группу по ошибке, удалите его значком корзины напротив этого объекта.

Если целевая группа добавлена по ошибке, удалите её кнопкой <cmd text="Удалить группу"/> напротив этой группы.

Внутри добавленной целевой группы также отображаются условия активации для объектов группы.

Условия активации для объектов группы отличаются от условий активации групп. Возможны следующие варианты:

-  **Все** -- для активации целевой группы в заказе пользователя должны присутствовать все объекты этой целевой группы.

-  **Любой** -- для активации целевой группы в заказе пользователя должен присутствовать хотя бы один объект из этой целевой группы.

-  **Количество** -- появляется параметр **Минимальное количество**. Для активации целевой группы в заказе пользователя должно присутствовать заданное в нём минимальное количество объектов из этой целевой группы.

-  **Сумма** -- появляется параметр **Минимальная сумма**. Для активации целевой группы в заказе пользователя должны присутствовать объекты из этой целевой группы на сумму, равную заданной или превышающую её.

## Вознаграждение

Вознаграждение -- то, что получает пользователь при выполнении условий скидки.

Тип награды:

-  **Бонус** -- пользователь получит бонусы за заказ. По сути, вариант кэшбэка бонусами.

-  **Скидка** -- пользователь получит скидку.

Вознаграждение может быть применено к:

-  **Строке заказа** -- пользователь получит скидку только на объекты, указанные в целевых группах.

-  **Всему заказу** -- пользователь получит скидку на весь заказ, а не только на объекты, указанные в целевых группах.

Тип расчёта вознаграждения:

-  **Процент** -- процент скидки, применяемый к строке заказа или ко всему заказу.

-  **Фиксированный** -- фиксированная сумма вознаграждения за заказ (сумма скидки или сумма начисленного бонуса).

Раздел содержит отчётность клуба: сводку по выручке и загрузке, а также журналы операций — по заказам, сменам, товарам, транзакциям, оборудованию и лицензиям. Отчёты разнесены по вкладкам, первой открывается «Обзор».

Раздел открывается кнопкой <cmd text="Отчеты"/> в левом меню.

## Обзор

Вкладка, которая открывается первой. Наверху -- выбор периода: **За день**, **За неделю**, **За месяц**, **За год**, а также **Пользовательское** для произвольного отрезка и **Больше, чем** / **Меньше, чем** для открытых границ.

Ниже расположены блоки сводки.

### Операторов

Таблица по сменам за выбранный период:

-  **Имя** -- оператор, работавший смену.

-  **График смены** -- когда смена началась и закончилась.

-  **Проданных часов** -- сколько игрового времени продано.

-  **Проданная продукция** -- выручка от товаров.

-  **Продано предложений по времени** -- выручка от пакетов времени.

-  **Продано комплектов** -- выручка от наборов.

-  **Аннулирования** -- отменённые продажи.

-  **Выплаты на входе и выходе** -- движение денег в кассе, не связанное с продажами.

-  **Итог** -- сумма по смене.

### Коэффициент использования (%)

-  **Использование AVG** -- средняя загрузка игровых мест за период.

-  **Уникальные логины участников** -- число зарегистрированных пользователей, входивших в систему.

-  **Среднее количество визитов участников в день** -- средняя посещаемость зарегистрированными пользователями.

-  **Уникальные логины для гостей** -- число гостевых входов.

-  **Среднее количество визитов гостей в день** -- средняя посещаемость гостями.

### Пользователей

-  **Всего счетов** -- количество учётных записей.

-  **Новые аккаунты** -- сколько записей заведено за период.

-  **Заблокированные аккаунты** -- сколько записей заблокировано.

### Выручка

-  **Средняя выручка** -- средние суммы отдельно по гостям и зарегистрированным пользователям.

-  **Выручка на группу** -- распределение выручки по группам пользователей.

-  **Общая выручка** -- сумма за период.

-  **Итого по финансовым показателям** -- итоговая строка сводки.

## Остальные вкладки

-  **Избранное** -- отчёты, отмеченные для быстрого доступа.

-  **Все отчеты** -- полный перечень доступных отчётов: Обзор, Приложений, Продукция, Регистрация пользователей, Сеансы, Статистика заказов, Топ пользователей, [Финансовый отчёт](./finansovyy.md), Хосты.

-  **Журнал заказов** -- история заказов.

-  **Журнал оборудования** -- что происходило со станциями и оборудованием.

-  **Журнал смен** -- открытие и закрытие смен.

-  **Журнал счетов** -- выставленные счета.

-  **Журнал товаров** -- движение товаров.

-  **Журнал транзакций** -- денежные операции.

-  **Журнал Z** -- Z-отчёты, то есть итоги закрытых смен по кассе.

-  **Запас** -- складские остатки.

-  **Лицензии** -- использование лицензий на приложения.

Вкладка «Продажи» — рабочее место кассира. Здесь собирается корзина и проводится оплата.

Экран разделён надвое: слева список товаров, разложенный по группам, справа корзина текущей продажи.

## Кому продаём

Наверху переключатель между двумя режимами:

-  **Гости** -- продажа без учётной записи, деньги просто проходят через кассу.

-  **Авторизованные** -- продажа конкретному пользователю. Так покупка попадает в его историю, может списаться с депозита и учитывается в его скидках.

Если гостя ещё нет в системе, его можно завести не выходя с экрана — кнопкой <cmd text="Создать пользователя"/>.

## Корзина

-  **Товар** -- что продаётся.

-  **Цена** -- цена за единицу.

-  **Количество** -- сколько единиц.

-  **Итого** -- сумма по строке.

Товары слева разложены по группам: вкладка **Все** показывает весь ассортимент, остальные вкладки соответствуют группам товаров, заведённым в разделе «Магазин».

## Порядок продажи

1.  Выберите режим: **Гости** или **Авторизованные**. Во втором случае укажите пользователя.

2.  Наберите корзину, выбирая товары в левой части экрана.

3.  Проверьте строки и сумму в корзине.

4.  Проведите оплату кнопкой <cmd text="Действия"/> и выберите способ расчёта.

Проведённая продажа попадает в «Журнал платежей», а её сумма — в отчёт по смене.

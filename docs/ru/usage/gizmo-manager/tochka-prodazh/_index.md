«Касса» — рабочий экран администратора: здесь продают время и товары, принимают оплату, ведут депозиты гостей и снимают отчёты по смене. Это то место, в котором сотрудник клуба проводит большую часть рабочего дня.

Раздел открывается кнопкой <cmd text="Касса"/> в левом меню.

## Вкладки

-  **Продажи** -- собственно продажа: корзина, товары, оплата.

-  **Журнал платежей** -- принятые платежи.

-  **Заказы** -- заказы, оформленные гостями.

-  **Электронные платежи** -- безналичные операции.

-  **Депозиты** -- деньги, лежащие на счетах гостей.

## Смена и отчёты по кассе

Работа кассира привязана к смене: при входе в Gizmo Manager оператор выбирает кассу, в которой будет работать, и все его продажи попадают именно в неё.

Прямо с экрана продаж доступны служебные действия:

-  <cmd text="Открыть денежный ящик"/> -- открыть ящик, не проводя продажу.

-  <cmd text="X-отчет (касса)"/> -- промежуточный отчёт по наличным без закрытия смены.

-  <cmd text="X-отчет (эквайринг)"/> -- то же по безналичным платежам.

X-отчёт можно снимать сколько угодно раз: он показывает текущее состояние кассы и ничего не закрывает.

Вкладка содержит журнал заказов клуба. В отличие от раздела «Заказы» в левом меню, где отображаются заказы в работе, здесь хранится полная история, включая закрытые и аннулированные.

## Список заказов

-  **Номер заказа** -- порядковый номер заказа.

-  **Дата** -- дата и время оформления.

-  **Пользователь** -- пользователь, оформивший заказ.

-  **Филиал** -- филиал, в котором оформлен заказ.

-  **Хост** -- игровое место, с которого поступил заказ.

-  **Оператор** -- сотрудник, обработавший заказ.

-  **Номер смены** -- смена, к которой отнесён заказ.

-  **Касса** -- касса, через которую проведён расчёт.

-  **Статус платежа** -- состояние оплаты.

-  **Статус доставки** -- состояние выдачи.

-  **Аннулирован** -- признак отмены заказа.

-  **Осталось оплатить** -- непогашенная часть суммы.

-  **Итог** -- полная сумма заказа.

Двойное нажатие на строку открывает [карточку заказа](./kartochka-zakaza.md).

## Связанные разделы

Расчёт по заказу проводится на вкладке [«Продажи»](./../prodazhi.md). Сводные данные по заказам за период доступны в разделе [«Отчеты»](./../../otchety/_index.md), вкладки «Журнал заказов» и «Статистика заказов».

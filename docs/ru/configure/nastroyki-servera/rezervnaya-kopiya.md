title: Резервная копия
---

**Резервная копия** - копия базы данных вашего Gizmo Server. Резервная копия необходима для переноса базы данных на другой сервер, либо для восстановления базы данных.

В данном разделе отображаются настройки для создания резервной копии базы данных Gizmo Server.

Доступные опции:

-  Включение/Выключение резервного копирования

-  Максимальное количество файлов резервных копий для хранения

-  Время создания резервной копии

-  Путь хранения резервной копии на сервере

## Включение/Выключение резервного копирования

По умолчанию механизм резервного копирования отключен. Для Включения необходимо нажать переключатель.

При включении переключателя дополнительные параметры резервного копирования становятся доступны.

При выключении переключателя дополнительные параметры резервного копирования становятся неактивными.

## Максимальное количество файлов резервных копий для хранения

**Максимальное количество файлов резервных копий для хранения** - целое значение, указывает количество резервных копий для хранения. По умолчанию - 10.

Например, у вас ввключен механизм резервного копирования, Максимальное количество файлов резервных копий для хранения - 10. Резервная копия создается ежедневно. После созданиия одинадцатой копии Gizmo Server автоматически удалит самую старую копию. Таким образом на сервере всегда будут 10 последних копий базы данных.

## Время создания резервной копии

**Время создания резервной копии** - время, в которое будт создана резервная копия. По умолчанию - 0:00 (в полночь).

## Путь хранения резервной копии на сервере

**Путь хранения резервной копии на сервере** - путь в файловой системе, по которому будут созданы резервные копии.

Необходимо указывать полный путь до желаемой папки. Учтите различия в построении путей, которыми обладают различные операционные системы.

> [!WARNING]
> 
> При указании пути, убедитесь что пользователь операционной системы, от имени которого запущен Gizmo Server обладает необходимыми для записи и чтения правами на указываемую вами папку.

title: Отправка отчетов
---

В данном разделе настраиваются правила автоматической доставки отчетов операторам.

В таблице отображаются все созданные правила со следующей информацией:

-  **Название** - название правила доставки.

-  **Время** - время отправки отчетов.

-  **Частота** - периодичность отправки.

-  **Включено** - статус правила (активно или отключено).

Для создания нового правила нажмите кнопку **«Создать правило доставки»** в правом углу страницы.

Для редактирования существующего правила нажмите на соответствующую строку в таблице.

title: Карточка правил доставки
---

Карточка правила доставки открывается при создании нового правила или редактировании существующего.

**Имя** - название правила доставки. Поле является обязательным для заполнения.

## Отчеты

В данном блоке выбираются отчеты, которые будут включены в рассылку.

Таблица содержит следующие столбцы:

-  **Имя** - название отчета.

-  **Подтип отчета** - подтип выбранного отчета.

Для добавления отчета нажмите **«+ Выбрать отчет»**. В открывшемся диалоге выберите нужный отчет из списка (поле обязательно для заполнения) и нажмите **«Сохранить»**.

## Планирование доставки отчетов

**Время** - время суток, в которое будет выполняться отправка отчетов.

**Тип** - периодичность отправки. Доступные варианты: ежедневно и другие периоды.

## Получателей

В данном блоке настраиваются получатели рассылки.

Таблица содержит следующие столбцы:

-  **Пользователь** - оператор, которому отправляется отчет.

-  **Метод** - способ доставки.

-  **Ценность** - адрес или идентификатор получателя (например, email).

-  **Включено** - статус получателя (активен или отключён).

Для добавления получателя нажмите **«+ Добавить получателя»**. В открывшемся диалоге выберите оператора из списка (поле обязательно для заполнения) и нажмите **«Сохранить»**.

> [!CAUTION]
> 
> Не забудьте нажать кнопку «Сохранить» для применения ваших настроек.

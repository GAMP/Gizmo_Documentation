title: Причины бана
---

В данном разделе настраиваются причины блокировки пользователей.

В таблице отображаются все созданные причины со следующей информацией:

-  **Название** - название причины бана.

-  **Описание** - описание причины бана.

Для создания новой причины нажмите кнопку **«Создать причину бана»** в правом углу страницы.

Для редактирования существующей причины нажмите на соответствующую строку в таблице.

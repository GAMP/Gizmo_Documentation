В данном разделе настраивается поведение очереди ожидания -- системы, позволяющей пользователям занимать место в очереди на хост, когда все компьютеры заняты.

## Глобальные настройки

Глобальные настройки применяются ко всем группам хостов.

**Льготный период перед входом** - после того как хост стал доступен, пользователь из очереди получает льготный период для входа в систему. Если пользователь не войдёт в течение указанного времени, он будет перемещён в конец очереди или удалён. Можно включить/выключить; задаётся продолжительность в минутах.

**Следующий по времени** - время в минутах, в течение которого следующий пользователь в очереди получает приоритет на доступный хост. Задаётся время ожидания в минутах.

**Время удаления** - время в минутах, по истечении которого неактивный пользователь автоматически удаляется из очереди. Задаётся время ожидания в минутах.

**Удаление пользователя из очереди** - при включении пользователь автоматически удаляется из всех очередей после успешного входа на хост. Можно включить/выключить.

## Очередь

В данном подразделе настраиваются параметры очереди для каждой группы хостов.

Таблица содержит следующие столбцы:

-  **Группа хостов** - группа хостов, для которой применяются настройки.

-  **Филиал** - филиал, к которому относится группа хостов.

-  **Удалить вкл.** - при включении пользователи автоматически удаляются из очереди данной группы хостов по истечении времени удаления.

-  **Включить сл.** - при включении активируется режим «Следующий по времени» для данной группы хостов.

-  **Включить п.** - при включении активируется льготный период перед входом для данной группы хостов.

## Приоритет

В данном подразделе настраивается приоритет групп пользователей в очереди. Группы с более высоким приоритетом получают место в очереди раньше остальных.

Для изменения порядка приоритета перетащите нужную группу пользователей за иконку `::` на требуемую позицию. Группы, расположенные выше в списке, имеют более высокий приоритет.

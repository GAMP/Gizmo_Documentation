В данном разделе настраиваются типы запросов о помощи, которые пользователь может отправить оператору через интерфейс Gizmo Client.

В списке отображаются все созданные типы запросов. Порядок их отображения можно изменить, перетаскивая элементы за иконку **::** слева от названия.

Для создания нового типа запроса нажмите кнопку **«Создать тип запроса помощи»** в правом углу страницы.

## Создание типа запроса

При создании нового типа запроса необходимо заполнить следующее поле:

**Название** - наименование типа запроса, которое будет отображаться пользователю в Gizmo Client. Поле является обязательным для заполнения.

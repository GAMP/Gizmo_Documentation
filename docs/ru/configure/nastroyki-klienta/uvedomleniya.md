В данном разделе отображаются настройки опвещений клиентов для Gizmo Client, а именно:

-  Оповещения об окончании времени

-  Оповещения о бронировании

## Оповещения об окончании времени

**Оповещения об окончании времени** - оповещения, которые будут показаны/озвучены клиенту по истечению оплаченного времени.

Для каждого оповещения настраиваются следующие параметры:

-  **Сообщение** - текст сообщения, которое отображается клиенту (допускается импользование перемнной времени).  Если поле не заполнено, используется уведомление по умолчанию.

-  **Минут до оповещения** - за сколько минут до истечения времени будет показано уведомление.

-  **Сворачивание окон** - при включении все открытые окна на хосте сворачиваются в момент показа уведомления.

-  **Тип уведомления** - способ оповещения пользователя. Доступные варианты: визуальное, звуковое, визуальное и звуковое.

Для добавления нового оповещения нажмите **«Создать уведомление»**.

Для редактирования или удаления существующего используйте иконки карандаша и корзины напротив соответствующей записи.

## Оповещение о бронировании

**Оповещение о бронировании** - уведомление, которое получает пользователь в Gizmo Client при наступлении забронированного времени на текущий хост.

Для каждого оповещения настраиваются следующие параметры:

-  **Сообщение** - текст уведомления о бронировании (допускается импользование перемнной времени).  Если поле не заполнено, используется уведомление по умолчанию.

-  **Минут до оповещения** - за сколько минут до начала бронирования будет показано уведомление.

-  **Сворачивание окон** - при включении все открытые окна на хосте сворачиваются в момент показа уведомления.

-  **Тип уведомления** - способ оповещения пользователя. Доступные варианты: визуальное, звуковое, визуальное и звуковое.

Для добавления нового оповещения нажмите **«Создать уведомление»**.

Для редактирования или удаления существующего используйте иконки карандаша и корзины напротив соответствующей записи.

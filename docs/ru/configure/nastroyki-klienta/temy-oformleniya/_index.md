В данном разделе настраиваются профили темы оформления интерфейса Gizmo Client.

**Стандартная тема оформления** - базовая тема интерфейса Gizmo Client, применяемая по умолчанию. Выбирается из списка доступных тем.

В таблице отображаются все созданные профили оформления со следующей информацией:

-  **Имя** - название профиля. Профиль, установленный по умолчанию, отмечен меткой «По умолчанию».

-  **Филиал** - филиал или филиалы, к которым привязан профиль.

Для управления профилем нажмите кнопку **«...»** напротив нужной записи. Доступные действия:

-  **Редактировать** - открыть карточку профиля для редактирования.

-  **Установить значение по умолчанию** - назначить данный профиль профилем по умолчанию.

Для создания нового профиля нажмите кнопку **«Создать профиль оформления»** в правом углу страницы.

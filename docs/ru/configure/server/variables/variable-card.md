title: Карточка переменной
---

В карточке переменной доступны для заполнения следующие поля:

-  Имя - название переменной, указывается без экранирующих символов %

-  Значение - значение новой переменной;

-  Область применения - Область, в которой может быть вызвана переменная.

Для удаления переменной нажмите кнопку «Удалить» в правом нижнем углу карточки.

При внесении изменений не забывайте нажать кнопку «Сохранить» в правом верхнем углу.

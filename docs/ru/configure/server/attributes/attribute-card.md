order: 1
title: Карточка атрибута
---

В карточке атрибута доступны для заполнения следующие поля:

-  Ключ

-  Название

**Ключ** - уникальный идентификатор атрибута (название в базе данных)

**Название** - название атрибута для отображения в Gizmo Client и Gizmo Manager.



Для удаления атрибута нажмите кнопку «Удалить» в правом нижнем углу карточки.

> [!CAUTION]
> 
> При удалении атрибута удаляются все связанные с ним значения!

> [!CAUTION]
> 
> При внесении изменений в пользовательское соглашение не забывайте нажать кнопку «Сохранить» в правом верхнем углу.

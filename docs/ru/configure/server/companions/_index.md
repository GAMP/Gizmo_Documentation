Компаньон ([Gizmo Companion](./../../../about/overview/gizmo-companion.md)) - это дополнительная программа, которая позволяет использовать функции Gizmo в части организации связи c POS оборудованием и подключенными устройствами (например для доступа к файлам).

В данном разделе вы можете ознакомиться с уже подключенными Компаньонами к вашему серверу, а также добавить новый компаньон.

В интерфейсе данного раздела представлена таблица с подключенными к вашему серверу компаньонами. Таблица включает в себя:

-  **Название**  - произвольное название компаньона, которое может быть задано на этапе создания или редактирования компаньона;

-  **Статус** - статус подключения к серверу;

-  **IP** - IP-адрес компаньона;

-  **Токен** - уникальный идентификатор компаньона.

Для изменения имени компаньона, копирования его токена или для удаления компаньона перейдите в [Карточку компаньона](./companion-card.md) дважды кликнув мышкой по нужному компаньону в таблице.

Для добавления нового компаниона нажмите на кнопку в правом верхнем углу «[Добавить компаньон»](./add-new-companion.md).

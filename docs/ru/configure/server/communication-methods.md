Раздел задаёт почтовый сервер, через который Gizmo отправляет письма: подтверждения регистрации, уведомления и отчёты по расписанию. Без этих настроек почта из системы уходить не будет.

Раздел открывается в «Настройки» → «Сервер» → «Настройки SMTP».

## Поля

-  **Включить** -- переключатель, отвечающий за то, пользуется ли Gizmo почтой вообще. Пока он выключен, остальные поля значения не имеют.

-  **SMTP Host** -- адрес почтового сервера, через который отправляются письма.

-  **Порт SMTP** -- порт этого сервера. По умолчанию подставляется **465** -- порт защищённого соединения.

-  **Безопасность SMTP** -- способ шифрования соединения: **No** (без шифрования), **SSL** или **STARTTLS**. По умолчанию **SSL**.

-  **Ответить на адрес** -- адрес, который получатель увидит в поле «Кому ответить». На него придут ответы гостей на письма от клуба.

-  **SMTP аутентификация** -- переключатель. Включается, если почтовый сервер требует представиться, прежде чем принять письмо. Большинство внешних почтовых служб этого требуют. При включении появляются поля **Логин** и **Пароль** учётной записи почты.

Изменения вступают в силу по кнопке <cmd text="Сохранить"/>, отменяются -- по <cmd text="Отмена"/>.

## Пример: Яндекс Почта

| Поле | Значение |
|---|---|
| **Включить** | включено |
| **SMTP Host** | `smtp.yandex.ru` |
| **Порт SMTP** | `465` |
| **Безопасность SMTP** | SSL |
| **SMTP аутентификация** | включено |
| **Логин** | ваш адрес на Яндексе |
| **Пароль** | [пароль приложения](https://id.yandex.ru/security/app-passwords) Яндекса, а не пароль от почты |
| **Ответить на адрес** | тот же адрес на Яндексе |

**Ошибка «Имя пользователя и пароль не принимаются»:**

- проверьте, что **Логин** и адрес в **Ответить на адрес** совпадают;
- создайте новый пароль приложения в Яндексе и вставьте его заново;
- после изменения настроек перезапустите Gizmo Server -- см. [«Как перезапустить сервер Gizmo»](./../../tutorials/operations/server-restart.md).

## Зачем это нужно

Настроенный здесь сервер используется интеграцией **Системный SMTP** -- той самой, через которую Gizmo рассылает электронную почту. Если интеграция добавлена, а SMTP не настроен, письма уходить не будут: интеграция берёт параметры отсюда, а не хранит свои.

Порядок такой: сначала заполните этот раздел, затем добавьте интеграцию «Системный SMTP» в разделе «Плагины».

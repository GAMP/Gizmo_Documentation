Интеграции -- это внешние службы, подключаемые к Gizmo для расширения функционала, например, службы отправки SMS, боты в Telegram и др.

Интеграции живут в разделе «Настройки» -> «Сервер» -> «Плагины», во втором блоке экрана -- **Интеграции**. Первый блок, **Плагины**, отвечает за другое: там перечислены файлы расширений, установленные на сервере.

> [!CAUTION]
>
> Изменения интеграций -- добавление, удаление, включение или отключение -- вступают в силу **после перезапуска сервера**. Пока сервер не перезапущен, новая интеграция работать не начнёт.

## Как добавить

1. Откройте «Настройки» -> «Сервер» -> «Плагины».
2. В блоке **Интеграции** нажмите <cmd text="Добавить" />.
3. В окне «Выберите тип интеграции» выберите нужную службу.
4. Заполните её параметры -- состав полей зависит от выбранного типа.
5. Сохраните и **перезапустите сервер**.

## Доступные типы

- **Telegram-бот** -- интеграция мессенджера Telegram для подтверждения пользователей и уведомлений.
- **Пользовательский** -- отправляет SMS на любой SMS-шлюз с помощью настраиваемого HTTP-запроса. Подходит, когда нужного оператора нет в списке готовых.
- **Red SMS** -- SMS-сообщения и флэш-звонки через сервис RedSMS.ru.
- **SMS Aero RU** -- SMS-сообщения через сервис SMS Aero.
- **SMSC RU** -- SMS-сообщения и флэш-звонки через сервис SMSC.ru.
- **Twilio** -- SMS-сообщения через сервис Twilio.
- **Системный SMTP** -- электронная почта через системную конфигурацию SMTP. Сам почтовый сервер настраивается отдельно, в разделе «Настройки SMTP».

## Таблица интеграций

Добавленные интеграции показываются списком:

- **Название** -- название интеграции.
- **Тип** -- служба, к которой она подключена.
- **Включен** -- работает интеграция или отключена.

### Пользовательский провайдер

Если нужного SMS-провайдера нет в списке, выберите **Пользовательский** и укажите URL HTTP-запроса провайдера. Требования:

- поддерживаются методы GET и POST;
- все параметры передаются в строке URL -- параметры в теле запроса не поддерживаются;
- в URL используются подстановки: `{FROM}` -- отправитель, `{TO}` -- номер получателя, `{MESSAGE}` -- текст сообщения.

Примеры URL для популярных провайдеров (замените заглавные значения на свои):

| Провайдер | URL |
|---|---|
| [Vonage (Nexmo)](https://developer.vonage.com/) | `https://rest.nexmo.com/sms/json?api_key=APIKEY&api_secret=APISECRET&from={FROM}&to={TO}&text={MESSAGE}` |
| [Twilio](https://www.twilio.com/docs/sms/api) | `https://TWILIO_ACCOUNT_SID:TWILIO_AUTH_TOKEN@api.twilio.com/2010-04-01/Accounts/TWILIO_ACCOUNT_SID/Messages.json?From={FROM}&To=+{TO}&Body={MESSAGE}` |
| [SMS Traffic](https://www.smstraffic.ru/) | `https://api.smstraffic.ru/multi.php?login=ACCOUNTNAME&password=ACCOUNTPASSWORD&originator={FROM}&phones={TO}&message={MESSAGE}` |
| [SMStraf](https://smstraf.ru/api) | `http://billing.smstraf.ru/sys/send.php?login=ACCOUNTNAME&psw=ACCOUNTPASSWORD&sender={FROM}&phones={TO}&mes={MESSAGE}` |
| [sms.etc.uz](http://sms.etc.uz/) | `http://sms.etc.uz:8083/http2sms?login=LOGIN&pwd=PASSWORD&CgPN=SENDER&CdPN={TO}&text={MESSAGE}` |

### Телефон Android как SMS-шлюз

Вместо SMS-провайдера можно отправлять сообщения через обычный телефон на Android:

1. Установите на телефон приложение [GSM - modem (SMS)](https://play.google.com/store/apps/details?id=com.gsmmodem).
2. В приложении нажмите **Users** и создайте пользователя с паролем.
3. Нажмите **ВКЛ.** и проверьте, что статус службы -- **started**.
4. В Gizmo добавьте интеграцию **Пользовательский** с URL:

```
http://PHONEIP:8090/SendSMS?username=USER&password=PASSWORD&phone={TO}&message={MESSAGE}
```

где `PHONEIP` -- IP-адрес телефона, который показывает приложение, а `USER` и `PASSWORD` -- пользователь и пароль, созданные в приложении. Телефон должен быть в одной сети с сервером.

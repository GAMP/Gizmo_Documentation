Интеграции — это внешние службы, через которые Gizmo связывается с гостями: рассылает SMS, пишет в Telegram, отправляет электронную почту. Пока интеграция не добавлена, отправлять сообщения системе нечем.

Интеграции живут в разделе «Настройки» → «Сервер» → «Плагины», во втором блоке экрана — **Интеграции**. Первый блок, **Плагины**, отвечает за другое: там перечислены файлы расширений, установленные на сервере.

> [!CAUTION]
>
> Изменения интеграций — добавление, удаление, включение или отключение — вступают в силу **после перезапуска сервера**. Пока сервер не перезапущен, новая интеграция работать не начнёт.

## Как добавить

1. Откройте «Настройки» → «Сервер» → «Плагины».

2. В блоке **Интеграции** нажмите <cmd text="Добавить"/>.

3. В окне «Выберите тип интеграции» выберите нужную службу.

4. Заполните её параметры — состав полей зависит от выбранного типа.

5. Сохраните и **перезапустите сервер**.

## Доступные типы

-  **Telegram-бот** -- интеграция мессенджера Telegram для подтверждения пользователей и уведомлений.

-  **Пользовательский** -- отправляет SMS на любой SMS-шлюз с помощью настраиваемого HTTP-запроса. Подходит, когда нужного оператора нет в списке готовых.

-  **Red SMS** -- SMS-сообщения и флэш-звонки через сервис RedSMS.ru.

-  **SMS Aero RU** -- SMS-сообщения и флэш-звонки через сервис SMS Aero.

-  **SMSC RU** -- SMS-сообщения и флэш-звонки через сервис SMSC.ru.

-  **Twilio** -- SMS-сообщения через сервис Twilio.

-  **Системный SMTP** -- электронная почта через системную конфигурацию SMTP. Сам почтовый сервер настраивается отдельно, в разделе «Настройки SMTP».

## Таблица интеграций

Добавленные интеграции показываются списком:

-  **Имя** -- название интеграции.

-  **Тип** -- служба, к которой она подключена.

-  **Включен** -- работает интеграция или отключена.

title: Права доступа
---

В данном разделе настраиваются предустановки прав доступа -- наборы разрешений, которые назначаются операторам.

В таблице отображаются все созданные предустановки со следующей информацией:

-  **Имя** - название предустановки.

-  **Права доступа** - общее количество включённых разрешений.

-  **Операторы** - количество операторов, которым назначена данная предустановка.

Для создания новой предустановки нажмите кнопку **«Создать право доступа»** в правом углу страницы.

Для редактирования существующей предустановки нажмите на соответствующую строку в таблице.

В данном разделе настраиваются способы оплаты, доступные в Gizmo Manager и Gizmo Client.

## Стандартные способы оплаты

Стандартные способы оплаты встроены в систему и не могут быть удалены. Для каждого из них можно настроить доступность:

-  **Включен** - общий статус способа оплаты в системе.

-  **Менеджер** - доступность способа оплаты в Gizmo Manager.

-  **Клиент** - доступность способа оплаты в Gizmo Client.

Доступные стандартные способы оплаты:

-  **Cash** - наличные.

-  **Credit Card** - банковская карта.

-  **Deposit** - оплата с депозита пользователя.

-  **Points** - оплата баллами лояльности.

**Использовать платежный терминал при оплате банковской картой** - при включении оплата картой проводится через подключённый платёжный терминал. Доступны два режима работы терминала:

-  **Не в сети** - терминал работает в офлайн-режиме.

-  **В сети** - терминал работает в онлайн-режиме.

## Дополнительные способы оплаты

В данном подразделе настраиваются пользовательские способы оплаты, например, интеграции с платёжными системами (YooKassa, Tinkoff и др.).

Таблица отображает все созданные дополнительные способы оплаты. Для каждого из них доступны те же настройки, что и для стандартных: **Включен**, **Менеджер**, **Клиент**. Порядок отображения можно изменить перетаскиванием за иконку **::**. Для удаления способа оплаты нажмите иконку корзины.

Для создания нового способа оплаты нажмите кнопку **«+ Создать способ оплаты»**. Откроется форма со следующими полями:

**Имя** - название способа оплаты, отображаемое в интерфейсе. Поле является обязательным для заполнения.

**Включен** - общий статус способа оплаты. При включении становятся доступны дополнительные настройки:

-  **Менеджер** - доступность способа оплаты в Gizmo Manager.

-  **Клиент** - доступность способа оплаты в Gizmo Client.

**Фискальный** - при включении данный способ оплаты учитывается при фискализации чеков. В поле **«Вид платежа фискального чека»** выбирается тип платежа для отражения в чеке (например, наличные).

Описанная выше форма соответствует созданию способа оплаты типа **«Не в сети»** -- для приёма платежей без интеграции с внешней платёжной системой.

Для создания онлайн-способа оплаты (**«В сети»**) выберите соответствующий вариант при создании -- откроется страница **«Провайдеры платежей»** со списком доступных интеграций:

-  [Click.uz](http://Click.uz)

-  Cloud payments

-  Kaspi

-  OPay

-  Pay Selection

-  Stripe

-  Tinkoff

-  YooKassa

Провайдеры, которые уже добавлены в систему, отмечены меткой **«Уже добавлено»** и недоступны для повторного выбора. Для подключения нового провайдера нажмите на его карточку и следуйте инструкциям по настройке интеграции.

## Настройки онлайн-депозита для Shell

В данном подразделе настраивается пополнение депозита пользователем через интерфейс Gizmo Client.

**Разрешить произвольную сумму пополнения** - при включении пользователь может самостоятельно ввести любую сумму пополнения в пределах установленных лимитов.

**Минимальная сумма** - минимальная сумма, которую пользователь может пополнить за один раз.

**Максимальная сумма** - максимальная сумма, которую пользователь может пополнить за один раз.

**Шаблоны** - фиксированные суммы пополнения, отображаемые пользователю в виде кнопок быстрого выбора. Для добавления шаблона нажмите **«+ Добавить шаблон»**, укажите сумму и нажмите **«Готово»**.

## Другие

**URL для успешного платежа** - адрес страницы, на которую перенаправляется пользователь после успешной оплаты онлайн.

**URL для неуспешных платежей** - адрес страницы, на которую перенаправляется пользователь в случае неудачной оплаты онлайн.

title: Тарифы
---

В данном разделе настраиваются профили тарификации -- правила начисления оплаты за время, проведённое пользователем на хосте.

Все созданные тарифы отображаются в виде карточек. Каждая карточка показывает название профиля и количество привязанных филиалов.

Для создания нового тарифа нажмите кнопку **«Создать тариф»** в правом углу страницы.

Для редактирования существующего тарифа нажмите на его карточку.

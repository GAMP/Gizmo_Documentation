title: Карточка тарифа
---

Карточка тарифа открывается при создании нового тарифа или редактировании существующего.

Карточка состоит из двух частей: панели настроек слева и календарного графика справа.

## Общее

Блок **«Общее»** содержит базовые настройки тарифного профиля, действующие по умолчанию в те периоды, которые не охвачены расписаниями.

**Название профиля цен** - наименование тарифного профиля.

**Филиалы** - филиалы, в которых применяется данный тариф. Можно выбрать несколько филиалов.

**Группы хостов** - группы хостов, к которым применяется данный тариф. Можно выбрать несколько групп.

**Основной тариф** - тип тарификации. Доступны два варианта:

-  **Почасовой** - оплата начисляется пропорционально времени использования хоста.

-  **Пошаговый** - оплата начисляется по заданным шагам с индивидуальными правилами для каждого интервала.

### Почасовой тариф

**Стартовый взнос** - фиксированная сумма, списываемая при начале сеанса.

**Минимальный взнос** - минимальная сумма, которая будет списана за сеанс вне зависимости от его продолжительности.

**Почасовая оплата** - стоимость одного часа использования хоста.

**Начислять каждые (минут)** - интервал в минутах, с которым производится начисление оплаты.

**Бесплатные минуты** - количество минут в начале сеанса, за которые оплата не начисляется.

### Пошаговый тариф

Пошаговый тариф позволяет задать разные правила начисления для последовательных временных интервалов одного сеанса.

Для каждого шага настраиваются следующие параметры:

-  **Минута шага** - с какой минуты сеанса начинает действовать данный шаг.

-  **Действие** - тип действия при наступлении шага (например, «Начислить»).

-  **Начисление** - сумма, начисляемая при наступлении шага.

-  **Почасовая оплата** - почасовая ставка, действующая в рамках данного шага.

Для добавления нового шага нажмите **«+ Создать шаг»**. Для удаления шага нажмите кнопку **«Удалить»** внутри его карточки.

## Расписания

Расписания позволяют задавать отличные от основного тарифные условия для конкретных временных интервалов в течение недели.

Для создания расписания нажмите кнопку **«Создать расписание»** в нижней части панели. Созданное расписание появится в панели слева в виде отдельного блока и на календарном графике справа.

Каждое расписание содержит те же параметры тарификации, что и блок «Общее» (почасовой или пошаговый тариф), и может быть удалено кнопкой с иконкой корзины.

## Календарный график

Календарный график отображает недельное расписание тарифа. Строки соответствуют дням недели, столбцы -- часам суток (с 00:00 до 24:00).

-  Серые блоки подписаны **«Общее»** -- в эти периоды действует базовый тариф из блока «Общее».

-  Цветные блоки соответствуют созданным расписаниям -- в эти периоды действуют их тарифные условия.

Чтобы назначить расписание на определённый интервал, выделите нужный период на графике, зажав левую кнопку мыши и проведя по шкале времени в строке нужного дня.

Для удаления тарифа нажмите кнопку **«Удалить»** в правом верхнем углу страницы.

> [!CAUTION]
> 
> Не забудьте нажать кнопку «Сохранить» для применения ваших настроек.

В данном разделе настраиваются пакеты времени -- предоплаченные временные предложения, которые пользователи могут приобрести в Gizmo Client или через Gizmo Manager.

Раздел содержит две вкладки: **«Пакеты»** и **«Приоритет»**.

## Вкладка «Пакеты»

Отображает все созданные пакеты времени в виде карточек, сгруппированных по филиалу и группе хостов.

Список можно отфильтровать по следующим параметрам:

-  **Филиал** - фильтр по филиалу.

-  **Группа хостов** - фильтр по группе хостов.

-  **Пакет времени** - фильтр по конкретному пакету.

Для сброса всех фильтров нажмите **«Очистить все»**.

Каждая карточка пакета отображает:

-  название пакета;

-  стоимость;

-  продолжительность (в формате ЧЧ:ММ);

-  количество филиалов, в которых пакет доступен.

Для создания нового пакета нажмите кнопку **«Создать пакет времени»** в правом углу страницы.

Для редактирования существующего пакета нажмите на его карточку.

## Вкладка «Приоритет»

Отображает все пакеты времени в виде таблицы с указанием продолжительности. Здесь можно задать порядок отображения пакетов -- перетащите нужный элемент за иконку **::** в требуемую позицию.

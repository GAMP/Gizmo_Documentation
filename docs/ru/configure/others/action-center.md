title: Центр действий
order: 2
---

Страница открывается в **Настройки -> Другое -> Центр действий**. Здесь настраиваются звуковые уведомления Gizmo Manager -- например, о новых заказах гостей или выходе гостей из системы.

Для каждого звука можно:

-  включить или выключить его;

-  загрузить свой звуковой файл вместо стандартного.

> [!NOTE]
>
> Список звуков и событий, к которым они привязаны, будет добавлен позже.

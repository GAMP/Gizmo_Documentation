---

Карточка кассы открывается при создании новой кассы или редактировании существующей.

## Настройки места

**Филиал** - филиал, к которому привязана касса. Поле является обязательным для заполнения.

**Склад** - склад, связанный с данной кассой. Используется для учёта товаров при продажах.

**Компаньон** - Gizmo Companion, который будет работать с данной кассой.

**Номер** - порядковый номер кассы.

**Имя** - название кассы. Поле является обязательным для заполнения.

**Наличных на начало смены** - сумма наличных денег, с которой открывается смена на данной кассе.

**Таймаут простоя** - время бездействия в секундах, после которого касса переходит в режим ожидания.

**Номер платежного терминала** - идентификационный номер платёжного терминала, подключённого к данной кассе.

**Номер принтера фискальных чеков** - идентификационный номер фискального принтера, подключённого к данной кассе.

**Номер QR-дисплея** - идентификационный номер QR-дисплея, подключённого к данной кассе.

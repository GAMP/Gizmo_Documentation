В данном разделе настраиваются кассы, используемые в Gizmo Manager при проведении финансовых операций.

В таблице отображаются все созданные кассы. Список можно отфильтровать по филиалу, нажав на фильтр **«Филиал»**.

Таблица содержит следующие столбцы:

-  **Имя** - название кассы.

-  **Филиал** - филиал, к которому привязана касса.

-  **Компаньон** - Gizmo Companion, связанный с данной кассой.

Для создания новой кассы нажмите кнопку **«Создать кассу»** в правом углу страницы.

Для редактирования существующей кассы нажмите на соответствующую строку в таблице.

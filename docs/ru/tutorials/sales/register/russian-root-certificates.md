---
title: Онлайн-платежи не проходят -- как установить российские корневые сертификаты
order: 4
---

Банки и платёжные сервисы, например Т-Банк, переходят на российские сертификаты Минцифры (Russian Trusted Root CA). Если на пк с Gizmo Server их нет, сервер не может установить защищённое соединение с платёжным сервисом, и онлайн-пополнения не проходят.

**Признак проблемы** -- в разделе [«Журналы»](./../../../usage/gizmo-manager/logs.md) Gizmo Manager появляется ошибка:

```
System.Exception: The SSL connection could not be established, see inner exception
```

Чтобы её исправить, установите корневые сертификаты на пк с Gizmo Server и перезапустите сервер.

## Что нужно заранее

- права администратора на пк с Gizmo Server;
- доступ в интернет на этом пк -- чтобы скачать сертификаты.

## Шаг 1. Скачайте сертификаты

1. Откройте [страницу загрузки сертификатов](https://www.gosuslugi.ru/crt) на Госуслугах.
2. В разделе **Сертификаты для Windows** нажмите **Скачать корневые сертификаты**.
3. Распакуйте архив в отдельную папку, например `C:\certs`. В нём два файла:
   - `russian_trusted_root_ca.cer`;
   - `russian_trusted_root_ca_gost_2025.cer`.

## Шаг 2. Установите сертификаты

1. Нажмите **Win + R**, введите `certlm.msc` и нажмите **OK**. Если Windows попросит, подтвердите запуск от имени администратора -- откроется окно **Сертификаты -- локальный компьютер**.
2. В списке слева откройте **Доверенные корневые центры сертификации**.
3. Нажмите правой кнопкой мыши на папку **Сертификаты** и выберите **Все задачи -> Импорт...**.
4. В мастере импорта нажмите **Далее** и выберите файл `russian_trusted_root_ca.cer`.
5. Проверьте, что выбрано хранилище **Доверенные корневые центры сертификации**, и завершите импорт.
6. Повторите шаги 3--5 для файла `russian_trusted_root_ca_gost_2025.cer`.

После импорта оба сертификата появятся в списке.

> [!TIP]
>
> Шаги 1 и 2 можно выполнить автоматически скриптом. Скачайте архив **[ССЫЛКА: install-russian-trust.zip]**, распакуйте оба файла (`install-russian-trust.bat` и `install-russian-trust.ps1`) в одну папку и запустите `install-russian-trust.bat` от имени администратора. Скрипт скачает сертификаты с официального сайта, установит их, проверит соединение с платёжным сервисом и сохранит лог в `install-russian-trust.log` рядом с собой.

## Шаг 3. Перезапустите Gizmo Server

Перезапустите сервер, чтобы изменения применились, -- см. инструкцию [«Как перезапустить сервер Gizmo»](./../../operations/server-restart.md).

## Результат

Проведите тестовый онлайн-платёж: ошибка SSL-соединения в журнале должна исчезнуть, а оплата -- пройти.

**Если ошибка осталась**, проверьте:

- сертификаты установлены от имени администратора;
- сертификаты установлены именно на том пк, где работает Gizmo Server;
- на сервере правильно настроены дата и время -- их сбой тоже вызывает ошибки сертификатов.

Если не помогло, [обратитесь в поддержку](./../../../about/support.md).

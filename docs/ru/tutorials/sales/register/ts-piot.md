---
title: Как подключить ТС ПИоТ для маркированных товаров
order: 3
---

С 1 июля 2026 года в России изменились правила продажи маркированных товаров. Если в клубе продаются энергетики, вода или другие товары с маркировкой «Честный знак», касса должна проверять коды маркировки при каждой продаже. Для этого используется **ТС ПИоТ** -- техническое средство получения информации о товаре: модуль, который проверяет маркированные товары и передаёт нужные данные.

Без ТС ПИоТ продажа маркированных товаров через кассу может не пройти. Инструкция описывает подключение для ККТ АТОЛ и ШТРИХ, которые работают с Gizmo через ККМ-сервер.

> [!TIP]
>
> Центры технического обслуживания (ЦТО) часто предлагают настройку ТС ПИоТ под ключ. Шаги 2--4 можно выполнить и самостоятельно.

## Что нужно заранее

- ФФД ККТ -- версии 1.2;
- прошивка ККТ АТОЛ -- не ниже 5.17.0, ККТ ШТРИХ -- не ниже Т.3;
- драйвер ККТ АТОЛ -- не ниже 10.10.8.23, ККТ ШТРИХ -- не ниже 5.25.2096;
- ККМ-сервер -- не ниже 2.3.16.36;
- Gizmo Companion -- не ниже 3.0.0 (версия указана внизу страницы интерфейса Companion);
- в драйвере ККТ включён признак **Торговля маркированными товарами**;
- касса подключена к Gizmo через ККМ-сервер -- см. [«Фискализация чеков в РФ»](./../../../articles/fiscalization.md).

## Шаг 1. Обновите или установите ККМ-сервер

- Если ККМ-сервер уже установлен, [скачайте актуальную версию](https://kkmserver.ru/Donload/Dist/Setup_KkmServer.exe) и установите её поверх.
- Если ККМ-сервера нет, установите его по разделу «Подключение через ККМ-сервер» в статье [«Фискализация чеков в РФ»](./../../../articles/fiscalization.md). Перевести Companion на работу с ККМ-сервером поможет [поддержка](./../../../about/support.md).

## Шаг 2. Обновите ДТО

Установите актуальный драйвер торгового оборудования для вашей кассы:

- для ККТ АТОЛ -- [ДТО АТОЛ](https://kkmserver.ru/Donload/Atol_DTO_x32_setup.exe);
- для ККТ ШТРИХ -- [ДТО ШТРИХ](https://torgbalance.com/download_new/).

## Шаг 3. Установите модуль ЕСМ

1. Зарегистрируйтесь в личном кабинете ЕСП и подтвердите учётную запись -- [инструкция по регистрации](https://ao-esp.ru/base/install-update/registration).
2. Оплатите и установите «Единый сервисный модуль» (ЕСМ) -- это и есть ТС ПИоТ -- [инструкция по оплате и установке](https://ao-esp.ru/base/install-update/pay_install).

> [!IMPORTANT]
>
> Если обращаетесь в поддержку ТС ПИоТ, сообщите, что ТС ПИоТ нужно настроить для работы с ККМ-сервером.

## Шаг 4. Настройте модуль ЕСМ

Выполните шаги из инструкции производителя для вашей кассы:

- [инструкция для АТОЛ](https://static.ao-esp.ru/downloads/pmsr/docs/ATOL/all/WINDOWS_1.7.pdf);
- [инструкция для ШТРИХ](https://static.ao-esp.ru/downloads/pmsr/docs/SHTRIHM/all/WINDOWS_1.4.pdf).

> [!WARNING]
>
> Обязательно проверьте настройку локального модуля «Честного знака» (ЛМ ЧЗ) -- иначе данные о товарах не будут передаваться в сервис.

## Шаг 5. Включите ТС ПИоТ в ККМ-сервере

1. На пк с ККМ-сервером откройте страницу настройки ТС ПИоТ: [http://localhost:5893/TcPiot/](http://localhost:5893/TcPiot/). Ссылка работает только на этом пк.
2. Включите **Использовать ТС ПИоТ**.
3. Укажите **URL ТС ПИоТ (ЕСМ)** -- по умолчанию `https://localhost:51401`.
4. Нажмите **Обновить список ККТ** -- должен загрузиться список касс, на которые зарегистрирован ТС ПИоТ.
5. Нажмите **Сохранить настройки**.

## Результат

Касса проверяет коды маркировки через ТС ПИоТ, и маркированные товары продаются через Gizmo по новым правилам.

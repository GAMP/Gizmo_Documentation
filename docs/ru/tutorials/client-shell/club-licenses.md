---
title: Как настроить клубные аккаунты в лаунчерах
order: 1.2
---

Если клуб покупает игры на свои аккаунты в Steam, Epic, Battle.net и других лаунчерах, Gizmo может сам входить в свободный аккаунт, когда гость запускает игру, и выходить из него после игры. Гостю не нужен свой аккаунт, а пароли от клубных аккаунтов он не видит.

Для этого к исполняемому файлу игры привязывается **профиль лицензий** -- набор клубных аккаунтов одного лаунчера.

## Перед началом

- Игра добавлена в клиентскую оболочку -- см. [«Как добавить игру в клиентскую оболочку»](./add-app-to-shell.md).
- На сервере включён плагин лицензий: **Настройки -> Сервер -> Плагины**, плагин **BaseLmPlugin**. Если он был выключен, включите его и перезапустите сервер и Gizmo Manager -- иначе карточка лицензии не откроется.

## Шаг 1. Настройте запуск игры через лаунчер

В исполняемом файле игры укажите **файл лаунчера** и аргумент, который запускает игру. Например, для Steam:

- **Путь к исполняемому файлу** -- `C:\Program Files (x86)\Steam\steam.exe`;
- **Аргументы** -- `steam://rungameid/730`.

Пути и аргументы для других лаунчеров -- в справочнике [«Пути и аргументы запуска для лаунчеров и приложений»](./launch-arguments.md).

## Шаг 2. Создайте профиль лицензий

1. Откройте исполняемый файл игры и перейдите на вкладку **Лицензии**.
2. Нажмите **+ Создать новую лицензию** и выберите лаунчер. Сменить лаунчер после создания профиля нельзя.
3. Укажите **Название** профиля.
4. Нажмите **+ Добавить ключ лицензии** и введите логин и пароль клубного аккаунта. Повторите для каждого аккаунта.
5. Сохраните профиль.

Если аккаунт нужно закрепить за конкретным пк, выберите этот пк в поле **Хост** у ключа. Иначе аккаунты распределяются между пк автоматически.

## Шаг 3. Настройте освобождение аккаунта после игры

Чтобы после выхода гостя из игры лаунчер закрывался и аккаунт освобождался для следующего гостя:

1. В поле **Ignored processes in tree** укажите процесс самой игры -- его точное название можно посмотреть в диспетчере задач Windows. Например, `cs2.exe` для Counter-Strike 2 или `TslGame_BE.exe` для PUBG. Несколько процессов перечисляются через `;`.
2. Включите **End session when process tree exits**.
3. В поле **Grace period after tree exit** при необходимости задайте, сколько секунд подождать после выхода из игры, прежде чем закрыть лаунчер.

Тогда, как только гость закроет игру, Gizmo закроет лаунчер и вернёт аккаунт в пул свободных.

> [!NOTE]
>
> Если гость не запустил игру в течение 60 секунд после того, как Gizmo выдал ему аккаунт, аккаунт отзывается и возвращается в пул. Так гость не может занять клубный аккаунт, не играя.

> [!WARNING]
>
> **Аккаунты EA app (EA Desktop).** Каждый аккаунт EA нужно один раз подготовить, иначе Gizmo будет входить в лаунчер через эмуляцию ввода с клавиатуры, а она срабатывает не всегда:
>
> 1. Откройте [ea.com](https://www.ea.com/) и, если вы уже вошли, выйдите из аккаунта.
> 2. Войдите в аккаунт снова и примите соглашение EA, если сайт его покажет.
> 3. Если сайт попросит подтвердить личность, нажмите **Отправить код** и пройдите проверку.
>
> Повторите для каждого аккаунта. Если EA изменит условия соглашения, шаги нужно будет повторить.

## Шаг 4. Привяжите профиль к игре

1. На вкладке **Лицензии** исполняемого файла выберите созданный профиль в поле **Выберите лицензию**.
2. В поле **Стратегия резервирования лицензий** оставьте **Первая доступная**.
3. Сохраните исполняемый файл.

## Если на аккаунтах несколько игр

Аккаунт лаунчера может быть в сети только на одном пк. Пока гость играет в одну игру с аккаунта, остальные игры этого аккаунта другим гостям недоступны. Поэтому лучше покупать **одну игру на один аккаунт**.

Если на аккаунтах всё же несколько игр, настройте профили так:

- **Группируйте аккаунты по набору игр.** В одном профиле -- только аккаунты с одинаковым набором игр. Например, 5 аккаунтов с одними и теми же тремя играми -- один профиль. Аккаунт с теми же тремя играми и ещё одной -- уже другой профиль.
- **Каждый аккаунт -- только в одном профиле.** Не добавляйте один аккаунт дважды -- ни в тот же профиль, ни в другой.
- **Сначала профили с меньшим количеством игр.** В исполняемом файле игры добавьте все профили, в которых есть аккаунты с этой игрой: первыми -- профили, где на аккаунтах меньше игр, последними -- где больше. Например, для PUBG сначала профиль с аккаунтами, где есть только PUBG, затем профиль с аккаунтами, где есть PUBG и Call of Duty.
- **Стратегия -- «Первая доступная».** Gizmo берёт первый свободный аккаунт, начиная с верхнего профиля, -- так аккаунты с несколькими играми остаются в запасе для других игр.

## Результат

Гость запускает игру, Gizmo сам входит в свободный клубный аккаунт, а после игры закрывает лаунчер и освобождает аккаунт.

Все поля профиля лицензий -- в статье [«Карточка лицензии»](./../../usage/gizmo-manager/stations/prilozheniya/kartochka-redaktirovaniya-ispolnyaemogo-fayla/kartochka-licenziy.md). Как убирать с пк авторизацию гостей в лаунчерах после сеанса -- в инструкции [«Очистка сессий игр и лаунчеров»](./session-cleanup.md).

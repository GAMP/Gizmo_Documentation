---

Приложение в Gizmo -- это игра или программа, которую гость может запустить из клиентской оболочки. Настраивается в <cmd text="Станции"/> -> <cmd text="Приложения"/>.

Каждое приложение состоит из двух связанных, но разных сущностей: карточки приложения и одного или нескольких исполняемых файлов внутри неё.

## Карточка приложения

-  **Название** -- то, что видит гость в оболочке.

-  **Обложка** -- изображение карточки.

-  **Группа по умолчанию** -- категория, к которой относится приложение (настраивается в разделе организации приложений).

-  **Категория** -- используется для сортировки и фильтрации приложений в оболочке.

## Исполняемый файл

Один или несколько на карточку -- если игра установлена по разным путям на разных пк клуба, для каждого варианта пути создаётся отдельный исполняемый файл внутри той же карточки.

-  **Подпись** -- название ярлыка, которое видит гость, и иконка для него.

-  **Доступность** -- филиалы, в которых этот ярлык должен появиться. Без включения доступности для нужного филиала ярлык нигде не будет виден.

-  **Путь к исполняемому файлу** -- путь на клиентском пк (не на сервере), по которому запускается приложение.

-  **Рабочий каталог** -- как правило совпадает с путём к исполняемому файлу.

## Организация параметров запуска

-  **Auto Launch** -- параметр поведения запуска приложения из оболочки.

-  **Monitor Children** -- позволяет Gizmo Client отслеживать дочерние процессы, запущенные приложением (например, отдельные лаунчеры или античит-модули), а не только сам исполняемый файл.

> 
> Точное техническое поведение Auto Launch и Monitor Children (что именно меняется при включении/выключении каждого) появится в этой статье отдельно, после сверки с разработчиками.

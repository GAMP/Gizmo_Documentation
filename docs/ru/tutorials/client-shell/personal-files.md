Гость прошёл полкампании, а в следующий визит сел за другой пк -- или за тот же, но после перезагрузки -- и обнаружил, что прогресса нет. Сохранения большинства игр лежат локально на пк, поэтому без отдельной настройки они не переходят между сеансами и игровыми местами.

Для этого в Gizmo есть **личные файлы пользователей (ЛФП)**. Gizmo сохраняет указанную папку с клиентского пк на сервере и возвращает её, когда гость запускает игру или входит в систему на любом пк клуба. Так сохранения не пропадают, даже если пк перезагружается после каждого сеанса, и синхронизируются между игровыми местами и филиалами. ЛФП настраиваются отдельно для каждой игры -- в её исполняемом файле.

## Шаг 1. Проверьте, где сервер хранит личные файлы

1. Откройте **Настройки -> Клиент -> Файловая система**, блок **Файловая система на стороне сервера**.
2. В поле **Путь к пользовательскому хранилищу** проверьте или укажите директорию на сервере, в которой будут храниться личные файлы пользователей.

Описание полей раздела -- в статье [«Файловая система»](./../../configure/client/file-system.md).

## Шаг 2. Откройте исполняемый файл игры

1. Откройте **Станции -> Приложения**, затем карточку нужной игры и её исполняемый файл.
2. Перейдите на вкладку **Личные файлы**.
3. Нажмите **+ Создать новый личный файл** -- откроется карточка ЛФП. Если подходящий ЛФП уже создан, прикрепите его в поле **Выберите личный файл**.

Если игры ещё нет в оболочке, сначала добавьте её по инструкции [«Как добавить игру в клиентскую оболочку»](./add-app-to-shell.md).

## Шаг 3. Заполните карточку ЛФП

**Основные поля**

- **Имя** -- название ЛФП в Gizmo Manager.
- **Заголовок** -- название ЛФП, которое видят клиенты в оболочке.
- **Источник** -- путь к папке с сохранениями на клиентском пк. Если нужно сохранить запись реестра, включите параметр **Реестр** и укажите путь к записи реестра в этом поле.
- **Уровень сжатия** -- чем выше уровень, тем медленнее копирование и развёртывание, но тем меньше места ЛФП занимает на сервере. Тип «Хранилище» означает, что ЛФП не сжимается.

**Когда возвращать файлы на пк**

В поле **Активация** выберите вариант:

- **На старте** -- файлы копируются на пк при запуске игры, к которой прикреплён ЛФП;
- **При входе в систему** -- файлы копируются на пк при входе гостя в аккаунт. Если у гостя много ЛФП, вход может заметно задержаться.

**Сколько места выделить**

**Квота** -- сколько МБ может занимать сохранение этого ЛФП для каждого клиента. 0 -- без ограничения.

> [!WARNING]
>
> Если сжатый размер сохранения больше квоты, оно не будет записано на сервер.

**Дополнительные параметры** -- по необходимости:

- **Доступен** -- показывать ли ЛФП гостю в оболочке с возможностью выбора. Даже если выключено, ЛФП продолжает работать -- гость просто не видит его в параметрах запуска.
- **Очистка** -- перед восстановлением файлов Gizmo удаляет всё содержимое каталога назначения.
- **Включить подкаталоги** -- сохранять вложенные папки и файлы внутри папки-источника.
- **Включить файлы**, **Включить каталоги**, **Исключить файлы**, **Исключить каталоги** -- какие файлы и папки попадут в копию. Поддерживаются групповые символы, элементы разделяются «;».

Сохраните карточку ЛФП и исполняемый файл. Описание всех полей -- в статье [«Карточка ЛФП»](./../../usage/gizmo-manager/stations/prilozheniya/kartochka-redaktirovaniya-ispolnyaemogo-fayla/lichnye-fayly-polzovateley.md).

## Шаг 4. Проверьте сохранение

Копирование с клиентского пк на сервер всегда происходит, когда гость выходит из системы. Чтобы проверить настройку, войдите тестовым аккаунтом, запустите игру и сохранитесь, выйдите из системы, а затем войдите тем же аккаунтом на другом пк и запустите игру -- сохранение должно быть на месте.

## Личное хранилище для группы

Кроме ЛФП для отдельных игр, участникам группы пользователей можно выделить личное хранилище -- личную папку, файлы в которой сохраняются между сеансами:

- в карточке группы (**Пользователи -> Группы пользователей**), в блоке **Настройки**, включите **Личное хранилище**;
- в **Настройки -> Клиент -> Файловая система** есть опция **Личное хранилище пользователя** и поле **Путь пользователя по умолчанию** -- папка по умолчанию для новых пользователей при первом входе.

## Результат

- При выходе гостя из системы папка с сохранениями копируется на сервер.
- Когда гость запускает игру или входит в систему на любом пк клуба, Gizmo возвращает его сохранения на этот пк -- прогресс не теряется ни после перезагрузки, ни при пересадке за другое место.

Как убирать чужие сессии лаунчеров между гостями -- в инструкции [«Очистка сессий игр и лаунчеров»](./session-cleanup.md). Все вкладки исполняемого файла -- в статье [«Карточка редактирования исполняемого файла»](./../../usage/gizmo-manager/stations/prilozheniya/kartochka-redaktirovaniya-ispolnyaemogo-fayla/_index.md).

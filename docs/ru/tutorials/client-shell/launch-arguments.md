Справочник к инструкции [«Как добавить игру в клиентскую оболочку»](./add-app-to-shell.md): что указывать в полях **Путь к исполняемому файлу**, **Аргументы** и **Рабочий каталог** исполняемого файла, чтобы игра из лаунчера или системное приложение запускались из Gizmo Client.

Все поля исполняемого файла -- в статье [«Карточка редактирования исполняемого файла»](./../../usage/gizmo-manager/stations/prilozheniya/kartochka-redaktirovaniya-ispolnyaemogo-fayla/_index.md).

> [!IMPORTANT]
>
> Приложение должно быть установлено по одному и тому же пути на всех клиентских пк. Если на разных пк пути отличаются, создайте отдельный исполняемый файл для каждого пути.

## Игры из лаунчеров

Для игр из лаунчеров в **Пути к исполняемому файлу** указывается файл **лаунчера**, а не самой игры: лаунчер получает команду из поля **Аргументы** и запускает нужную игру. **Рабочий каталог** -- папка лаунчера; если оставить поле пустым, она обычно подставляется при сохранении.

Ниже `<ID>` -- идентификатор игры в лаунчере: подставьте его без угловых скобок.

| Лаунчер | Путь к исполняемому файлу | Аргументы |
|---|---|---|
| Steam | `...\Steam\steam.exe` | `steam://rungameid/<ID>` |
| Epic Games | `...\Epic Games\Launcher\Portal\Binaries\Win64\EpicGamesLauncher.exe` | `com.epicgames.launcher://apps/<ID>?action=launch&silent=false` |
| Riot Games | `...\Riot Client\RiotClientServices.exe` | `--launch-product=<ID> --launch-patchline=live` |
| Ubisoft Connect | `...\Ubisoft Game Launcher\UbisoftConnect.exe` | `uplay://launch/<ID>` |
| VK Play | `...\GameCenter\GameCenter.exe` | `vkplay://play/<ID>` |
| Battle.net | `...\Battle.net\Battle.net Launcher.exe` | Не указываются -- лаунчер не поддерживает запуск игры по аргументу |

### Steam

ID игры -- число в адресной строке на странице игры в магазине Steam. Например, у Counter-Strike 2 ID `730`, аргумент -- `steam://rungameid/730`.

Свои ключи запуска игры (те, что вы указывали в свойствах игры в Steam) добавьте после ID через пробел:

```
steam://rungameid/730 -language "russian" -novid -w 1280 -h 1080
```

### Epic Games

Указывайте лаунчер из папки **Win64**, а не Win32.

Как узнать аргумент:

1. В лаунчере откройте библиотеку, нажмите на три точки у игры и выберите **Управление -> Создать ярлык**. Пункт доступен, только если игра установлена.
2. На рабочем столе нажмите правой кнопкой мыши на созданный ярлык и выберите **Свойства -> Веб-документ**.
3. Значение поля **URL-адрес** -- это и есть аргумент.

### Riot Games

ID -- название игры строчными буквами, пробелы заменяются нижним подчёркиванием:

- League of Legends -- `--launch-product=league_of_legends --launch-patchline=live`;
- Valorant -- `--launch-product=valorant --launch-patchline=live`.

### Ubisoft Connect и VK Play

1. Создайте ярлык игры на рабочем столе -- в VK Play: страница игры в лаунчере -> дополнительное меню -> **Создать ярлык на рабочем столе**.
2. Нажмите на ярлык правой кнопкой мыши и выберите **Свойства**.
3. Значение поля **URL-адрес** -- это и есть аргумент.

## Приложения из Microsoft Store

**Способ 1 -- через ярлык**

1. Откройте меню **Пуск**, найдите приложение и перетащите его значок на рабочий стол -- появится ярлык.
2. Положите ярлык в одинаковую папку на всех клиентских пк.
3. В **Пути к исполняемому файлу** укажите путь к ярлыку (файл `.lnk`) и включите **Shell Execute**.

**Способ 2 -- через проводник** (работает не со всеми приложениями)

1. Создайте ярлык приложения, как в способе 1, откройте его **Свойства** и скопируйте значение **Тип объекта** -- например, `Microsoft.WindowsStore_8wekyb3d8bbwe!App`.
2. Заполните поля исполняемого файла:
   - **Путь к исполняемому файлу** -- `%windir%\explorer.exe`;
   - **Аргументы** -- `shell:AppsFolder\<тип объекта>`;
   - **Рабочий каталог** -- `%windir%`.

| Приложение | Путь к исполняемому файлу | Аргументы | Рабочий каталог |
|---|---|---|---|
| Discord | `%LocalAppData%\Discord\Update.exe` | `--processStart Discord.exe` | `%LocalAppData%\Discord` |
| Панель управления NVIDIA | `C:\Windows\explorer.exe` | `shell:AppsFolder\NVIDIACorp.NVIDIAControlPanel_56jybvy8sckqj!NVIDIACorp.NVIDIAControlPanel` | `C:\Windows\` |
| Параметры мыши Windows | `C:\Windows\system32\control.exe` | `Main.cpl` | `C:\Windows\system32\` |
| Параметры звука Windows | `C:\Windows\system32\control.exe` | `mmsys.cpl` | `C:\Windows\system32\` |

>
> Параметры мыши и звука открываются через панель управления. Если в профиле безопасности включено **Prohibit access to Control Panel and PC settings**, они не откроются -- см. [«Карточка профиля безопасности»](./../../usage/gizmo-manager/stations/profili-bezopasnosti/kartochka-redaktirovaniya-profilya-bezopasnosti.md).

## Частые вопросы

**Как запустить приложение не от имени администратора?**

По умолчанию Gizmo запускает приложения с правами администратора. Чтобы запустить приложение с обычными правами, запускайте его через проводник:

- **Путь к исполняемому файлу** -- `C:\Windows\explorer.exe`;
- **Аргументы** -- путь к файлу приложения, например `C:\Program Files\FACEIT AC\faceitclient.exe`;
- **Рабочий каталог** -- `C:\Windows\`.

**Можно ли запускать не .exe-файлы?**

Да: `.bat`, `.lnk` (ярлыки) и любые другие файлы, которые Windows умеет открывать. Для этого включите у исполняемого файла **Shell Execute** -- тогда система сама выберет, чем открыть файл.

**Что делать, если в пути есть имя пользователя Windows?**

Используйте переменные среды -- Windows сама подставит нужный путь. Например, `%LocalAppData%` означает `C:\Users\<имя пользователя>\AppData\Local`, `%AppData%` -- `C:\Users\<имя пользователя>\AppData\Roaming`.

Как подключить к игре клубные аккаунты лаунчера -- в инструкции [«Как настроить клубные аккаунты в лаунчерах»](./club-licenses.md).

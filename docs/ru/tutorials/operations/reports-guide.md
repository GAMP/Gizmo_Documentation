Отчёты -- это аналитика клуба: выручка, загрузка станций, продажи по категориям, работа операторов. То, на что стоит смотреть регулярно, а не только когда что-то пошло не так.

## С каких отчётов начать

Для владельца обычно важнее всего финансовый отчёт -- сколько заработали за смену, день, месяц, и за счёт чего (почасовая оплата, пакеты, товары). Дальше уже интересны отчёты по загрузке станций (какие места и зоны реально приносят деньги) и по операторам (кто на какую смену продал больше всего).

## Автоматическая рассылка отчётов

Отчёты не обязательно открывать вручную каждый раз -- можно настроить автоматическую рассылку на почту по расписанию, чтобы, например, утренний отчёт о вчерашнем дне приходил сам. Настраивается в <cmd text="Настройки"/> -> <cmd text="Отправка отчётов"/>.

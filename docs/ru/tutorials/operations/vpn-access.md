Чтобы контролировать клуб из дома, нужно открывать Gizmo Manager на домашнем пк. Если пробросить порт на роутере клуба нельзя (например, у провайдера серый IP-адрес) или вы не знаете, как это сделать, подойдёт VPN: он объединяет домашний пк и сервер клуба в одну виртуальную сеть.

Подойдёт любое приложение для туннелирования. Ниже -- два популярных у клиентов Gizmo варианта: **Radmin VPN** и **ZeroTier**. Выберите один.

> [!WARNING]
>
> Поддержка Gizmo не отвечает за доступность и работу этих сервисов и не помогает с их настройкой. Они приведены только как пример.

> [!IMPORTANT]
>
> Приложение должно быть постоянно запущено и на сервере, и на пк, с которого вы подключаетесь. Не давайте доступ к созданной сети посторонним -- через неё можно попасть к данным клуба.

<tabs>

<tab name="Radmin VPN">

**На сервере** (или на пк администратора, если Gizmo Server установлен на нём):

1. [Скачайте Radmin VPN](https://www.radmin-vpn.com/ru/), установите и запустите.
2. Нажмите **Сеть -> Создать сеть**.
3. Укажите название и пароль сети. Пароль задайте сложный -- любой, кто подключится к сети, получит доступ к серверу.
4. Нажмите **Создать** -- сеть появится в интерфейсе.

**На пк, с которого подключаетесь:**

1. Установите и запустите Radmin VPN.
2. Нажмите **Сеть -> Присоединиться к сети -> Частная сеть** и введите название и пароль сети.
3. В списке появится сервер. Нажмите на него правой кнопкой мыши и выберите **Копировать IP-адрес**.

</tab>

<tab name="ZeroTier">

**На сервере** (или на пк администратора, если Gizmo Server установлен на нём):

1. [Скачайте ZeroTier](https://download.zerotier.com/dist/ZeroTier%20One.msi), установите и запустите из меню «Пуск». Окно не откроется -- это нормально.
2. Откройте [my.zerotier.com](https://my.zerotier.com/), войдите (например, через Google) и нажмите **Create a Network**.
3. Откройте созданную сеть и скопируйте её ID.
4. В трее Windows нажмите на иконку ZeroTier, включите **Start UI at Login** и выберите **Join New Network...**.
5. Вставьте ID сети и нажмите **Join**.

**На пк, с которого подключаетесь:**

1. Установите и запустите ZeroTier.
2. В трее нажмите на иконку ZeroTier, включите **Start UI at Login**, выберите **Join New Network...**, вставьте тот же ID сети и нажмите **Join**.

**Авторизуйте оба пк в сети:**

1. Откройте сеть в [личном кабинете ZeroTier](https://my.zerotier.com/) и дождитесь, пока в списке появятся оба устройства. Если какого-то нет, подождите минуту и обновите страницу.
2. Отметьте оба устройства флажками и нажмите **Authorize**.
3. Через минуту обновите страницу -- у устройств появятся внутренние IP-адреса.
4. Найдите сервер: сравните поле **Address** в списке со значением **My Address** в ZeroTier на сервере (трей -> иконка ZeroTier). Скопируйте IP-адрес сервера из поля **Managed IPs**.

</tab>

</tabs>

## Откройте Gizmo Manager

На пк, с которого подключаетесь, откройте в браузере адрес `http://<IP сервера в VPN>/apps/manager/signin`, например `http://26.12.34.56/apps/manager/signin`. Если в настройках сети сервера задан нестандартный порт, укажите его после IP через двоеточие.

Если страница входа открылась -- подключение работает. Если нет, проверьте, что VPN-приложение запущено на обоих пк и что Gizmo Server работает, и повторите шаги.

Чтобы открывать Gizmo Manager как обычную программу, без адресной строки, -- см. инструкцию [«Gizmo Manager как приложение»](./../gizmomanager-as-an-app.md).

## Результат

Домашний пк и сервер клуба находятся в одной виртуальной сети, и Gizmo Manager открывается из любого места, где есть интернет.

Другой способ доступа из интернета -- проброс портов на роутере, см. статью [«Проброс портов -- как и зачем»](./../../articles/port-forwarding.md).

Раздел задаёт почтовый сервер, через который Gizmo отправляет письма: подтверждения регистрации, уведомления и отчёты по расписанию. Без этих настроек почта из системы уходить не будет. Раздел открывается в «Настройки» → «Сервер» → «Настройки SMTP».



<note type="hotfixes" title="Перечень определений" collapsed="true">

-  **Включить** -- переключатель, отвечающий за то, пользуется ли Gizmo почтой вообще.

-  **SMTP Host** -- адрес почтового сервера, через который отправляются письма.

-  **Порт SMTP** -- порт этого сервера. По умолчанию подставляется **465** -- порт защищённого соединения.

-  **Безопасность SMTP** -- способ шифрования соединения. По умолчанию **SSL**.

-  **Ответить на адрес** -- адрес, который получатель увидит в поле «Кому ответить». На него придут ответы гостей на письма от клуба.

-  **SMTP аутентификация** -- переключатель. Включается, если почтовый сервер требует представиться, прежде чем принять письмо. Большинство внешних почтовых служб этого требуют.

Изменения вступают в силу по кнопке <cmd text="Сохранить"/>, отменяются -- по <cmd text="Отмена"/>.

</note>

<note type="hotfixes" title="Влияние на систему" collapsed="true">

-  Пока переключатель **Включить** выключен, остальные поля значения не имеют.

-  Настроенный здесь сервер используется интеграцией **Системный SMTP** -- той самой, через которую Gizmo рассылает электронную почту. Если интеграция добавлена, а SMTP не настроен, письма уходить не будут: интеграция берёт параметры отсюда, а не хранит свои.

</note>

<note type="hotfixes" title="Заключение" collapsed="true">

Порядок такой: сначала заполните этот раздел, затем добавьте интеграцию «Системный SMTP» в разделе «Плагины» -- см. [«Добавление интеграции»](./plugins/add-new-plugin.md).

</note>

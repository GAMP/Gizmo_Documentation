Настройки сервера находятся в разделе **«Сервер»** в общих настройках Gizmo Manager. Здесь собраны параметры, которые определяют работу вашего Gizmo Server: от пользовательских атрибутов и переменных окружения до сети и резервного копирования.



<note type="hotfixes" title="Перечень определений" collapsed="true">

Раздел состоит из следующих подразделов:

-  [Атрибуты](./attributes/_index.md) -- дополнительные поля для объектов Gizmo.

-  [Компаньоны](./companions/_index.md) -- подключение Gizmo Companion к серверу.

-  [Переменные](./variables/_index.md) -- переменные окружения для приложений Gizmo.

-  [Плагины и интеграции](./plugins/_index.md) -- сторонние плагины и интеграции.

-  [Сеть](./network.md) -- сетевые настройки и доступ к серверу.

-  [Резервная копия](./backup.md) -- автоматическое резервное копирование базы данных.

-  [Настройки SMTP](./communication-methods.md) -- почтовый сервер, через который Gizmo отправляет электронную почту.

</note>

<note type="hotfixes" title="Влияние на систему" collapsed="true">

> [!NOTE]
>
> Данный раздел находится в разработке.

</note>

<note type="hotfixes" title="Заключение" collapsed="true">

Раздел «Сервер» объединяет параметры, от которых зависит работа Gizmo Server.

</note>

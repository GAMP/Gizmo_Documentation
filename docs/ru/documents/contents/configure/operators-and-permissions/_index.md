Настройки операторов и прав доступа находятся в разделе **«Операторы и настройки прав доступа»** в общих настройках Gizmo Manager.

Здесь управляются учётные записи сотрудников, работающих в Gizmo Manager, и наборы разрешений, которые определяют, какие действия им доступны.



<note type="hotfixes" title="Перечень определений" collapsed="true">

Раздел состоит из следующих подразделов:

-  [Операторы](./operators/_index.md) -- учётные записи сотрудников.

-  [Права доступа](./permissions/_index.md) -- предустановки разрешений для операторов.

</note>

<note type="hotfixes" title="Влияние на систему" collapsed="true">

-  Набор разрешений, назначенный оператору, определяет, какие действия ему доступны в Gizmo Manager.

</note>

<note type="hotfixes" title="Заключение" collapsed="true">

Раздел позволяет завести учётные записи сотрудников для работы в Gizmo Manager и ограничить их действия с помощью предустановок прав доступа.

</note>

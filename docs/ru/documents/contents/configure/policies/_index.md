Политики находятся в разделе **«Политики»** в общих настройках Gizmo Manager. Здесь настраиваются правила, которые управляют доступом пользователей и автоматизированными процессами: очередь ожидания, возрастные ограничения, бронирование, рассылка отчётов и причины бана.



<note type="hotfixes" title="Перечень определений" collapsed="true">

Раздел состоит из следующих подразделов:

-  [Очередь ожидания](./queue.md) -- поведение очереди на хост, когда все компьютеры заняты.

-  [Возрастные ограничения](./age-restrictions.md) -- ограничения доступа по возрасту пользователя.

-  [Бронирования](./reservations.md) -- правила бронирования хостов.

-  [Отправка отчётов](./report-schedule/_index.md) -- автоматическая доставка отчётов операторам.

-  [Причины бана](./ban-reasons/_index.md) -- причины блокировки пользователей.

</note>

<note type="hotfixes" title="Влияние на систему" collapsed="true">

> [!NOTE]
>
> Данный раздел находится в разработке.

</note>

<note type="hotfixes" title="Заключение" collapsed="true">

Раздел «Политики» собирает в одном месте правила доступа пользователей и автоматизированных процессов Gizmo.

</note>

---
title: Карточка товара
order: 1
---

Карточка открывается при создании товара кнопкой <cmd text="Создать товар"/> либо двойным нажатием на строку в списке [товаров](./_index.md). Состоит из блоков: описание, медиа, доступность, ценообразование, награда, склад и расписание продаж.



<note type="hotfixes" title="Перечень определений" collapsed="true">

### Описание

-  **Имя** -- наименование позиции. Обязательное поле.

-  **Описание** -- пояснение для пользователя, отображается в клиентской оболочке.

-  **Товарная группа** -- группа, определяющая размещение позиции на экране кассира. Обязательное поле.

-  **Это услуга** -- признак позиции без физического остатка.

-  **Является акцизом** -- признак подакцизного товара.

-  **Имеет маркировку товара** -- признак товара, подлежащего обязательной маркировке.

### Медиа

Обложка позиции для клиентской оболочки. Рекомендуемый размер -- **400 × 444 пикселя**. Изображение перетаскивается в поле либо выбирается кнопкой <cmd text="Добавить обложку"/>.

### Доступность

-  **По филиалу** -- перечень филиалов с отметкой **Включить**.

-  **Показать в клиентской оболочке** -- определяет, доступна ли позиция пользователю на игровом месте.

-  **Доступность для групп пользователей** -- перечень групп, которым доступна позиция. Отдельной строкой выведены **Незарегистрированные**, остальные группы добавляются кнопкой <cmd text="Добавить"/>.

### Ценообразование

-  **Цена** -- цена продажи. Обязательное поле.

-  **Выбор** и **И** -- условие оплаты: деньгами, баллами либо и тем и другим.

-  **Баллы** -- стоимость позиции в баллах.

-  **Налог** -- налоговая ставка, применяемая к позиции.

### Награда

-  **Баллы** -- количество баллов, начисляемых пользователю за покупку.

### Склад

-  **Штрихкод** -- код для сканера.

-  **Складской учет** -- включает списание позиции со склада при продаже.

### Расписание продаж

-  **Диапазон дат** -- поля **Дата начала** и **Дата конца**, ограничивающие период продажи.

-  **Диапазон времени** -- часы в течение суток, когда позиция доступна.

</note>

<note type="hotfixes" title="Влияние на систему" collapsed="true">

-  Позиция продаётся только в филиалах, отмеченных в блоке **По филиалу**.

-  Без отметки **Показать в клиентской оболочке** товар доступен только кассиру.

-  Изменения сохраняются кнопкой <cmd text="Сохранить"/>. До сохранения карточка выводит предупреждение о несохранённых изменениях.

</note>

<note type="hotfixes" title="Заключение" collapsed="true">

Карточка товара объединяет все параметры позиции: описание, медиа, доступность, ценообразование, награду, складской учёт и расписание продаж.

</note>

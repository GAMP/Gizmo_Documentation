Раздел предназначен для настройки объявлений, скидок, акций и соревновательных механик. Раздел разделён на восемь вкладок, первой открывается **Новости**.

Раздел открывается кнопкой <cmd text="Маркетинг" /> в левом меню.



<note type="hotfixes" title="Перечень определений" collapsed="true">

### Вкладки

-  [**Новости**](./news.md) -- объявления, отображаемые в клиентской оболочке. По каждой новости выводятся название, признак публикации, даты начала и окончания показа и ссылка на подробности. Создаются кнопкой <cmd text="Создать новость" />.

-  [**Каналы**](./feeds.md) -- источники, по которым распределяются новости: например, отдельно общеклубные объявления и отдельно сообщения для конкретной зоны.

-  [**Достижения**](./achievements/_index.md) -- достижения пользователей.

-  **Лестница** -- настройка уровней привилегий: правила, по которым пользователи переходят из одной группы в другую. Подробнее -- в статье [«Уровни привилегий»](./lader/_index.md).

-  [**Испытания**](./challenges/_index.md) -- задания, за выполнение которых начисляется награда.

-  [**Скидки**](./discounts/_index.md) -- правила снижения цены.

-  [**Группы скидок**](./discount-groups/_index.md) -- наборы скидок, назначаемые группам пользователей целиком.

-  [**Акции**](./promotions.md) -- предложения, ограниченные сроком действия.

</note>

<note type="hotfixes" title="Влияние на систему" collapsed="true">

-  Заданные в разделе параметры передаются в Gizmo Client и отображаются пользователю на игровом месте.

-  Скидка применяется при продаже в разделе [«Касса»](./../tochka-prodazh/_index.md).

</note>

<note type="hotfixes" title="Заключение" collapsed="true">

Раздел «Маркетинг» объединяет объявления, скидки, акции и соревновательные механики для пользователей клуба.

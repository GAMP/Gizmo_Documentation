---
title: Меню оператора
order: 3
---

Меню оператора открывается нажатием на аккаунт оператора в правом верхнем углу.



<note type="hotfixes" title="Перечень определений" collapsed="true">

Доступны следующие действия:

-  **Изменить пароль** -- меняет пароль оператора.

-  **Переключить тему** -- переключает тему приложения.

-  **Выйти** -- выходит из аккаунта оператора.

</note>

<note type="hotfixes" title="Влияние на систему" collapsed="true">

> [!NOTE]
>
> Данный раздел находится в разработке.

</note>

<note type="hotfixes" title="Заключение" collapsed="true">

Меню оператора позволяет управлять собственной учётной записью: сменить пароль, переключить тему приложения или выйти из аккаунта.

</note>

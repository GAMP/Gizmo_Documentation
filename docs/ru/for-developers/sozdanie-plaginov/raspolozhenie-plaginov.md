title: Расположение плагинов
order: 1
---

Плагины Gizmo Server -- это библиотеки `.dll`, которые лежат в папке `plugins` в каталоге установки сервера. На Windows по умолчанию это `C:\Program Files\NETProjects\Gizmo Server\plugins`.

Чтобы установить плагин:

1. Скопируйте файл плагина в папку `plugins`.
2. Перезапустите Gizmo Server -- см. инструкцию [«Как перезапустить сервер Gizmo»](./../../tutorials/operations/server-restart.md). Сервер загружает плагины только при запуске.
3. Проверьте, что плагин появился и включён в **Настройки -> Сервер -> Плагины** -- см. статью [«Плагины и интеграции»](./../../configure/server/plugins/_index.md).

Чтобы удалить плагин, остановите сервер, уберите файл из папки `plugins` и запустите сервер снова.

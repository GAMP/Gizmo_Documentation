Gizmo Server предоставляет Web API для интеграции со сторонними системами: например, чтобы выгружать данные о пользователях, продажах и счетах в свои отчёты или Excel.

Описание всех конечных точек (Swagger) открывается из Gizmo Manager: **Настройки -> Другое -> О программе**, блок **Модули** -> **Модуль API**. Подробнее -- в статье [«О программе»](./../configure/others/about.md).

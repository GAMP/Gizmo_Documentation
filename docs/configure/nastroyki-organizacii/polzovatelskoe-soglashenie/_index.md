---

В данном разделе вы можете создать и настроить Пользовательские соглашения.

Как правило, для клиентов создают 2 и более соглашений. Например, «Правила клуба» и «Соглашение о конфиденциальности».

> [!NOTE]
> 
> Пользовательские соглашения отображаются при авторизации клиента в Gizmo Client. Правила отображения задаются в[ карточке пользовательского соглашения.](./kartochka-polzovatelskogo-soglasheniya.md)

Для создания пользовательского соглашения нажмите на кнопку **«Добавить»** в правом углу странице.

> [!NOTE]
> 
> С описанием карточки пользовательского соглашения мы можете ознакомиться на странице [«Карточка пользовательского соглашения»](./kartochka-polzovatelskogo-soglasheniya.md).

В данном разделе отображается таблица с уже созданными вами  пользовательскими соглашениями.

Таблица отображает:

-  порядок показа пользовательского соглашения;

-  название пользовательского соглашения;

-  правила показа пользовательского соглашения;

-  статус (включено/выключено для показа).

Таблица позволяет:

-  изменить порядок показа пользовательского соглашения для клиента (управляется через перетаскивание мышкой элемента ::: );

-  включить/выключить отображение пользовательского соглашения;

-  перейти в карточку пользовательского соглашения (двойной клик мышкой по строке).

> [!WARNING]
> 
> Пользовательские соглашения являются общими для всех филиалов. Это означает что все активные пользовательские соглашения отображаются во всех филиалах.

order: 1
title: Карточка пользовательского соглашения
---

Карточка пользовательского соглашения включает в себя:

-  статус отображения пользовательского соглашения в Gizmo Client;

-  название;

-  текст пользовательского соглашения;

-  правила отображения пользовательского соглашения.

Вы можете изменить статус отображения выбранного пользовательского сошглашения чере тумблер «Статус».

<note type="tip">

Текст пользовательского соглашения поддерживает HTML разметку.

Вы можете создать форматированный теккст в любом Online-редакторе, например [editorhtmlonline.com](https://editorhtmlonline.com/ru/) и затем вставить полученный HTML-код в поле для текста пользовательского соглашения.

</note>

Для пользовательского соглашения доступны следующие правила отображения в Gizmo Client:

-  Обязательно (отображается при авторизации клиента в Gizmo Client, клиент не имеет доступ к функциям Gizmo Client пока не подтвердит свое согласие с пользовательским соглашением. Пользовательское соглашение более не будет показываться клиенту при последующих авторизациях)

-  Опционально  (отображается при авторизации клиента в Gizmo Client, клиент  имеет возможность пропустить ознакомление с пользовательским соглашением и получить доспуп к функциям Gizmo Client. Пользовательское соглашение более не будет показываться клиенту при последующих авторизациях);

-  Всегда показывать (отображается при каждой авторизации клиента в Gizmo Client).

Вы можете удалить выбранное пользовательское соглашения, нажав на кнопку «Удалить» в правом нижнем углу.

<note type="danger">

При внесении изменений в пользовательское соглашение не забывайте нажать кнопку «Сохранить» в правом верхнем углу.

</note>

Open this page in **Settings -> Others -> Action Center**. Here you set up Gizmo Manager sound notifications -- for example, for new guest orders or for guests logging out.

For each sound you can:

-  turn it on or off;

-  upload your own sound file instead of the default one.

> [!NOTE]
>
> The list of sounds and the events they are linked to will be added later.

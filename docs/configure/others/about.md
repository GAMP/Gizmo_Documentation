This page shows general information about Gizmo and links to related resources. Open it in **Settings -> Others -> About**.

## Modules

The list of additional system modules, with links to their settings or documentation:

-  **User Registration Portal** -- a web portal where users sign up on their own.

-  **API Module** -- the interface for integrating Gizmo with third-party systems. From here you open the API description (Swagger).

## Downloads

Download links for the system components:

-  **Gizmo Client** -- the client app installed on hosts.

-  **Gizmo Companion** -- the Gizmo Companion app.

## Resources

-  **Gizmo Documentation** -- a link to the official Gizmo documentation.

## Version

Shows the current version of the installed Gizmo Server and Gizmo Manager. Use it to check whether you need an update -- see [How to update Gizmo](./../../tutorials/operations/update-gizmo.md).

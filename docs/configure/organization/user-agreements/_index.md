**IMAGE: the Settings -> Organization -> User agreements page with the table of agreements**

Here you create and set up user agreements.

Clubs usually create two or more agreements for guests -- for example, "Club rules" and "Privacy policy".

> [!NOTE]
> 
> User agreements are shown when a guest signs in to Gizmo Client. The display rules are set in the [user agreement card](./user-agreement-card.md).

To create an agreement, click <cmd text="Create User Agreement"/> in the corner of the page.

The section shows a table of the agreements you have created:

| Column    | Description                                        |
|-----------|----------------------------------------------------|
| Name      | the name of the user agreement                     |
| Consent   | whether the guest must accept this document        |
| Enable    | whether the agreement is shown to the guest        |

In the table you can:

-  change the order in which agreements are shown -- drag a row by the drag handle <icon code="grip-vertical" /> on the left; the table has no separate order column;

-  turn the display of an agreement on and off;

-  open the agreement card -- double-click its row.

> [!WARNING]
> 
> User agreements are shared by all branches: all active agreements are shown in every branch.

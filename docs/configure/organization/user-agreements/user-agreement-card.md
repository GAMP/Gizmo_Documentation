**IMAGE: the user agreement card with the Status switch, name, agreement text and display rules**

The user agreement card contains:

-  the display status of the agreement in Gizmo Client;

-  the name;

-  the text of the user agreement;

-  the display rules of the agreement.

To change the display status of the agreement, use the **Status** switch.

> [!TIP]
> 
> The text of the user agreement supports HTML markup.
>
> You can format the text in any online editor, for example [editorhtmlonline.com](https://editorhtmlonline.com/), and then paste the resulting HTML code into the agreement text field.

These display rules are available for an agreement in Gizmo Client:

-  **Required** -- the agreement is shown when the guest signs in, and the guest cannot use Gizmo Client until they accept it. It is not shown again at later sign-ins.

-  **Optional** -- the agreement is shown at sign-in, but the guest can skip it and use Gizmo Client right away. It is not shown again at later sign-ins.

-  **Always show** -- the agreement is shown every time the guest signs in.

To delete the agreement, click <cmd text="Delete"/> in the bottom right corner.

**IMAGE: the branch card with the Branch Address, Organization Information, Work Schedule and Regional Settings groups**

The branch card opens when you create or edit a branch.

To deactivate a branch, click the button at the bottom of the card.

The branch card has these groups of settings:

-  **Branch address** -- country/region, address, postal code, city, phone.

-  **Organization information** -- branch name, organization name, email, website.

-  **Work schedule**.

-  **Regional settings** -- time zone.

> [!NOTE]
> 
> All groups of settings except **Branch address** duplicate the global server settings, and you can override them in the branch card. This is useful when a branch's settings differ from the general ones: for example, when the branch legally belongs to another organization.

To reset the branch settings to the global ones, click the button in the corner of the settings group.

For a detailed description of organization information, work schedule and regional settings, see [General](./../general.md).

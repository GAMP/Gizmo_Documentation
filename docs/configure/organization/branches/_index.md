**IMAGE: the Settings -> Organization -> Branches page with the status filter and the branch mini cards**

Here you set up the branches of your chain.

**We recommend hosting no more than 15 branches on one server.**

> [!NOTE]
> 
> If a chain of more than 15 branches needs a single user database, consider the [Single auth plugin](./../../../plugins/single-auth-plugin.md) for several servers.

In this section you can:

-  create a new branch with the button on the right side of the section;

-  filter branches by status (all, active, inactive);

-  view the branch mini cards with the name, address (if filled in), working hours, status and number of hosts.

To view or edit a branch, click its [branch card](./branch.md).

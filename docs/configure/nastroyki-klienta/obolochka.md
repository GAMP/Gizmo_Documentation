> 
> Для применения настроек данного раздела требуется перезагрузка Gizmo Client.

## Общие настройки

Общие настройки - это ключевые настройки оболочки Gizmo Client.

К Общим настройкам относятся:

-  Язык оболочки

-  Действие при выходе из системы

-  Путь к данным клиента

-  Пароль менеджера

-  Энергосбережение

### Язык оболочки

**Язык оболочки** - язык оболочки Gizmo Client.

### Действие при входе в систему

**Действие при входе в систему** - действие, которое будет выполнено после завершения пользовательского сеанса.

Возможны следующие варианты для выбора:

-  Без действий

-  Перезагрузка

-  Закрытие всех программ

-  Выключение

-  Завершение сеанса

-  Переход в режим ожидания

-  Переход в режим администратора

### Путь к данным клиента

**Путь к данным клиента** - путь, по которому на компьютере с установленным Gizmo Client хранятся мета-данные Gizmo Client.

Значение по умолчанию - *%PROGRAMDATA%\\NETProjects\\Gizmo Client\\*

### Пароль менеджера

Пароль менеджера - пароль, введя который в специальном скрытом окне Gizmo Client можно войти в режим обслуживания Gizmo Client, в котором доступны следующие действия:

-  Свернуть оболочку Gizmo Client

-  Деактивировать Gizmo Client

-  Удалить Gizmo Client

> [!TIP]
> 
> Подробнее о режиме обслуживания Gizmo Client можно узнать в разделе Gizmo Client - Режим обслуживания

Пароль менеджера по умолчанию - password

### Энергосбережение

**Энергосбережение** - опция, отвечающая за поведение компьютера, на котором установлен Gizmo Client, при простое компьютера.

Включив данную опцию, вы можете задать параметры работы режима энергосбережения, а именно:

-  Действие при простое

-  Триггерное время

**Триггерное время**   - время простоя (в минутах), после которого будет выполнено настроенное действие.

**Действие при простое** - действие, которое будет принято по окончании триггерного времени. Возможны следующие варианты:

-  Завершение опция, включив которую, клиенту в Gizmo Client становится доступен экран самостоятельной регистрации. работы

-  Спящий режим

## Настройки клиентских сессий

**Настройки клиентских сессий** - настройки, отвечающие за поведение Gizmo Client во время активной клиентской сессии в Gizmo Client.

В данном разделе доступны следующие опции:

-  Автоматический повторный вход пользователей

-  Автоматический повторный вход гостей

-  Завершение ожидающих сессий

-  Выход из системы отключенных клиентов

-  Время ожидания

**Автоматический повторный вход пользователей -** автоматический вход клиентов, относящихся к пользовательским группам пользователей, в Gizmo Client после аварийной перезагрузки компьютера, на котором установлен Gizmo Client.

**Автоматический повторный вход гостей -** автоматический вход клиентов, относящихся к гостевым группам пользователей, в Gizmo Client после аварийной перезагрузки компьютера, на котором установлен Gizmo Client.

**Завершение ожидающих сессий -** опция, позволяющая автоматически завершать сеанс клиента в Gizmo Server и Gizmo Manager, в случае потери соединения между Gizmo Server и Gizmo Client.

**Выход из системы отключенных клиентов** -  опция, позволяющая автоматически завершать сеанс клиента в Gizmo Client, в случае потери соединения между Gizmo Server и Gizmo Client.

**Время ожидания.** В случае, если сетевое соединение между Gizmo Server и Gizmo Client разорвано и включена одна из двух вышеуказанных опций («**Выход из системы отключенных клиентов**» или «**Завершение ожидающих сессий**»), то **время ожидания -**  это допустимое время  разрыва соединения (в секундах) после которого будет выполнено завершение сессий клиента в Gizmo Client (в случае активной опции «**Выход из системы отключенных клиентов**») и в Gizmo Server и Gizmo Manager (в случае активной опции «**Завершение ожидающих сессий**»).

По умолчанию значение данного параметра - 180 секунд.

> [!WARNING]
> 
> Для применения опций «**Время ожидания**», «**Выход из системы отключенных клиентов**» и «**Завершение ожидающих сессий**» требуется перезагрузка Gizmo Client.

## Настройки экрана регистрации пользователей

**Настройки экрана регистрации пользователей** - настройки, связанные с экраном регистрации пользователей. В данном разделе доступны следующие опции:

-  Регистрация пользователей

-  Подтверждения регистрации

-  Восстановление пароля

-  Длина и тип символов для кода подтверждения

### Регистрация пользователей

В данном подразделе доступны следующие опции:

-  Регистрация с Gizmo Client

-  Регистрация на веб-портале

**Регистрация с Gizmo Client** - опция, включив которую, клиенту в Gizmo Client становится доступен экран самостоятельной регистрации.

**Регистрация на веб-портале** -  опция, включив которую, клиенту на веб-портале самостоятельной регистрации становится доступен экран самостоятельной регистрации.

### **Подтверждение регистрации**

В данном подразделе доступно включение опции **«Подтвержедие регистрации»**. Включение данной опции означает, что при регистрации клиента в Gizmo Client будет запрошена верификация email или телефона клиента.

Выбор метода подтверждения регистрации (email или телефон) становится доступен сразу после включения вышеуказанной опции.

> [!WARNING]
> 
> Не задудьте настроить «Способы коммуникации» для выбранного вами метода верификации.

### Восстановление пароля

В данном подразделе доступно включение опции **«Восстановление пароля»**. Включение данной опции означает, что на экране регистрации клиента в Gizmo Client будет доступен экран восстановления пароля.

Выбор метода востановления пароля (email или телефон) становится доступен сразу после включения вышеуказанной опции.

> [!WARNING]
> 
> Не задудьте настроить «Способы коммуникации» для выбранного вами метода верификации.

### Длина и тип символов для кода подтверждения

**Длина и тип символов для кода подтверждения** - опции, отвечающие за длину и состав кодов подтверждения, которые могут быть использованы для восстановления пароля клиента в Gizmo Client.

Максимально возможная длина кода восстановления - 6 символов.

Опции для состава кода восстановления:

-  Заглавные буквы

-  Цифры

-  Заглавные буквы и цифры

## Системные настройки

**Системные настройки** - настройки, связанные системным поведением Gizmo Client.

К системным настройкам относятся:

-  Автоматическое обновление оболочки

-  Автоматическое понижение версии оболочки

-  Запуск bat-скриптов на компютерах

**Автоматическое обновление оболочки**. В случае, если при обновлении на новую версию Gizmo Server требуется обновление Gizmo Client, то, при включении данной опции, обновление Gizmo Client будет происходить автоматически.

**Автоматическое понижение версии оболочки.** В случае, если при обновлении на старую версию Gizmo Server требуется даунгрейд Gizmo Client, то, при включении данной опции, даунрейд Gizmo Client будет происходить автоматически.

**Запуск bat-скриптов на компютерах** - опция, отвечающая за возможность запуска bat-скриптов на компьютере с запущенным Gizmo Client.

## Настройки для приложений

**Настройки для приложений** - настройки, связанные с запуском приложений через Gizmo Client.

Доступные настройки:

-  Ограничить одновременный запуск нескольких приложений

**Ограничить одновременный запуск нескольких приложений** - данная опция управляет возможностью одновременного запуска клиентом нескольких приложений одновременно. При включенной опции одновременный запуск двух и более приложений в Gizmo Client невозможен.

## Настройки льготного периода пополнения

**Льготный период пополнения**. При включении данной опции, клиенту с активной сессией, у которого закончилось время, будет показан таймер обратного отсчета с  сообщением о необходимости пополнения баланса/покупки времени. В случае, если за отведенный период времени клиент успевает пополнить баланс - его сессия продолжается, в противном случае происходит разлогин клиента.

**Время льготного периода.** Параметр появляется в случае включения вышеуказанной опции. Параметр задает время в минутах для **Льготного периода пополнения.**

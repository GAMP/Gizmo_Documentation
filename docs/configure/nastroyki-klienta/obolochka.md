В данном разделе отображаются настройки оболочки для Gizmo Client, а именно:

-  Общие настройки

-  Настройки клиентских сессий

-  Настройки регистрации пользователей

-  Системные настройки

-  Настройки для приложений

-  Настройки льготного периода пополнения

-  Требования к пользовательским паролям

> [!WARNING]
> 
> Для применения настроек данного раздела требуется перезагрузка Gizmo Client.

## Общие настройки

Общие настройки - это ключевые настройки оболочки Gizmo Client.

К Общим настройкам относятся:

-  Язык оболочки

-  Действие при выходе из системы

-  Путь к данным клиента

-  Пароль менеджера

-  Энергосбережение

### Язык оболочки

**Язык оболочки** - язык оболочки Gizmo Client.

### Действие при входе в систему

**Действие при входе в систему** - действие, которое будет выполнено после завершения пользовательского сеанса.

Возможны следующие варианты для выбора:

-  Без действий

-  Перезагрузка

-  Закрытие всех программ

-  Выключение

-  Завершение сеанса

-  Переход в режим ожидания

-  Переход в режим администратора

### Путь к данным клиента

**Путь к данным клиента** - путь, по которому на компьютере с установленным Gizmo Client хранятся мета-данные Gizmo Client.

Значение по умолчанию - *%PROGRAMDATA%\\NETProjects\\Gizmo Client\\*

### Пароль менеджера

Пароль менеджера - пароль, введя который в специальном скрытом окне Gizmo Client можно войти в режим обслуживания Gizmo Client, в котором доступны следующие действия:

-  Свернуть оболочку Gizmo Client

-  Деактивировать Gizmo Client

-  Удалить Gizmo Client

> [!TIP]
> 
> Подробнее о режиме обслуживания Gizmo Client можно узнать в разделе Gizmo Client - Режим обслуживания

Пароль менеджера по умолчанию - password

### Энергосбережение

**Энергосбережение** - опция, отвечающая за поведение компьютера, на котором установлен Gizmo Client, при простое компьютера.

Включив данную опцию, вы можете задать параметры работы режима энергосбережения, а именно:

-  Действие при простое

-  Триггерное время

**Триггерное время**   - время простоя (в минутах), после которого будет выполнено настроенное действие.

**Действие при простое** - действие, которое будет принято по окончании триггерного времени. Возможны следующие варианты:

-  Завершение работы

-  Спящий режим

## Настройки клиентских сессий

**Настройки клиентских сессий** \- настройки, отвечающие за поведение Gizmo Client во время активной клиентской сессии в Gizmo Client.

В данном разделе доступны следующие опции:

-  Автоматический повторный вход пользователей

-  Автоматический повторный вход гостей

-  Завершение ожидающих сеансов

-  Выход из системы отключенных клиентов

-  Время ожидания

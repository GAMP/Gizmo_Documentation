**Attributes** are additional fields that you can add to objects in Gizmo.

> [!WARNING]
> 
> For now, attributes are available only for the **Users** object. For details, see [User attributes](./../../../articles/user-attributes.md).

The table in this section has two columns:

-  **Key** -- the unique ID of the attribute (its name in the database).

-  **Name** -- the name of the attribute shown in Gizmo Client and Gizmo Manager.

This section shows a table of your attributes.

To add an attribute, click <cmd text="Create Attribute"/> in the top right corner.

To edit or delete an attribute, double-click it in the table. The [attribute card](./attribute-card.md) opens.

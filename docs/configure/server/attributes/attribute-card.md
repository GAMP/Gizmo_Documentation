**IMAGE: the attribute card with the Key and Name fields and the Delete button**

The attribute card has these fields:

-  **Key** -- the unique ID of the attribute (its name in the database).

-  **Name** -- the name of the attribute shown in Gizmo Client and Gizmo Manager.

To delete the attribute, click <cmd text="Delete"/> in the bottom right corner of the card.

> [!CAUTION]
> 
> When you delete an attribute, all values linked to it are deleted too.

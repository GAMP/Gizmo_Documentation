**IMAGE: the variable card with the Name, Value and Scope fields and the Delete button**

The variable card has these fields:

-  **Name** -- the name of the variable, without the `%` escape characters.

-  **Value** -- the value of the variable.

-  **Scope** -- where the variable can be called.

To delete the variable, click <cmd text="Delete"/> in the bottom right corner of the card.

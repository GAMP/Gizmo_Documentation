**Companion** ([Gizmo Companion](./../../../about/overview/gizmo-companion/_index.md)) is an additional program that connects Gizmo with POS hardware and connected devices, for example to access files.

In this section you can see the companions already connected to the server and add a new one.

The table of connected companions shows:

-  **Name** -- any name of the companion, set when you create or edit it.

-  **Status** -- the status of the connection to the server.

-  **IP** -- the IP address of the companion.

-  **Token** -- the unique ID of the companion.

To change the name of a companion, copy its token or delete it, double-click the companion in the table. The [companion card](./companion-card.md) opens.

To connect a new companion, click <cmd text="Create Companion"/> in the top right corner. The fields are described in [Adding a new companion](./add-new-companion.md).

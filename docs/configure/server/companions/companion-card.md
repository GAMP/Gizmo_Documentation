**IMAGE: the companion card with the Name field, the Token field with the copy icon and the Delete button**

The companion card has one field:

-  **Name** -- any name of the companion shown in Gizmo Manager.

To copy the companion token, click the copy icon in the **Token** field.

To delete the companion, click <cmd text="Delete"/> in the bottom right corner of the card.

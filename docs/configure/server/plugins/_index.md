This section shows the connected third-party plugins and integrations.

**Plugins** are add-ons for Gizmo that third-party developers create based on the open documentation.

**Integrations** are connections to third-party services.

> [!NOTE]
> 
> For more on developing and connecting plugins, see the **For Developers** section, group [Plugins creation](./../../../for-developers/sozdanie-plaginov/_index.md).

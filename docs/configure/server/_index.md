Server settings are in the **Server** section of the Gizmo Manager settings.

Here you find the options that define how your Gizmo Server works: from user attributes and environment variables to the network and backups.

The section contains these subsections:

-  [Attributes](./attributes/_index.md) -- additional fields for Gizmo objects.

-  [Companion](./companions/_index.md) -- connecting Gizmo Companion to the server.

-  [Variables](./variables/_index.md) -- environment variables for Gizmo apps.

-  [Plugins](./plugins/_index.md) -- third-party plugins and integrations.

-  [Network](./network.md) -- network settings and access to the server.

-  [Backup](./backup.md) -- automatic database backups.

-  [Communication methods](./communication-methods.md) -- the mail server Gizmo uses to send email.

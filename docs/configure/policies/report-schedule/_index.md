**IMAGE: Settings -> Policies -> Report Schedules page with the table of delivery rules**

Here you set up the rules for automatic report delivery.

The table shows all the rules you have created:

-  **Name** -- the name of the delivery rule.

-  **Time** -- the time when reports are sent.

-  **Frequency** -- how often reports are sent.

-  **Enabled** -- the rule status (active or disabled).

To create a new rule, click <cmd text="Create Delivery Rule"/> in the right corner of the page.

To edit an existing rule, click its row in the table -- the [delivery rule card](./scheduler-card.md) opens.

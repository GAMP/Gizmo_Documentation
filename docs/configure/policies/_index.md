Policies are in the **Policies** section of the Gizmo Manager settings.

Here you set the rules that control user access and automated processes: the waiting line, age restrictions, reservations, report delivery and ban reasons.

The section has these subsections:

-  [Queue](./queue.md) -- how the waiting line for a host works when all computers are busy.

-  [Age restrictions](./age-restrictions.md) -- access restrictions based on the user's age.

-  [Reservations](./reservations.md) -- rules for reserving hosts.

-  [Report schedules](./report-schedule/_index.md) -- automatic delivery of reports to operators.

-  [Ban reasons](./ban-reasons/_index.md) -- reasons for banning users.

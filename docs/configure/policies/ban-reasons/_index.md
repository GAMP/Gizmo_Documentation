**IMAGE: Settings -> Policies -> Ban Reasons page with the table of ban reasons**

Here you set up the reasons for banning users.

The table shows all the reasons you have created:

-  **Name** -- the name of the ban reason.

-  **Description** -- the description of the ban reason.

To create a new reason, click <cmd text="Create Ban Reason"/> in the right corner of the page.

To edit an existing reason, click its row in the table -- the [ban reason card](./ban-reason-card.md) opens.

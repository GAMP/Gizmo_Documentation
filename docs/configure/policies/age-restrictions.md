**IMAGE: Settings -> Policies -> Age Restrictions page with the global settings and the login restrictions table**

Here you set access restrictions based on the users' age.

## Global settings

-  **Restrict Users by Date of Birth** -- when on, the system checks the user's date of birth and applies age restrictions.

-  **Age Restrictions for Applications** -- when on, age restrictions apply when apps are launched.

-  **Age Restrictions for Products** -- when on, age restrictions apply when products are sold.

## Login age restrictions

When this feature is on, you set an access schedule that depends on the user's age.

The table shows the rules you have created:

-  **Age** -- the age range the restriction applies to.

-  **Time** -- the time interval during which login is allowed.

To create a new rule, click <cmd text="Create Age Restriction"/> and set:

-  **Age From / Age To** -- the age range of the users the rule applies to.

-  **From / To** -- the time interval during which users of this age are allowed to log in.

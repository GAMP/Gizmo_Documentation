**IMAGE: the Settings -> Finances -> Tariffs page with the tariff cards**

This section sets the billing profiles -- the rules for charging users for the time they spend on a host.

All tariffs you have created are shown as cards. Each card shows the profile name and the number of linked branches.

To create a new tariff, click <cmd text="Create Tariff"/> in the corner of the page.

To edit an existing tariff, click its card. The [tariff card](./tariff-card.md) opens.

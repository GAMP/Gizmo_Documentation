**IMAGE: the Settings -> Finances -> Registers page with the table of registers and the Branch filter**

Here you set up the registers used in Gizmo Manager for financial operations.

The table shows all registers you have created. To filter the list by branch, use the **Branch** filter.

The table has these columns:

-  **Name** -- the name of the register.

-  **Branch** -- the branch the register belongs to.

-  **Companion** -- the Gizmo Companion linked to this register.

To create a new register, click <cmd text="Create Register"/> in the corner of the page.

To edit an existing register, click its row in the table. The [register card](./register-card.md) opens.

The register card opens when you create a new register or edit an existing one.

## Location settings

-  **Branch** -- the branch the register belongs to. This field is required.

-  **Warehouse** -- the warehouse linked to this register. It is used to track stock when you sell products.

-  **Companion** -- the Gizmo Companion that works with this register.

-  **Number** -- the sequence number of the register.

-  **Name** -- the name of the register. This field is required.

-  **Shift starting cash** -- the amount of cash a shift on this register opens with.

-  **Idle timeout** -- the idle time in seconds after which the register goes into standby.

-  **Payment terminal number** -- the ID number of the payment terminal connected to this register.

-  **Receipt printer number** -- the ID number of the receipt printer connected to this register.

-  **Default operator** -- the operator assigned to this register by default. The default value is **Not set**.

## Default register

At the bottom of the card there are two switches:

-  **Default register for the branch** -- the register is used by default within its branch.

-  **Global default register** -- the register is used by default in the whole system.

**IMAGE: the Settings -> Finances -> Time Products page with the Time Products and Priority tabs**

This section sets the time products -- prepaid time offers that users can buy in Gizmo Client or through Gizmo Manager.

The section has two tabs: **Time Products** and **Priority**.

## Time Products tab

It shows all time products you have created as cards, grouped by branch and host group.

You can filter the list by:

-  **Branch** -- filter by branch.

-  **Host group** -- filter by host group.

-  **Time product** -- filter by a specific time product.

To reset all filters, click <cmd text="Clear All"/>.

Each time product card shows the name, the price, the duration (in HH:MM format) and the number of branches where the time product is available.

To create a new time product, click <cmd text="Create Time Product"/> in the corner of the page. To edit an existing one, click its card.

## Priority tab

It shows all time products as a table with their duration. Here you set the order of the time products: drag an item by the drag handle <icon code="grip-vertical" /> to the position you need. The order sets both how time products are displayed and in which order a guest's time products are used up: if a guest has several available time products, the one higher in the list is used first. Priority does not override the time product restrictions (host groups, dates, time).

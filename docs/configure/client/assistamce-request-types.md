**IMAGE: Settings -> Client -> Assistance Request Types page with the list of request types**

Here you set up the types of assistance requests that a user can send to the operator from the Gizmo Client interface.

The feature turns on automatically as soon as at least one request type exists: Gizmo Client shows an icon that the guest uses to send the operator a message -- for example, about a problem with a game or a device. The request appears in Gizmo Manager on the **Requests** tab of the notifications -- see [Notifications](./../../usage/gizmo-manager/interface/notifications.md). The operator accepts or rejects the request; once the operator accepts it, the guest gets a notification on their PC. To make sure the operator does not miss a request, turn on a sound notification for it in **Settings -> Others -> Action Center** -- see [Action center](./../others/action-center.md).

The list shows all request types you have created. To change their order, drag the items by the drag handle <icon code="grip-vertical" /> to the left of the name.

To create a new request type, click <cmd text="Create Assistance Request Type"/> in the right corner of the page.

## Creating a request type

When you create a new request type, fill in the field:

-  **Name** -- the name of the request type that the user sees in Gizmo Client. This field is required.

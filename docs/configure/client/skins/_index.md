**IMAGE: Settings -> Client -> Skins page with the default skin selector and the table of skin profiles**


In this section you set up skin profiles for the Gizmo Client interface -- with them you can give the client a different look for different host groups.

**Default Skin** -- the base Gizmo Client skin that applies by default. You choose it from the list of profiles you have already created.

Below is a table with all the skin profiles you have created:

| Column | What it means                                                          |
|--------|------------------------------------------------------------------------|
| Name   | The profile name. The default profile is marked with the "Default" label. |
| Branch | The branch or branches the profile is linked to.                       |

To manage a profile, click **"..."** next to it -- a menu with actions opens:

-  <cmd text="Edit"/> -- opens the profile card for editing.

-  <cmd text="Set as Default"/> -- makes the selected profile the default one.

To create a new profile, click <cmd text="Create Skin Profile"/> in the upper right corner of the page. Its settings are described [here](./skin-profile.md).

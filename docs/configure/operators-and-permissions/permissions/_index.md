**IMAGE: the Settings -> Operators and permissions -> Permissions page with the table of permission presets**

Here you set up permission presets -- the permission sets assigned to operators.

The table shows all presets you have created:

-  **Name** -- the name of the preset.

-  **Permissions** -- the total number of permissions turned on.

-  **Operators** -- the number of operators the preset is assigned to.

To create a new preset, click <cmd text="Create Permission"/> in the corner of the page.

To edit an existing preset, click its row in the table. The [permission card](./permission-card.md) opens.

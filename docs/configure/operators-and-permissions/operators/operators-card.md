**IMAGE: the operator card with the Information, Permission, Shift, Address and Details blocks**

The operator card opens when you create a new operator or edit an existing one.

## Information

-  **First name** -- the operator's first name.

-  **Last name** -- the operator's last name.

-  **Username** -- the operator's login for Gizmo Manager. This field is required.

-  **Password** and **Repeat password** -- to change the operator's password, fill in both fields. If you leave them empty, the password stays the same.

-  **Email** -- the operator's email address.

## Permission (required)

-  **Branches** -- the branches where the operator can work. You can choose several. This field is required.

-  **Permission preset** -- the permission set that defines which actions the operator can perform in the system. You choose it from the presets you set up in advance -- see [Permissions](./../permissions/_index.md).

## Shift (required)

Sets whether this operator needs to open a shift:

-  **Disabled** -- shifts are not used, and the operator can work without opening a shift.

-  **Optional** -- the operator can work with or without a shift.

-  **Required** -- the operator must open a shift before starting work.

## Address (optional)

-  **Country/Region** -- the operator's country or region of residence.

-  **Postal code** -- the postal code.

-  **City** -- the city of residence.

-  **Address** -- the home address.

-  **Phone** -- the operator's contact phone number, with a country code selector.

## Details (optional)

-  **Image** -- a photo or avatar of the operator. To choose one, click <cmd text="Select Image"/>.

-  **Mobile phone** -- the operator's mobile phone number, with a country code selector.

-  **Sex** -- the operator's sex.

-  **Date of birth** -- the operator's date of birth.

To fire an operator, click <cmd text="Fire"/> in the bottom right corner of the page. The operator loses access to the system and moves to the **Fired** tab of the operator list.

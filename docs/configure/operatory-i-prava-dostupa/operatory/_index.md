title: Операторы
---

В данном разделе управляются учётные записи операторов -- сотрудников, работающих в Gizmo Manager.

Список операторов разделён на две вкладки:

-  **Активный** - операторы, которые в данный момент работают в системе.

-  **Уволенный** - операторы, которые были уволены и лишены доступа к системе.

В таблице отображается имя каждого оператора. Для редактирования нажмите на соответствующую строку.

Для создания нового оператора нажмите кнопку **«Создать оператора»** в правом углу страницы.

Настройкии сервера можно найти в разделе **«Сервер»** перейдя в общие настройки Gizmo Manager.

Раздел «Сервер» содержит в себе основные настройки для вашего Gizmo сервера.

Содержание раздела:

-  Атрибуты

-  Компаньоны

-  Переменные

-  Плагины и Интеграции

-  Сеть

-  Резервная копия

-  Способы коммуникации

В данном разделе отображаются подключенные сторонние плагины и подключенные интеграции.

Плагины для Gizmo могут быть созданы сторонними разработчиками на основе открытой информации.

Интеграции - подключенные интеграции со сторонними сервисами.

<note type="info">

Подробнее о разработке и применении плагинов можно ознакомиться в разделе «Для разработчиков» в группе «[Создание плагинов](./../../../for-developers/sozdanie-plaginov/_index)»

</note>

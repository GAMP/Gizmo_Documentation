title: Карточка компаньона
---

В карточке компаньона доступны для заполнения следующие поля:

-  Название

**Название** - произвольное название вашего компаньона для отображения в Gizmo Manager.

Для копирования токена компаньона нажмите на кнопку копирования, расположенную в поле «Токен».

Для удаления компаньона нажмите кнопку «Удалить» в правом нижнем углу карточки.

<note type="danger">

При внесении изменений не забывайте нажать кнопку «Сохранить» в правом верхнем углу.

</note>

В данном разделе отображаются настройки сети для Gizmo Server, а именно:

-  Настройки сетевого интерфейса

-  Правила подключения

## Настройки сетевого интерфейса

**Настройки сетевого интерфейса** - настройки Gizmo Server, которые определяют доступность Gizmo Server и Gizmo Manager по сети.

Доступны следующие настройки:

-  Протокол  и порты доступа

-  Доменное имя сервера

-  Сертификат PFX

### Протокол и порты доступа

Gizmo Server и Gizmo Manager могут быть доступны по протоколам http, https или по обоим сразу. При этом пользователь может выбрать порт доступности для каждого протокола.

По умолчанию, выбраны протоколы http и https, доступные по портам 80 и 443 соответственно.

> [!WARNING]
> 
> Внимание! Если Gizmo Server запущен через Docker, то настройки портов будут проигнорированы сервером. Данное ограниечение продиктовано особенностями настройки Docker контейнеров.

### Доменное имя сервера

**Доменное имя сервера** - имя, по которому ваш сервер доступен в сети.

Значение по умолчанию - «gizmo.local» (доступ только в локальной сети).

> [!WARNING]
> 
> Внимание! Если Gizmo Server запущен через Docker, то Gizmo Manager и Gizmo Server будут недоступны при обращении к ним по доменному имени, заданному по умолчанию (gizmo.local). Gizmo Server продолжит использовать порты, указанные при создании Docker контейнера. Данное ограниечение продиктовано особенностями работы Docker контейнеров.

> [!WARNING]
> 
> Указание доменного имени сервера является обязательным для использования функций удаленного просмотра и удаленного управления.

Допустимые значения:

-  Локальный IP-адрес сервера

-  Локальное доменное имя сервера

-  Глобальный IP-адрес сервера

-  Глабальное доменное имя сервера

#### Локальный IP-адрес сервера

**Локальный IP-адрес сервера** - это адрес вашего сервера, на котором установлен Gizmo Server.

Локальный адрес должен принадлежать одной из следующих сетей:

-  10\.0.0.0/8

-  192\.168.0.0/16

-  172\.16.0.0/12

По локальному адресу вы сможете получить доступ к вашему серверу только внутри вашей локальной сети.

#### Локальное доменное имя сервера

**Локальное доменное имя сервера** - доменное имя для локального IP-адреса Gizmo Server, предварительно настроенное вами на вашем DNS-сервере, роль которого, как правило, выполняет ваш локальный роутер. 

> [!CAUTION]
> 
> В случае указания локального доменного имени сервера, на устройствах, на которых установлен Gizmo Client, и устройствах, с которых планируется открывать Gizmo Manager в локальной сети в качестве DNS-сервера должен быть указан адрес вашего DNS-сервера, на котором вы указалали соответствие доменного имени и IP-адреса (как правило - IP-адрес вашего роутера).

#### Глобальный IP-адрес сервера

**Глобальный IP-адрес сервера** - 'это публичный IP-адрес, по которому доступен ваш Gizmo Server. 

В случае, если ваш Gizmo Server установлен локально, то Глобальный IP-адрес сервера - это публичный (внешний) адрес вашего роутера. При этом, в данном случае, необходимо заранее озаботиться о пробросе портов до Gizmo Server на вашем роутере.

В случае, если ваш Gizmo Server установлен на внешней VPS/сервере облачного провайдера, Глобальный IP-адрес сервера - это IP-адрес, по которому VPS/сервере облачного провайдера доступен из сети Интернет.

#### **Глабальное доменное имя сервера**

**Глабальное доменное имя сервера** - купленное заранее доменное имя, которому в панеле управлении регистратора доменных имен сопоставлен **Глобальный IP-адрес сервера.**

### **Сертификат PFX**

**Сертификат PFX** - это SSL сертификат в формате PFX, необходимый для работы по протоколу https. По умолчанию используется встроенный самоподписный сертификат.

В данном разделе вы можете установить ваш SSL сертификат.

Сертификат можно выбрать и загрузить, нажав на кнопку «Обзор».

Для того, чтобы вернуться к использованию самоподписного сертификата, нажмите кнопку «Очистить».

> [!WARNING]
> 
> Для применения настройки сетификата требуется перезагрузка Gizmo Server.

title: Добавление новой переменной
---

При создании новой переменной доступны следующие поля для заполнения:

-  Имя - название переменной, указывается без экранирующих символов %

-  Значение - значение новой переменной;

-  Область применения - Область, в которой может быть вызвана переменная.

<note type="danger">

Не забудьте нажать кнопку «Сохранить» в правом верхнем углу.

</note>

Переменные - это  дополнительные статичные переменные окружения, которые могут быть использованы приложениями Gizmo, такими как Gizmo Manager, Gizmo Client и Gizmo Server.

Формат вызова переменных - %var%

var - название переменной.

Самый частый вариант использования переменных это использование переменных в скриптах и в приложениях (указание путей до исполняемых файлов).

<note type="lab">

Подробнее с использованием переменных для приложений вы можете ознакомиться в цикле статей «[Использование переменных](./../../../stati/ispolzovanie-peremennykh)».

</note>

В данном разделе вы можете ознакомиться с уже добавленными переменными, а также создать новые переменные.

В интерфейсе данного раздела представлена таблица с переменными:

-  **Имя**  - имя переменной, которое может быть задано на этапе создания или редактирования переменной;

-  **Значение** - значение переменной;

-  **Область применения** - область применения переменной (Gizmo Client, Gizmo Manager, Gizmo Server).

Для изменения или удаления переменной перейдите в [Карточку переменной]() дважды кликнув мышкой по нужной переменной в таблице.

Для добавления новой переменной нажмите на кнопку в правом верхнем углу «[Добавить переменную»](./../kompanony/dobavlenie-novogo-kompanona).

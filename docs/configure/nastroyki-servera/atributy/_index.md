---

Атрибуты - это дополнительные поля, которые могут быть добавлены для объектов в Gizmo.

<note>

На текущий момент атрибуты доступны только для объекта «пользователи».

Подробнее о пользовательских атрибутах вы можете узнать в статье [«Пользовательские атрибуты»](./../../../stati/polzovatelskie-atributy).

</note>

Каждый атрибут состоит из **ключа** и **названия**.

**Ключ** - уникальный идентификатор атрибута (название в базе данных)

**Название** - название атрибута для отображения в Gizmo Client и Gizmo Manager/



В текущем разделе отображается таблица с вашими атрибутами.

Для добавления атрибута нажмите кнопку «**Добавить**» в правом вехнем углу.

Для редактирования или удаления атрибута перейдите в [**Карточку атрибута**](./kartochka-atributa)**,** дважды нажав на него мышкой в таблице атрибутов.

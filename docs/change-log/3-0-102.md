Release date: 2026-10-15

## Client Module

### Fixed bugs

- Custom CSS styles can't be loaded on the login screen.
- Blank grey screen on Client startup.
- The online deposit window was unavailable in some cases.
- Now Abilities to pay from deposit on The Client side don't depend on the ability  to pay from deposit on the Manager side.
- Uploaded leaderboard icons may have caused layout changes.
- Client manager menu password can't be used after v3 update.

### New features

- New Skin - Grafit.

### Usability Problem

- After entering an incorrect password, the client's phone number was erased from the field

## Common

### Fixed bugs

- Fixed UI/UX bugs during setup time ranges for Time products and general Products.

### New features

- New features for the User’s Loyalty Program — Achievements, Levels, Challenges.
- The server-side event scripts (UserLogin, UserLogout, PowerOn, PowerOff in the `batch` folder) now run on Linux and Docker installations. Linux and Docker installs uses '.sh' files instead of Windows ('.bat' files).
- Added an ability to configure exposed ports under self-hosted docker. The ports and host name are now used as hints to generate target server url.

## Companion

### Fixed bugs

- Fiscalization issue with STRIH printers. Receipt can't be printed because a user phone number can't be mapped correctly.
- No ability to switch off Fiscal provider integration in the companion.

## Manager Module

### Fixed bugs

- KZ phone code wouldn't be set on the User profile page (contact information window)

### Cosmetics

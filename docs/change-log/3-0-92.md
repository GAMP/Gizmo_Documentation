## Common

### New features

- Linux version of Gizmo.
- Docker version of Gizmo.
- PostgreSQL database support.
- Web version of Gizmo Manager (v3).
- Updated API (v3).
- Web-based remote access to client PCs (RemoteControl).
- Web-based remote view of client PCs (RemoteView).
- Several clubs on one server (branches) with a shared user database.
- Extended list of security policies.
- One cart for products, services and deposits for one or several users.
- Age restrictions: sale of products and services, login, app launch.
- X-Report for the card payment terminal.
- Favorite reports with saved custom filters.
- Custom fields in the user profile.
- Online payment methods right from the Manager, with the option to send a payment link to the user.
- Stock management: warehouses, moving products between warehouses, restocking and writing off products (stock count).
- Stock count with the option of full payment, payment at cost or writing off the missing items.
- Flexible discount system: discounts on the hourly tariff, payment method, products and product groups, and time products, with combinable conditions. A discount can optionally be given as bonus points.
- Discount groups.
- Linking discount groups to user groups.
- Promo codes linked to a discount group.
- Paid reservations.
- Partial payment of reservations.
- Updated reservation logic that takes active sessions into account.
- Extended list of reservation statuses.
- Reserving several devices at once.
- Advanced reservation settings: seating limits before and after a session, waiting period for the reservation start, permission to sell time products and the hourly tariff, minimum and maximum reservation time, deficit factor, service fee in the reservation payment, minimum initial payment, first payment timeout, cancellation grace period and refund amount, discounts and promo codes for reservations.
- Reservation log.
- Waiting line (Queue) for guests.
- Gizmo Companion settings moved to Gizmo Manager.
- Updated Gizmo Companion design.
- Updated order processing logic.
- Skin settings moved to Gizmo Manager.
- Operator roles: cashier, owner, marketer, administrator, manager.
- Custom operator roles.
- Advanced operator permission settings.
- User and computer parameters passed to an iframe (Gizmo Client).
- Customizable main screen splash.
- Automatic card refunds.
- Updated phone and email verification for users through third-party services. The list of services is extended with plugins.
- Other visual improvements and optimizations.

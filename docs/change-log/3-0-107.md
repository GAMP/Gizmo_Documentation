Release date: 2026-11-04

## Client Module

### Fixed bugs

- Added signatures to all dll files for safe update.
- Fixed User remaining time notifications.
- Fixed the bug with buying time products from Gizmo Client (when the default register doesn't set).
- Gizmo Client shows all news from all branches even if news was disabled on the current branch. Fixed.

## Common

### Fixed bugs

- Now orders with a zero payment amount will be assigned the statuses Paid and Completed (if delivery is not required).
- Points for a product are not awarded if the cost of the product in the order is 0. Fixed.
- API permission bug. Fixed.
- The percentage bonus reward was not being awarded in some cases. Fixed.
- Server can crash while backup in progress and backup related configuration changes. Fixed.
- PowerOff.bat didn't execute for restart command. Fixed.

## Companion

### Fixed bugs

- Duplicating Bundle items in a fiscal receipt. Fixed.

## Web Manager Module

### Fixed bugs

- Fixed the bug with auto-closing user balances.
- Deleted branches were shown in the list on the Stock card page and on the Register card page. Fixed.
- Visibility the 'Actions' menu on the User card page depends on 'Edit' user permission. Fixed.
- The "Change user group" permission did not apply to the user creation process. Fixed.

### Cosmetics

- Hide time from the date filter in the booking calendar.
- The Plugin tab was renamed to 'Plugins and Integrations'.

### Exception

- You cannot delete a register if it is the last register for the branch and there are active operators for whom a shift is required.
- New exception: An operator cannot sell a time product to a client if the client is logged in to a host in a host group for which the sale of that package is prohibited.

### New features

- Added Duplicate Product function
- Added Duplicate Time offer function
- Added Duplicate Tariff function
- New separate operators permissions: Login users (for hosts) and Login users (for endpoints)
- Now user balance is shown in the 'Close balance' window.

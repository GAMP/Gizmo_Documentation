## Gizmo manager

To try Gizmo before installing it, you can connect to the shared demo server -- a Gizmo server that is already deployed and set up. You don't need to install a database or a server.

The demo server address is `cloud3.gizmopowered.net`. You can get the login details from [support](./support.md).

> [!WARNING]
>
> - The demo server is shared: other clubs use it at the same time. Do not enter real data on it -- launcher accounts, guest data, passwords.
> - Some features may not work on the demo server, for example remote PC control.
> - You cannot connect gaming PCs to the demo server.

When you are ready to install Gizmo at your club, see the [Quick install](./../instalation/quick-install.md) guide.

Gizmo offers a wide set of tools to attract and keep customers. Logically, these tools fall into two categories:

- Group loyalty tools
- Personalized loyalty tools

## Group loyalty tools

Group loyalty tools are all the tools tied to a user group, namely:

- Personalized apps for a user group. This tool lets you give a specific user group unique content in the form of exclusive games and apps.
- A personalized security profile. This tool lets you give your privileged users more freedom on the gaming PC.
- Personal storage. Lets you set up personal storage for privileged users, for saves and other user data.
- Discounts. The number of discounts is unlimited. Discounts are available in different usage scenarios that can be combined. The use of discounts can be limited by dates, days of the week and time. How to set up discounts is described in [Discounts and promotions](./discounts-and-promotions.md). Possible setups:
  - Cashback in points for a specific order or any order
  - A fixed points reward for a specific order or any order
  - A discount on a specific item in the order or on the whole order
  - A discount or a reward for a specific payment method
  - and more.
- A credit line. This tool lets you open a credit line for your privileged users -- see [How to enable postpay](./../staff/postpay.md).
- Loyalty points. A tool that encourages users to collect points and spend them on certain products. Points can be earned for buying certain products and services, for the total amount of money spent or for the total time spent -- see [Loyalty points for customers](./loyalty-program.md).
- Restricting the use of certain device groups. With this tool, you can create a zone of devices in your venue that is available only to privileged users.
- Privilege levels. This tool lets you set the rules for moving users from one group to another (through the achievement system), automating how users get all the group privileges listed above -- see [How to set up privilege levels](./ladder.md).

## Personalized loyalty tools

Personalized loyalty tools include the following:

- Promotions. A tool that lets you create promotional campaigns with promo codes. A promo code activates a discount or a discount group for the user once -- see [Promo codes](./promo-codes.md).
- Achievements. A tool that lets you mark a user's progress in the venue. Achievement progress can be counted in the privilege levels and in challenges. The system has a ready-made set of achievements (money spent, time, points collected, time since registration and others), but you can also create your own custom achievements, for example an achievement for following the club on social media -- see [How to set up achievements](./achievements.md).
- Challenges. This tool lets you motivate users to complete achievements. Challenges can have time limits and limits on the number of completions. For a challenge, the user can be given a prize in the form of a product, a service or free time. The prize can be given automatically or manually by the operator -- see [How to set up challenges](./challenges.md).

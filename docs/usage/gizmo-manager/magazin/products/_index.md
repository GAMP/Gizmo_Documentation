The tab lists the items available for sale. A product created here appears on the [Sales](./../../tochka-prodazh/prodazhi.md) screen and, if set up accordingly, in the client shell.

## Product list

-  **Name** -- the item name.

-  **Barcode** -- the code for the scanner.

-  **Status** -- whether the item is available for sale.

-  **Reward** -- the points the user earns for buying it.

-  **Cost** -- the purchase cost of the item.

-  **Price** -- the sale price.

-  **Type** -- product or service.

-  **Group** -- the product group that defines where the item appears on the cashier's screen.

## Actions

-  **Create Product** -- opens an empty [Product card](./kartochka-produkta.md).

-  **Delete** -- deletes the selected items. A deleted product is not erased for good: you can restore it.

Double-click a row to open the card of an existing product.

## Related sections

Item stock is tracked in the warehouse -- see the **Product Stock** and **Stock Movement** tabs of the [Shop](./../_index.md) section. The groups that sort products on the cashier's screen are set on the **Product Groups** tab.

---

The card opens when you create a product with the <cmd text="Create Product"/> button or double-click a row in the [Products](./_index.md) list. It has these blocks: description, media, availability, pricing, reward, warehouse and sales schedule.

## Description

-  **Name** -- the item name. Required.

-  **Description** -- an explanation for the user, shown in the client shell.

-  **Product Group** -- the group that defines where the item appears on the cashier's screen. Required.

-  **This Is a Service** -- marks an item that has no physical stock.

## Media

The item's cover image for the client shell. The recommended size is **400 × 444 pixels**. Drag the image into the field or select it with the <cmd text="Add Cover"/> button.

## Availability

-  **By Branch** -- the list of branches with the **Enable** checkbox. The item is sold only in the checked branches.

-  **Show in Client Shell** -- defines whether the item is available to the user at the gaming station. Without this checkbox the product is available only to the cashier.

-  **User Group Availability** -- the list of groups the item is available to. **Unregistered** is shown as a separate row, and other groups are added with the <cmd text="Add"/> button.

## Pricing

-  **Price** -- the sale price. Required.

-  **Or** and **And** -- the payment condition: with money, with points, or with both.

-  **Points** -- the item's price in points.

-  **Tax** -- the tax rate applied to the item.

## Reward

-  **Points** -- the number of points the user earns for buying the item.

## Warehouse

-  **Barcode** -- the code for the scanner.

-  **Stock Tracking** -- deducts the item from the warehouse when it is sold.

## Sales schedule

-  **Date Range** -- the **Start Date** and **End Date** fields that limit the sales period.

-  **Time Range** -- the hours of the day when the item is available.

Save the changes with the <cmd text="Save"/> button. Until you save, the card shows a warning about unsaved changes.

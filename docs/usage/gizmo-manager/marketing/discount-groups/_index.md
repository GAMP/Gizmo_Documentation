The tab holds the table of created discount groups.

> [!NOTE]
>
> A discount group is a logical entity that combines discounts. One discount can belong to several discount groups.

The discount groups table has these columns:

-  **Name** -- the discount group name.

-  **Discount Count** -- the number of discounts in the group.

-  **User Group Count** -- the number of user groups this discount group is linked to.

## Search

The tab has search.

## Creating a discount group

To create a discount group, click <cmd text="Create Discount Group"/> in the top right corner of the screen. The [Discount group card](./discount-group-card.md) opens.

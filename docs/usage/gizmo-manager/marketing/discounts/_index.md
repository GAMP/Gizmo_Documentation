The tab holds the table of created discounts. Here you can view, create and set up the discounts used in the system.

> [!NOTE]
>
> A discount is an entity applied to a user's invoices. Per-minute billing also uses invoices, so discounts can also apply to per-minute tariffs.

The discounts table has these columns:

-  **Name** -- the discount name.

-  **Status** -- the discount status (active/archived).

## Filtering and search

The tab has search and the **Status** filter (active/archived).

All the conditions you set are cleared with the <cmd text="Clear All" /> link.

## Creating a discount

To create a discount, click <cmd text="Create Discount"/> in the top right corner of the screen. The [Discount card](./discount-card.md) opens.

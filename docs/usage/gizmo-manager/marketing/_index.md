The section is for setting up announcements, discounts, promotions and competitive mechanics. The parameters set here are passed to Gizmo Client and shown to the user at the gaming station. The section has eight tabs, and **News** opens first.

The section opens from <cmd text="Marketing" /> in the left menu.

> [!NOTE]
>
> The overall concept of the loyalty program in Gizmo and all its mechanics are described in the [Loyalty program](./../../../tutorials/loyalty/_index.md) guides.

## Tabs

-  **News** -- announcements shown in the client shell. Each news item shows its title, whether it is published, the start and end dates of display and a link to the details. Created with the <cmd text="Create News" /> button.

-  **Feeds** -- RSS feeds whose entries are shown on the Gizmo Client home page. See [Feeds](./feeds.md).

-  **Achievements** -- user achievements.

-  **Ladder** -- setting up the ladder levels: the rules by which users move from one user group to another. See [Ladder](./lader/_index.md).

-  **Challenges** -- tasks that earn a reward when completed.

-  **Discounts** -- price reduction rules.

-  **Discount Groups** -- sets of discounts assigned to whole user groups.

-  **Promotions** -- offers limited in time.

A discount is applied during a sale in the [POS](./../tochka-prodazh/_index.md) section.

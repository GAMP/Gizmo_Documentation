**IMAGE: Challenges tab with the table of created challenges, the Status filter and the Create Challenge button**

The tab holds the table of created challenges. Here you also create, delete and edit them.

A challenge is a set of achievements that earns the user a reward.

The table shows the challenge parameters:

-  **Name** -- the challenge name.

-  **Status** -- active/inactive, hidden from the client.

-  **Start** -- the challenge start date.

-  **End** -- the challenge end date.

-  **Availability** -- how many completions of the challenge are available.

## Bulk delete

You can delete challenges in bulk. To do this, check the challenges you need or all the challenges on the page. To select all challenges, check the box in the table header.

## Filters and search

The tab has search and the **Status** filter.

All filter conditions are cleared with the <cmd text="Clear All" /> link.

## Creating a challenge

To create a challenge, click <cmd text="Create Challenge"/> in the top right corner of the screen. The [Challenge card](./challange-card.md) opens.

## Other actions

The **"…"** menu in a challenge row has the <cmd text="Edit"/>, <cmd text="Disable"/>, <cmd text="Hide from Clients"/> and <cmd text="Delete"/> actions.

### Editing a challenge

To edit a challenge, double-click its row or select <cmd text="Edit"/> in the **"…"** menu of the challenge row. The [Challenge card](./challange-card.md) opens.

### Changing a challenge's status

To change a challenge's status, double-click its row or select <cmd text="Enable"/>/<cmd text="Disable"/> or <cmd text="Hide from Clients"/>/<cmd text="Show to Clients"/> in the **"…"** menu of the challenge row. These actions are also available in the [Challenge card](./challange-card.md).

> [!WARNING]
>
> A challenge is a contract (an offer) made to the user. If the user completed a challenge before you started editing it, it stays completed for the user after the edit, whatever the new conditions are.

The card opens on the **Challenges** tab: double-click the challenge row or select <cmd text="Edit"/> in the **"…"** menu of the challenge row.

-  **Enabled** -- the challenge status (enabled/disabled).

-  **Name**.

-  **Hide from Clients** -- whether the challenge is visible to clients.

-  **Window Type** -- the time range in which the challenge is valid:

   -  **Unlimited**.

   -  **With Window** -- you set the fields:

      -  **Start** -- the date the challenge starts.

      -  **End** -- the date the challenge ends.

-  **Requirements** -- the list of achievements and how many of each are needed to complete the challenge. To add required achievements, select available [achievements](./../achievements/_index.md) from the list, set their quantity and click <cmd text="Add"/>. To remove an added achievement, click the cross icon on its badge.

-  **Completions and Limits** -- the block of limits:

   -  **Max Completions per Client** -- the maximum number of times each client can complete this challenge.

   -  **Max Total Completions** -- the maximum number of times all clients together can complete this challenge. Leave it empty for no limit.

-  **Rewards** -- the rewards the client gets for completing the challenge. Rewards can be granted automatically or on request at the operator's desk. You can add several reward types at once and any number of rewards.

   To add a reward, select its type, set the extra parameters and click <cmd text="Add"/>.

   To remove a reward, click the cross icon on the badge with the name of the added reward.

   -  **Reward Type** -- the type of reward. The available values:

      -  **Points** -- the user gets points for completing the challenge. The operator sets the number of points. You can also mark that the points are granted manually by the operator.

      -  **Product** -- the user gets the selected product for completing the challenge. The operator sets the number of products. You can also mark that the products are given out manually by the operator.

      -  **Time** -- the user gets time for completing the challenge. The operator sets the amount of time. You can also mark that the time is granted manually by the operator.

-  **Media** -- the challenge image. Shown in Gizmo Client.

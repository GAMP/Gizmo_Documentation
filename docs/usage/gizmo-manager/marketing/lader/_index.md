The ladder is a Gizmo mechanic for attracting and retaining users.

The tab is for setting up the ladder levels.

## General principles

[User groups](./../../users/user-groups/_index.md) play a big role in Gizmo. In particular, a user group can have access privileges to certain host groups, it can be assigned a discount group, and certain games and apps can be available to it.

The ladder lets you set up the mechanics and rules by which users move from one user group to another.

## Ladder counting modes

The ladder level is calculated in one of two modes: by points earned for achievements or by achievements earned.

### By points earned for achievements

In this mode, each [achievement](./../achievements/_index.md) is assigned points.

When the user gets an achievement, they are awarded the set number of points.

For each ladder level you can set how many points a user must have to reach that level.

### By achievements earned

In this mode, each ladder level has a list of achievements the user must have to reach that level.

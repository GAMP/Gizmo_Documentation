The card holds the parameters of one ladder level. The card opens when you create a level with the <cmd text="Add Level"/> button or edit an existing level.

-  **Level Badge** -- shown in Gizmo Client.

-  **Level Name**.

-  **Target User Group** -- users who reach this level are automatically moved to this group.

-  **Level Description** -- available to users in Gizmo Client.

The set of extra level parameters depends on the selected counting mode.

## Counting mode -- by points earned for achievements

-  **Points Threshold** -- the number of points the user needs to reach this ladder level.

## Counting mode -- by achievements earned

-  **Requirements** -- the list of achievements the user needs to reach this ladder level.

   > [!NOTE]
   >
   > For the starting level in the counting mode by achievements earned, no achievement list is set.

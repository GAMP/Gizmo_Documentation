An achievement is the basic building block of the user loyalty program.

The tab shows all the achievements set up for the venue. Here you also create, edit and delete them.

**IMAGE: Achievements tab with achievement badges in the left column and the achievement preview on the right**

## Creating an achievement

To create an achievement, click <cmd text="Add Achievement"/> in the top right corner.

The [Achievement card](./achivement-card.md) opens.

## Browsing achievements

All created achievements are shown in the left column as badges.

A badge shows the name, the status (active, inactive, hidden) and the name of the signal. These parameters are described in [Achievement card](./achivement-card.md).

## Filters and search

The **Signals** and **Statuses** filters are at the top of the page.

To search achievements by name, use the search button in the top right part of the page.

All the conditions you set are cleared with the <cmd text="Clear All" /> link.

## Achievement preview

When you select a badge, a preview of the achievement card opens on the right side of the screen with more actions: <cmd text="Edit"/>, <cmd text="Delete"/>, <cmd text="Enable"/>/<cmd text="Disable"/>.

The [Achievement card](./achivement-card.md) opens when you double-click the badge or click <cmd text="Edit"/>.

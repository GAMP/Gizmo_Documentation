Экран входа — это начальная страница Gizmo Manager, на которой оператор проходит аутентификацию для доступа к системе.

## Вход в систему

Для входа в Gizmo Manager введите:

-  **Имя пользователя** - логин оператора.

-  **Пароль** - пароль оператора. Нажмите на иконку глаза для отображения введённого пароля.

После заполнения полей нажмите кнопку **«Войти»**.

## Выбор действия при входе

Если у оператора уже есть открытая смена, после входа система предложит выбрать действие:

-  **Продолжить открытую смену** - продолжить работу в рамках текущей смены.

-  **Закрыть открытую смену** - закрыть текущую смену и начать новую.

## Меню пользователя

После входа в системе в правом верхнем углу отображается имя текущего оператора. При нажатии на него открывается меню со следующими действиями:

-  **Закрыть смену** - закрытие текущей рабочей смены оператора.

-  **Изменить пароль** - изменение пароля текущего оператора.

-  **Переключить тему** - переключение между светлой и тёмной темой интерфейса.

-  **Выйти** - выход из учётной записи оператора.

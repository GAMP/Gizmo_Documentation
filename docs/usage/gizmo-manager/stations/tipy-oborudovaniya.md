The **Assets** tab keeps track of what physically sits at the gaming stations: monitors, chairs, headsets, mouse pads, a simulator's steering wheel. It is an inventory list, not a station setting -- Gizmo does not control this equipment; it only stores information about what is there and how much of it.

## Asset list

-  **Name** -- the name of the asset type.

-  **Quantity** -- how many units of this type the club has.

## Actions

-  **Create Asset** -- adds a new type to the list.

You issue equipment to a specific guest and take it back in the <cmd text="Map"/> section, with the **Issue** and **Receive** commands.

**IMAGE: Endpoints tab in Gizmo Manager with the list of endpoints**

This section lets you add and manage endpoints. Endpoints are gaming stations in Gizmo that cannot be connected to directly for technical reasons, but whose sales you still want to run through Gizmo for easy control. For example, game consoles or pool tables.

Devices cannot be added here automatically -- you have to create them manually.

## Actions

-  **Edit** -- opens the [edit card](./terminal-card.md) of the selected endpoint.

-  **Delete** -- deletes the selected endpoints.

-  **Create Endpoint** -- creates a new endpoint.

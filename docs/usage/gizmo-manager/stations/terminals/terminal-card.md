**IMAGE: Endpoint edit card in Gizmo Manager with the Name, Number, Slots, Branch, Host Group, Layouts and Controller fields**

The card opens when you create a new endpoint manually or edit an existing one.

-  **Name** -- the endpoint name. It is shown in the host list, on the club map and in search results.

-  **Number** -- the endpoint's number in Gizmo.

-  **Slots** -- how many users can be logged in on this endpoint at the same time.

-  **Branch** -- the branch this endpoint is shown in.

-  **Host Group** -- the group the endpoint belongs to. It sets the hourly rate, the available time products and the security profile that applies.

-  **Layouts** -- the layouts the endpoint is shown on in the <cmd text="Map"/> section.

-  **Controller** -- the controller linked to the endpoint. You need it to turn the HDMI signal at this station on and off remotely.

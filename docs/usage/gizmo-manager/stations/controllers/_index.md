This section is where you create and edit Gizmo controllers -- devices that turn the HDMI signal to a screen on and off remotely. They are most often used on console screens to control play time.

## Controller list

-  **Name** -- the controller's name in Gizmo.

-  **Branch** -- the branch the controller is linked to.

-  **Serial Number** -- the number printed on the device case.

-  **Type** -- the controller type.

## Actions

-  **Edit** -- opens the [edit card](./controller-card.md) of the selected controller.

-  **Delete** -- deletes the selected controllers.

-  **Create Controller** -- creates a card for a new controller.

For more about the Gizmo HDMI Controller device, see [Gizmo HDMI Controller](./../../../../articles/gizmo-hdmi-controller.md). To learn how to connect a controller and link it to a gaming station, see [How to add a console or another gaming station](./../../../../tutorials/hosts-operations/add-terminal.md).

**IMAGE: Controller edit card in Gizmo Manager with the Name, Serial Number and Branch fields**

The card opens when you create a new controller or edit an existing one.

-  **Name** -- the controller's name in Gizmo.

-  **Serial Number** -- the number printed on the device case. It is used to match the record in the system with the physical controller.

-  **Branch** -- the branch the controller is linked to.

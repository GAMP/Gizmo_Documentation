**IMAGE: Apps Groups tab in Gizmo Manager with the list of app groups**

An app group combines several apps into one set that you can assign to a host group -- instead of linking each app to each host separately.

## Group list

-  **Name** -- the name of the app group.

## Actions

-  **Edit** -- opens the [edit card](./kartochka-redaktirovaniya-gruppy-prilozheniya.md) of the selected group.

-  **Delete** -- deletes the selected app groups.

-  **Create App Group** -- creates a group and opens its edit card.

You assign a finished group to hosts in the [host group card](./../station-groups/station-group-card.md), in the **App Group** field.

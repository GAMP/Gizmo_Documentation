**IMAGE: App group edit card in Gizmo Manager with the Name field and the tab for selecting the apps in the group**

The card opens when you create a new app group or edit an existing one.

-  **Name** -- the name of the app group.

-  **Organize Apps** -- the tab where you choose the apps that belong to the group. Check the apps you need or find them with the search.

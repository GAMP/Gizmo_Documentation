This section is where you link tasks to events on a gaming station. The screen is split into four blocks -- one for each event; the number of assigned tasks is shown in parentheses.

## Events

-  **Computer Startup** -- the PC has started and connected to the server.

-  **User Login** -- a user has logged in on the gaming station.

-  **User Logout** -- the user session has ended.

-  **Computer Shutdown** -- the PC is shutting down.

## Assigning a task

Each block has:

-  **Select Task** -- assigns one of the created [tasks](./zadachi.md) to the event.

-  **Create New Task** -- opens task creation; after you save the task, it becomes available for assignment.

You can assign several tasks to one event.

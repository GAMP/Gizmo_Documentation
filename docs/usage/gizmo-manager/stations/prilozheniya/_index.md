This section is where you set up the apps that users see in the client shell. An app consists of an app card and one or more executables -- different ways to launch it.

## Actions

-  **Edit** -- opens the [edit card](./kartochka-redaktirovaniya-prilozheniya.md) of the selected app.

-  **Delete** -- deletes the selected apps.

-  **Create App Category** -- creates a category. Categories visually split apps into subsections in the shell -- for example, "Games" and "Launchers" -- and are set in the app card.

-  **Create App** -- creates an app and opens its edit card.

## What an app consists of

-  [App card](./kartochka-redaktirovaniya-prilozheniya.md) -- name, description, cover, category and app group.

-  [Executable card](./kartochka-redaktirovaniya-ispolnyaemogo-fayla/_index.md) -- launch options, plus personal user files, deployments, licenses and tasks.

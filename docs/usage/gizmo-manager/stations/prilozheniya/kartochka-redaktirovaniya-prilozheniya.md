**IMAGE: App edit card in Gizmo Manager with the Title, Description, Executables, Links, Cover, App Group and App Category fields**

The card opens when you create a new app or edit an existing one.

-  **Title** -- the name of the app card in the app list and in the client shell search.

-  **Description** -- the app description the user sees in the shell when opening the app details.

-  **Executables** -- the app's launch shortcuts. The <cmd text="+ Create Executable"/> button opens the [executable card](./kartochka-redaktirovaniya-ispolnyaemogo-fayla/_index.md). You can add any number of executables -- for example, one to launch the game with a "Personal account" and another to launch the same game with a "Club account".

-  **Links** -- links to sources that the user sees when opening the app details. Add them with the <cmd text="Add Another Link"/> button. Each link has these fields:

   -  **Caption** -- the link name in the shell.

   -  **URL** -- the link address.

   -  **Description** -- the link description in the shell.

-  **Cover** -- the app's cover image in the client shell. The recommended resolution is 300×450 px, but any image with a 1:1.5 aspect ratio works.

-  **App Group** -- the group the app is linked to. If no group is selected, the app is not shown on gaming stations.

-  **App Category** -- one of the categories you created or one of the defaults.

-  You can also add information that users see when opening the app details in the shell:

   -  **Version** -- the app version.

   -  **Developer** -- the app developer.

   -  **Publisher** -- the app publisher.

   -  **Age Rating** -- the minimum age to launch the app. If it is set and age restrictions are configured in <cmd text="Settings"/>, users under this age cannot launch the app.

   -  **Release Date** -- the app's release date.

> [!WARNING]
>
> Save the app card before you create an executable. Opening the executable card closes the current card -- if it was not saved, you will have to make your changes again.

**IMAGE: Host group edit card in Gizmo Manager with the Name, Branch, Theme, Theme Profile, App Group, Security Profile and Default Guest Group fields**

The card opens when you create a new host group or edit an existing one.

-  **Name** -- the name of the host group.

-  **Branch** -- the branch the host group is linked to.

-  **Theme** -- the global client shell theme (skin) for the hosts in this group.

-  **Theme Profile** -- a specific profile within the selected theme. It lets you style the shell differently for different host groups.

-  **App Group** -- the apps available on the hosts in this group. If an app from the group is missing at the specified path on a particular PC, it is not shown in that PC's shell.

-  **Security Profile** -- the profile applied to all PCs and endpoints in this group.

-  **Default Guest Group** -- the user group that one-time (guest) accounts are placed in when they log in on hosts in this group.

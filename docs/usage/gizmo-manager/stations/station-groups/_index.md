This section is where you create and manage host groups. These are groups of gaming stations that you can link tariffs (hourly rates), time products, security profiles and other settings to.

> [!IMPORTANT]
>
> Every host must belong to a host group. Gizmo Client on a PC without a group will not connect to the server -- an error will appear on the screen.

## Group list

-  **Name** -- the name of the host group.

-  **Branch** -- the branch the group is linked to.

-  **Theme** -- the client shell theme for the hosts in the group.

-  **App Group** -- the set of apps available on the hosts in the group.

-  **Security Profile** -- the profile applied to the hosts in the group.

-  **Default Guest Group** -- the user group for guest accounts.

## Actions

-  **Edit** -- opens the [edit card](./station-group-card.md) of the selected group.

-  **Delete** -- deletes the selected host groups.

-  **Create Host Group** -- creates a new group and opens its edit card.

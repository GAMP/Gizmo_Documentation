This section lets you manage the client PCs that connect to the server. A PC appears here automatically the first time it connects to the server, or you can add it manually.

## Computer list

-  **Number** -- the station's number.

-  **Name** -- the PC's name in Gizmo.

-  **Hostname** -- the PC's name in Windows.

-  **Branch** -- the branch the PC belongs to.

-  **Host Group** -- the group the PC is linked to.

-  **Layouts** -- the layouts the PC is shown on in the <cmd text="Map"/> section.

-  **IP Address** -- the PC's current address on the local network.

-  **MAC Address** -- the physical address of the PC's network card.

-  **Version** -- the version of Gizmo Client installed on the PC.

-  **Controller** -- the controller linked to the PC.

Above the list are the **Branch**, **Host Group** and **Layout** filters.

## Actions

-  **Edit** -- opens the [edit card](./computer-card.md) of the selected PC.

-  **Delete** -- deletes the selected PCs.

-  **Create Computer** -- creates a card for a new PC.

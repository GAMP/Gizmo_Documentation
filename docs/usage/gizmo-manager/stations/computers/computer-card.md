**IMAGE: Computer edit card in Gizmo Manager with the Name, Number, Hostname, MAC Address, IP Address, Version, Branch, Host Group, Layouts and Controller fields**

The card opens when you create a new PC manually or edit an existing one.

-  **Name** -- the PC's name. It is shown in the host list, on the club map and in search results.

-  **Number** -- the PC's number in Gizmo.

-  **Hostname** -- the PC's name in Windows. If **Restore Hostname** is turned on in <cmd text="Settings"/> -> <cmd text="Server"/> -> <cmd text="Network"/>, in the **Connection Rules** block, Gizmo assigns this name to the PC in Windows every time it connects.

-  **MAC Address** -- the physical address of the PC's network card. It is used to identify the device when its IP changes and to send Wake On LAN.

-  **IP Address** -- the PC's current address on the local network. It is shown only when the PC is on and connected to the server.

-  **Version** -- the Gizmo Client version on this PC. It is shown only while the PC is connected.

-  **Branch** -- the branch this PC is shown in.

-  **Host Group** -- the group this PC is linked to. It sets the hourly rate, the available time products and the security profile that applies.

-  **Layouts** -- the layouts the PC is shown on in the <cmd text="Map"/> section.

-  **Controller** -- the controller linked to the PC. You need it to turn the HDMI signal at this station on and off remotely.

This section is where you create and manage map layouts. You can place gaming stations on layouts so that you can easily switch between them -- for example, between the 1st and 2nd floors of the club or between its different zones.

## Actions

-  **Edit** -- opens the [edit card](./kartochka-redaktirovaniya-sloya-karty.md) of the selected layout.

-  **Delete** -- deletes the selected layouts.

-  **Create Layout** -- creates a layout and opens its edit card.

You switch between the layouts you have created in the <cmd text="Map"/> section.

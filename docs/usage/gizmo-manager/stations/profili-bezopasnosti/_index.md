This section is where you create and manage the security profiles that apply restrictions on client PCs. Security profiles can lock down system features so that the user has no access to the PC except the shell and the games in it, and cannot remove the shell.

## Profile list

-  **Name** -- the name of the security profile.

## Actions

-  **Delete** -- deletes the selected security profiles.

-  **Create Security Profile** -- creates a profile card and opens it for editing.

You assign a finished profile to hosts in the [host group card](./../station-groups/station-group-card.md), in the **Security Profile** field. The full list of restrictions is covered in [Security profile card](./kartochka-redaktirovaniya-profilya-bezopasnosti.md).

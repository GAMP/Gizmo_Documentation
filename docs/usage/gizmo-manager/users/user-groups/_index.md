The tab lists the groups the club's accounts are sorted into. A group is a set of shared rules: which time sources its members may use, which hosts they can access, which discount they get and what is available to them in the client shell.

Use this tab to set rules not for each guest separately but for a whole category at once: regular customers, guests without an account, promotion participants. Here you create, edit and delete groups.

A new group is created with the <cmd text="Create Group" /> button in the top right corner. Double-click a row to open the [User group card](./user-group-card.md).

## Group list

- **Name** -- the group name.
- **Users** -- how many accounts are in the group.
- **Personal Storage** -- whether the group members get personal file storage on the host.
- **Guest** -- marks the guest group, which customers without their own account go to.
- **Default Group** -- marks the group that newly created accounts go to.
- **Discount Group** -- the discount group linked to this user group. Discount groups are created in the [Marketing](./../../marketing/_index.md) section.

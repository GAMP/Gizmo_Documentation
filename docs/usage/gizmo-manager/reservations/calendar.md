The tab shows gaming station occupancy over time and opens first when you go to the section. The club's hosts run vertically, and dates and half-hour slots run horizontally; reservations appear as rectangles where they cross.

Use this tab to see at a glance what is already taken in the room and to make a new reservation for a free host and time.

## Creating a reservation

The <cmd text="Create Reservation"/> button is in the top right corner and offers two options:

-  **With Payment** -- the reservation is made together with taking the payment;

-  **Without Payment** -- the reservation is made without money, and the guest pays later.

> [!IMPORTANT]
> 
> Both options open the same [reservation form](./reservation-card.md). They differ only in whether the payment is taken when the reservation is made.

## Filters

They are in the bar above the calendar and work together: if you set several, the grid keeps only the hosts and reservations that match all the conditions.

-  **Date** -- the period the grid shows. Next to the filter is a field with the start date and time, and to its right is the calendar icon.

-  **Branch** -- leaves the hosts of the selected branch.

-  **Host Group** -- leaves the hosts of the selected [host group](./../stations/station-groups/_index.md).

-  **User** -- leaves the reservations of the selected guest.

All the conditions you set are cleared with the <cmd text="Clear All"/> link. The help icon is in the right corner of the bar.

## Calendar grid

The grid rows are the club's hosts, grouped by host group: the group name is a separate row with its hosts below it. Each host shows the gaming station number on the left and the name on the right.

The grid header has two rows: the top one shows dates, the bottom one shows half-hour slots.

> [!NOTE]
> 
> You can scroll the grid with the mouse (hold the left button on an empty area of the grid and drag it left or right) or with the slider under the reservation grid.

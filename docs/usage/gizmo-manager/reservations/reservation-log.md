The tab holds the list of all the club's reservations -- both upcoming and past -- with their status and payment status.

Use this tab to review the history: find a specific guest's reservation, see whether it took place and whether it was paid, and how many hosts were reserved over a period. Unlike the [calendar](./calendar.md), which shows occupancy for the selected dates, the log shows the reservation records themselves.

## Filters

They are in the bar above the list and work together: if you set several, only the reservations that match all the conditions remain.

-  **Period** -- the time range for which reservations are shown. **Custom** is selected by default.

-  **Branch** -- reservations of the hosts of the selected branch.

-  **Host Group** -- reservations of the hosts of the selected [host group](./../stations/station-groups/_index.md).

-  **User** -- reservations of the selected guest.

-  **Reservation Status** -- the state of the reservation. The current value is shown next to the filter name; **All** removes the limit.

-  **Payment Status** -- the payment state. The current value is shown next to the filter name; **All** removes the limit.

All the conditions you set are cleared with the <cmd text="Clear All"/> link.

## Reservation list

Each row is one reservation.

-  **ID** -- the reservation number.

-  **Start Date** -- the date and time from which the host is reserved.

-  **End Date** -- the date and time until which the host is reserved.

-  **Hosts** -- how many hosts the reservation includes.

-  **User** -- the guest the reservation is for.

-  **Phone** -- the guest's phone from their [user account](./../users/users/user-card.md).

-  **PIN** -- the reservation code, created together with the reservation. The reservation owner does not need the PIN, but a guest who sits at a host from someone else's reservation, for example the owner's friend, must enter it. See [Reserving gaming stations](./../../../articles/booking.md).

-  **Reservation Status** -- the state of the reservation, shown as a colored label. For example, "Expired" for a reservation whose time has passed.

-  **Payment Status** -- the payment state, shown as a label with an icon. For example, "Without Payment" for a reservation made without taking money.

title: Remote access
order: 1
---

Remote access lets you control client PCs remotely. There are two modes -- control and view. Control lets you use the customer's cursor and keyboard, view does not. You switch between these modes in the remote access window.

## If remote access does not work

The connection between Gizmo Manager and the client PC goes through Gizmo Server, so Manager and the client do not have to be in the same subnet. If you cannot connect:

- check that Windows Firewall or an antivirus on the client PC or on the server is not blocking the connection.

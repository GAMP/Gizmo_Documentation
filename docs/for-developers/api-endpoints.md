Gizmo Server provides a Web API for integration with third-party systems: for example, to export data on users, sales and invoices to your own reports or to Excel.

The description of all endpoints (Swagger) opens from Gizmo Manager: **Settings -> Others -> About**, **Modules** block -> **API Module**. For details, see [About](./../configure/others/about.md).
